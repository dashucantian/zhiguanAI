## 文件

- `build_field_model.py`：只读四源，生成 `data/field-model.json` 与 `data/field-model.js`；`--watch` 监视四源 mtime，变化即重建。
- `index.html`：二维 SVG 关系图；四层（主体×任务×边界×模型）；点击节点显示文件:行号＋建模时原文；自动刷新 2 秒；零网络请求。
- `validate_anchors.py`：锚点探针（文件存在／不越界／非空行／行首 60 字指纹）；退出码 0＝CLEAN，1＝NEEDS-RECHECK。
- `selftest_four_criteria.py`：四条判据自测，读数落 `selftest_readings.txt`。
- `启动活看板.bat`：双击启动监视器并打开页面。
- `selftest_readings.txt`：四条判据实测读数（数据层）。
- `browser_readings.txt`：浏览器实测读数（点击回源、活刷新、零网络）。

## 怎么用

双击 `启动活看板.bat`：启动监视器（每 2 秒看四源 mtime），打开 `index.html`。改任一登记件，页面约 2 秒内自动刷新；点任一节点，右侧显示它的回源文件:行号与原文。关掉监视器黑窗即停止监视。

单独跑：

```
python build_field_model.py            # 生成一次
python build_field_model.py --watch    # 监视并重建
python validate_anchors.py             # 锚点探针
python selftest_four_criteria.py       # 四条判据自测
```

## 边界与已知限制

- 锚＝工作树行号＋行首 60 字指纹，`side=working-tree`；行号由构建脚本现算，不手填。行漂移会被探针抓，不自动修复（避免把坏锚悄悄修好）。
- 只读四源；不改任何共享登记件。判据②的改件测试用字节一致副本，副本 sha256 与源件逐件相同；真源测试后仍为「进行中」。
- 页面本身不读盘校验；真值闸是 `validate_anchors.py`，页面只展示建模时锚点与原文。
- 架构模型只读其登记件本身，不读它 `sourceRefs` 指向的代码文件（保持四源读面）。
- 任务层含历史任务与未标责任窗的任务；未标责任窗者不强行挂窗，不编造关系。
- 页面每 2 秒重载一次本地 `field-model.js`（约 360 KB，file:// 读取，零网络）；长时间挂机可关「自动刷新」，用「刷新」按钮手动取新。
