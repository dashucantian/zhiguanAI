## 附录·复跑配方（自含，不依赖 scratch 留存；_analysis_tmp 七日自清后仍可按此重建）

### A. 夹具目录约定

自建目录 FX（任意路径，建议仓库根 `_analysis_tmp/fx验/`，不入库）：FX/index.html＝看板根 index.html 字节复制；FX/data/＝空目录待放注入件。页面只认相对路径 data/，故夹具与正件互不干扰。

### B. 改源与版本（B2/E3/T3 用）

1. 复制看板 data/field-model.js 到 FX/data/。
2. 改版本与一节点名（python 两行）：读全文，替换 `"version":"<旧12位>"` 为新 12 位、替换任一 `"label":"<原名>"` 为原名加后缀；写回。
3. 开 FX/index.html 点「重新读盘」：期望版本条 old→new＋明细点名该节点；再点一次（无变化）：期望版本条与明细逐字不擦。

### C. 四坏锚与无锚节点（B4/D2/T2 用）

1. 复制 validate_anchors.py 与 anchor_check_emit.py 到 FX/（复制后 sha256 与看板根正本核对相符，判据单一真源）。
2. FX/src/tiny.md 写三行：第一行「### 小源第一行」、第二行空、第三行「第三行」。
3. FX/model.json 最小模型：root＝FX 绝对路径（正斜杠）；nodes 一枚 id=node.t1、anchors 五枚＝(tiny.md,1,fp=第一行全文)／(tiny.md,2)／(tiny.md,99)／(nosuch.md,1)／(tiny.md,3,fp=错串)；edges 空；stats.anchors=5。另加 node.t2（anchors 空数组）验无锚灰态。
4. FX/data/field-model.js 写 `window.FIELD_MODEL = <model.json 内容>;`。
5. FX/ 内跑 `python anchor_check_emit.py --model model.json --root .`：期望退码 1（有坏锚）且打印「锚 5、OK 1、坏 4」；解析行数不符时退 2 且不写文件（拒发闸）。
6. 开 FX/index.html：面板四类分列各 1；坏行「点回现场」到 tiny.md 对应行；node.t2 右栏灰「锚 未取到」。

### D. 500/2000 节点性能夹具（E2/E3 用）

python 生成：n 枚节点按 layer＝subject/task/boundary/model 轮转、label 带序号、anchors 一枚指 tiny.md:1；edges 每隔一对连一条「隶属」；stats 三数＝实数；version 自定。写入 FX/data/field-model.js 后开页量数；改 version 再量重建。

### E. 计时取数法（页内 evaluate，三段）

1. 同步渲染段：`const a=performance.now(); <click>; performance.now()-a`（click 用 element.click()，派发走同一 document 监听链；指针层另标未验）。
2. 重建端到端（不含绘制）：MutationObserver 观察 #verchip，click「重新读盘」后在回调里取 dt。
3. 首屏：`performance.getEntriesByType('navigation')[0].loadEventEnd`（含解析与注入、不含首绘）。

### F. 原文比对法（B1 用）

python：读源件按行切（CRLF 归一），取第 N 行（1 基）；与页内 `.rawline.sel .lt` 文本逐字比；不符即红。
