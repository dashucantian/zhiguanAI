## 一、数据模型契约

### 1.1 单一真源，前端只消费

- 真源＝`build_field_model.py` 只读四源生成的 `data/field-model.json`（人读）与 `data/field-model.js`（机读，`window.FIELD_MODEL = {...}`）。
- 前端经 **file:// 注入 `<script src="data/field-model.js?v=时间戳">`** 取数（现状法，保留）；**不用 fetch**（file:// 下 fetch 受 CORS 限，且注入法已证零网络）。
- 前端**不新增源、不新增边、不持久化任何派生数据为权威**。所有分组／叙事／邻域／信号计数都是 `FIELD_MODEL` 的**派生视图**，每次刷新现算（避坑 3「第二真源」）。

### 1.2 schema `field-model/1`（契约冻结，P5 不改生成器）

| 顶层键 | 形状 | 前端用途 |
|---|---|---|
| `version` | 12 位 hex | 刷新 diff 触发键（§五） |
| `generatedAtLocal` | `YYYY-MM-DD HH:MM:SS` | 版本条时刻 |
| `root` | 仓库根（正斜杠） | 锚「打开文件」file:// 拼接 |
| `sources[]` | {key,label,path,bytes,lines,mtime,sha256} | 空状态逐源 chip／底栏四源行数 |
| `nodes[]` | 见 1.3 | 图元／分组／叙事 |
| `edges[]` | 见 1.4 | 关系渲染／邻域 BFS／路径追踪 |
| `stats` | 见 0.1 | 概览计数／锚体检面板 |
| `sourceMeta` | {identity,tasks,rulings,arch}→sha | 版本溯源（前端不直接用） |

### 1.3 节点契约

公共字段：`id`、`layer`(subject/task/boundary/model)、`kind`、`label`、`desc`、`attrs{}`、`anchors[]`。
层特有：subject 带 `window`；task 带 `windows[]`、`status`、`attrs.状态类`；model 带 `archId`、`archType`。
kind 枚举：ai／human／window／task／ruling／window-boundary／task-boundary／arch-node／arch-hub。

### 1.4 边与锚契约

- 边：`id`、`from`、`to`、`type`、`desc`、`anchors[]`。type 七类：隶属／架构／责任／边界／裁定／授权／读取。
- 锚：`file`(相对路径)、`line`(int，工作树现算)、`fp`(行首 60 字指纹)、`side="working-tree"`、`note`、`section`、`raw`(归一后前 420 字)、`rawLen`。
- **锚是建模时快照**：`raw` 在生成时捕获，页面不回盘重读（README §边界）。真值闸是 `validate_anchors.py`，不是页面（§七）。

### 1.5 版本语义

`version = sha256("路径:sha256\n"×4)[:12]`。任一源**内容**变（sha 变）则版本变；仅 mtime 变而内容不变则版本不变。前端以版本相等与否决定要不要重渲染（§五），避免每 2 秒无谓 DOM 翻动。

## 二、布局算法（稳定优先；v1.1 改为文档流＋CSS grid，不算坐标）

### 2.1 总则（订正）

- **固定四列＝语义列序不变**：主体 → 任务 → 边界 → 模型（P1 §三明令的实质）。实现手段改为 **CSS grid**：`.canvas{display:grid;grid-template-columns:repeat(4,1fr)}`（P3 `p3.css` 已定）。**不再固定 X 坐标**——旧稿 `X={subject:90,task:590,boundary:1090,model:1590}` 是 SVG 实现的手段，随选型一并撤（§十六）。
- 布局＝**纯函数** `group(model) → columns[{layer, groups[{key,name,count,nodes[]}]}]`：只做确定性分组与稳定排序，**位置交给浏览器文档流**，JS 不算 X/Y、不做每帧重排、不用动画驱动位置。同输入必同输出。
- 边**不画曲线**：P3 §八明令「不画装饰曲线」，关系以**关系行／邻域清单／聚焦条**呈现（§三.3）。故无 `edgePath`、无 viewBox、无滚轮缩放、无拖拽平移；滚动＝页面原生滚动。

### 2.2 列内排布（稳定键，保留）

| 列 | 分组与排布规则 | 稳定键 |
|---|---|---|
| 主体 | 按窗分组（W3 协调／W1 工程／W2 文档／W4 模型）＋「决策人」组；组内法师置顶、AI 按号 | 窗 `Wk`；`attrs['AI 号']` |
| 任务 | 按状态分组（进行中／待办待裁／已完成已交／其他／已销）；组内任务号倒序 | `attrs.状态类`；`attrs.任务号` desc |
| 边界 | 按 kind 分组（窗口职责／裁定边界／任务边界） | `kind`；组内 id |
| 模型 | 按 archType 分组（服务／模块／正源／投影／外部·库·风险等）；hub 归服务组首 | archType 固定序；组内 label |

- 组名与计数**每次刷新现算**，不写死（P3 原型里的 16/11/6/3 等是稿上演示值，实现须由 `group()` 产出）。
- 增删节点时其余节点按同一规则可预测地顺移；**不做力导向避让**（P0 坑 1）。
- 组内超出首屏的节点以「展开余 N …」行收口（P3 `.more`），N 现算；点开即渲染余下节点，不改分组。

### 2.3 语义组折叠（原生 details，借 n8n 折叠组）

- 组块＝`<details class="group"><summary class="ghead">组名＋计数＋caret</summary><div class="gbody">节点…</div></details>`。**开合与高度由浏览器自管**，JS 不测量、不计算。
- `collapse{groupKey:bool}` 是 **UI 会话态**，只用于版本变重建 DOM 后还原开合；不入数据、不落盘。
- 收起时子节点仍在 DOM（`details` 语义），仅不显示 ⇒ 搜索命中收起组内节点时须自动展开该组（§四.1）。
- `prefers-reduced-motion` 生效时全静；本轮不加位移动画（P4 细化）。

### 2.4 窄屏（CSS 媒体查询，同一份 DOM）

| 断点 | 变换 | 依据 |
|---|---|---|
| ≤1100px | `.main{grid-template-columns:1fr}`（右栏下移）；`.canvas{repeat(2,1fr)}`（四列折 2×2）；`.overview{1fr}`；`.aside` 改横排可换行；`.workbench{1fr}` | P3 `p3.css` 末段已定 |
| ≤760px | `.canvas{1fr}`（单列纵向）；topbar 换行；状态栏精简 | 任务书 §四断点 760／1100／1440 |
| >1440px | 四列＋右栏 338px 原样 | P3 宽屏稿 |

- **法师真实 CSS 视口实测仅 900–1100 宽**（屏幕 2560×1600，非 1280）⇒ **2×2 是常态而非例外**，P7 窄屏验收以该宽度为首要面，不以 1440 稿为准。
- 这是 CSS 布局态切换，**不是另一套数据布局**：`group()` 输出不变，不重映射坐标、不重建 DOM。

## 三、渲染选型（v1.1 订正：HTML/CSS，不是 SVG 图）

### 3.1 选型决定：HTML/CSS 文档流（法师亲裁的 P3 原型即此）

| 规模 | DOM 量级估算 | 选型 | 理由 |
|---|---|---|---|
| 现 108 节点 | 节点卡 108×≈5＝540；组块 ≈20×4＝80；概览/右栏/底栏 ≈120 ⇒ **≈740 元素** | **HTML/CSS** | 文档流无坐标计算；`details` 原生折叠；文本可选中可复制；可访问性天然 |
| 投影 ≤500 节点 | ≈2500＋组块 ≈ **2700 元素** | **HTML/CSS 仍可用** | 折叠态下实际可见远小于总量；交互只切 class |
| >2000 节点 | 文档流压力显现 | 逃生舱＝**分组分页／虚拟列表**（本轮不实现） | 不上 Canvas、不上 WebGL |

- **边不占常驻 DOM**：91 条边不画曲线（P3 §八），只在聚焦时渲染该节点的邻域关系行（一跳＋经窗二跳，通常 ≤10 行）⇒ 边成本从 415 个 SVG path 降到按需十余行。
- **不上 WebGL/3D/Canvas**（任务书 §九「只做二维」）；旧稿的「Canvas2D 边层逃生舱」随曲线一并撤（§十六）。
- 触发阈值（写死供 P7 测）：节点数 >2000 **或** 500 节点交互 >16ms 持续，才议逃生舱；本项目远未到，**YAGNI，本轮纯 HTML/CSS**。

### 3.2 零第三方库、零网络资产

- 不用 D3/cytoscape/任何图库或组件框架（§九：第三方库须本地化＋先报体积许可，不许 CDN）。**vanilla DOM ＋ 一份 CSS**，零依赖。
- 折叠用原生 `details/summary`（P3 原型已用）；信号环用**内联 SVG 单个 `<circle>`**（P3 已定，14×14，属图标不是图渲染，不违反「不画装饰曲线」）。
- 字体只用系统栈（P3 `--serif/--sans/--mono` 已定回落链），**零网络字体、零图标库**。
- CSS 落点：新前端复用 P3 令牌与组件样式，**另起一件** `board.css`（不直接引 `design/p3_src/p3.css`，避免实现件依赖设计稿目录）；`p3.css` 原样不动（属 AI-036 产出）。

### 3.3 关系的呈现（边 → 关系行／邻域清单／聚焦条）

- 选中节点 → 顶部 `.focusstrip`：`聚焦：{label} —{type}→ {对端label}` ＋该边锚 chip ＋提示「点空白处解除聚焦 · 非邻域淡出但不隐藏」。
- 右栏「邻域」面板：`.relrow` 每行＝类型徽标（隶属/责任/边界/裁定/授权/读取/架构）＋`from → to`＋边锚 chip；一跳直连与经窗二跳分列计数（P3 聚焦态 tag「直连 1 · 经 W1 二跳 2」）。
- 邻域由 `edges` 现算 BFS（一跳＝直接相邻；二跳＝经窗节点中转），**不新增边、不推断无依据关系**。
- 非邻域节点加 `.dim`（opacity .32）、非邻域组加 `.group.dim`（.38）；选中节点加 `.lit`（**描边** outline 2px，不用色相）。点空白处解除。
- 点关系行／锚 chip → 切证据视图（皮肤 B）定位该锚全行。

### 3.4 可访问性（P4 细化，P5 定骨架）

- 节点卡 `tabindex=0`、`role=button`、`aria-label=label`；`summary` 天然可键盘开合；Enter 选中、Esc 解除聚焦、`/` 聚焦搜索框。
- 聚焦用**描边**不用色相（P3 §四.2，色盲安全）；信号环旁标文字「提案」，不靠颜色独传义；灰＝未取到必附文字，不靠色独传。
- 对比度：A 纸本墨字 `#2b2a27`/底 `#f4f0e6`；B 深色字 `#e8eaed`/底 `#14181d`（P3 令牌原值）。

- 文本溢出：节点标签沿用 P3 `nowrap＋ellipsis`，但**必附 `title` 全称**且点击后节点卡显全名 ⇒ 不重演旧 `fitText` 把字缩到 12px 以下再截断的病。

## 四、状态管理

### 4.1 单状态对象，无框架（保留现状模式）

```
state = {
  model, prevModel, lastVersion, loading, auto,
  selected, focused, neighborhood:{oneHop:[], twoHop:[]},
  preset:'总览'|'责任'|'证据', skin:'a'|'b',
  collapse:{groupKey:bool}, filters:{layer:bool},
  search:{query, mode:'highlight'|'filter'},
  bookmarks:[nodeId],          // 会话内，URL hash；不建持久层（§4.3）
  diff:{added:[],removed:[],changed:[]},   // 版本变时现算（§5.2）
  evidence:{nodeId, anchorIndex}           // 证据视图定位态
}
```

- **单向渲染**：事件 → 改 state → 渲染受影响部分。版本变才重建列 DOM；聚焦/过滤/搜索只切 class（保留现状 `highlight()`/`applyFilters()` 局部更新法），避免每交互全量翻动。
- 撤 `view:{x,y,k}`（缩放/平移随 SVG 选型一并撤，§二.1）；滚动由页面原生承担。
- 搜索命中收起组内节点时，自动把该组 `details.open=true` 并记入 `collapse`，否则命中不可见。
- 不引 Redux/信号库；直接监听器（现状法）。零依赖、file:// 可跑。

### 4.2 视图预设与皮肤绑定

- 预设（借 LikeC4 单源多视图）：**总览／责任／证据**，同读一份 `FIELD_MODEL`，不新增源/边。
- 预设决定皮肤：总览/责任 → A 纸本；证据 → B 深色（P3 §五）。皮肤＝`html[data-skin]` 整组令牌替换，**组件与语义不变**。
- 预设只改「看哪些组/哪种叙事/右栏形态」，不改数据。

### 4.3 书签（会话内 only；v1.1 明定不建持久层）

- 会话内书签＝URL hash（`#nodes=id,id`）＋`state.bookmarks`；同会话刷新页面可还原，**关窗即失**。
- **跨会话持久＝先不做**（协调窗建议、法师 03:2x 同意）：file:// 协议下各家浏览器 localStorage 行为不一，做了也不可靠；等真有人抱怨「每次要重新点」再上，现在做是凭空造持久层。
- 因此本轮**不写 localStorage、不写 IndexedDB、不落书签文件**；P3 右栏「书签（会话内）」插槽照留，文案改为「会话内书签 · 跨会话持久暂不做（候真实需求）」。
- 前一字「要」已被第二阶段覆盖（§0.3 表）；本件不再把持久层列为候裁项。

## 五、刷新与 diff

### 5.1 刷新链（保留现状，零网络）

1. `build_field_model.py --watch` 每 2 秒 stat 四源（mtime_ns＋size），签名变即 `build()`，原子 `os.replace` 写 `.json`/`.js`。
2. 前端每 2 秒注入 `field-model.js?v=Date.now()`（auto 开时），读 `window.FIELD_MODEL`。
3. 比 `version`：**相等→跳过重渲染**（只付脚本解析成本）；**不等→四列 DOM 重建＋版本条＋变化明细**（§5.2）。
4. 手动「刷新」按钮强取；auto 可关（长挂机省成本，README 注）。

### 5.2 变化态：版本条＋变化明细（v1.1 获批做，不再回落）

**两层呈现**

1. 版本条（P3 `.versionbar`）：「版本已变 `old` → `new`，`旧时刻` → `新时刻`」＋「明细 N 项」入口。
2. 变化明细清单：节点／边集合差，**每项带锚**，点开即切证据视图定位该锚全行。

**算法（纯前端、内存、确定性）**

- `state.prevModel` 留上一版完整 model（页面会话内）。版本不等时按 `id` 建 Map，比内容指纹（`label/desc/status/attrs/anchors` 的稳定序列化）：
  - `added`＝新有旧无；`removed`＝旧有新无；`changed`＝两版都有但指纹不等（附「变了哪几个字段」）。
- 边同法（`id`＋`from/to/type/desc/anchors` 指纹）。
- 每项渲染：类型徽标（新增／移除／变更）＋节点 label＋变化字段＋锚 chip。计数带分母，不做百分比。
- **首次加载无 prevModel** ⇒ 只显版本条，明写「明细未列：本页首次加载，无上一版可比」，不假装列明细。
- 关页即失（不跨会话，符合裁定②）。

**盘上底稿（当轮核对用，不是页面数据源）**

- 落点 `_analysis_tmp/`；件名 `field-snap-W1-8473bc3e-<version>-<YYYYMMDD_HHMMSS>.json`（前缀带本窗会话号，守一文件一写者；该目录现有 17,951 件，属多窗共用 scratch）。
- **现点 ignore 判据（2026-11-10 03:29 逐名实测）**：`.json` → `.gitignore:77 *.json`（**全局条，不是 `_analysis_tmp` 专条**）；`.txt` → `:313 /_analysis_tmp/*.txt`；**`.js` → 未被忽略（会入库）**。`_analysis_tmp` 无目录级忽略条，专条只有 `:311–314`（.py/.mjs/.txt/一个 .md）。
- 由此推出一条硬约束：底稿只能落 `.json`；而 file:// 页面 **fetch `.json` 受 CORS 限**、改用 `.js` 注入又会入库污染 ⇒ **页面不读盘上底稿**，明细一律由内存 `prevModel` 算。底稿只供人与探针当轮核对。
- 写底稿者＝**另起一件新脚本**（本窗自产，不改 `build_field_model.py`）；按需运行，不做常驻守护、不挂排程。
- **7 天自清判据＝文件名内嵌日期，不用 mtime**。现点反例：`_analysis_tmp/_canary_probe.txt` 的 mtime 显示 `11-10 04:01`，而现取 `date` 为 `03:29:02`（在未来 32 分钟）⇒ mtime 不可作唯一清理判据。
- 底稿属**过程物非成果**：不入交付清单、不引为验收证据正本（验收证据＝页面实测读数＋探针退码）。

### 5.3 空状态（源未取到）

- `field-model.js` 注入 `onerror` 或 `FIELD_MODEL` 为空 → 空状态：逐源灰 chip「未取到」（按 `sources[]` 逐源报，不合并）；四层骨架灰点、计数显「—」**不是 0**；底栏「未取到 ≠ 真零」（P3 §四.5）。
- 不催促、不假装有数据；等源恢复自动重建／手动重新读盘。

## 六、性能预算

| 指标 | 预算 | 测法（归 P7） |
|---|---|---|
| 本地首屏 | **<1 秒** | `performance.now()` 包 load+render；file:// 真机 |
