# 任务看板 · 使用说明（给法师）

## 一、怎么打开

**双击仓库根目录的 `任务看板.bat`。**

浏览器会自动跳到 `http://127.0.0.1:8848`。
关掉黑窗口＝看板停。

> 黑窗口不能关小到看不见？可以关小，别点 ×。

---

## 二、界面上你能做什么

| 你想干什么 | 点哪里 |
| --- | --- |
| 打字问 | 左栏输入框打完，按 **发送**（或回车） |
| 说话问 | 点 **🎤 语音**，说完再点一次停止 |
| 让回答念出来 | 勾 **朗读** |
| 让它带上看板数字回答 | 勾 **带看板摘要**（只送计数与任务标题，不送对话正文） |
| 截当前屏幕 | 右栏 **📷 屏幕共享（只存本机）** |
| 暂停某个看板作业 | 中栏作业行 **暂停** |
| 调优先级 | 中栏 **−／＋**（数字小＝先跑） |
| 立刻跑一次 | 中栏 **立即跑** |
| 催某个 AI 窗口 | 左栏「跨窗投递单」选窗口＋选动作 → **生成投递单** → **复制** → 你自己粘过去 |
| 看模型通不通 | 右栏 **探活** |

---

## 三、三件必须知道的事

**1. 看板不替你发消息。**
「投递单」只是生成一段文字。发不发、发给谁，由你决定。

**2. 屏幕截图永远不出这台电脑。**
截图只落在 `state/screen/`（该目录整个不进仓库），只在本机回环显示。
送云端模型会被当场拒绝——这是你自己定的原则，写成了服务端强制，绕过界面也拦得住。

**3. 一级内容别往云端模型里打。**
修道班资料、学员信息、录音转写、居士真名与联系方式——**禁止**输入云端模型（千问 Flash／Plus）。
打了会被闸2 整段拦下，一个字都不发出去。
要用这些内容，请切到「本机规则应答」或 LM Studio。

## 五、窗口状态为什么有时标「磁盘mtime推断」

真正的 `runtimeState`（running／cold）**只有 AI 窗口能取**，看板取不到。
所以：任一 AI 窗口执行 MCP `list_chat_sessions`，把结果写进 `state/live_sessions.json`，看板 20 秒内就会改标「MCP快照」。
超过 180 秒没刷新，看板退回按文件修改时间推断，并在界面写明来源——**不会拿推断冒充实时**。
