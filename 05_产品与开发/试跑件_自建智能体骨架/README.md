## 六、器物层发现一件（与规则无关，但会影响别人复现）

本机 `python`（DSH 运行时自带 3.14）**不把脚本所在目录放进 `sys.path`**，`import agent_skeleton` 直接 `ModuleNotFoundError`。已在 `selftest_offline.py` 里显式补 `sys.path`，并在文件内注明缘由。**同一台机上别的窗若要跑，照抄这一行即可。**
