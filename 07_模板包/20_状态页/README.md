# 20_状态页包 —「我们到哪了」只需要一页纸

**问题**：进度散在几十段聊天记录里，新窗口一问三不知；两个窗各信一份旧文档，干出互相打架的活。

**方案**：项目根放**一页**《当前状态》——重心一行、硬约束几行、各线一格、候裁清单、滚动收口。它是全项目的**仲裁层**：文档与它冲突以它为准；它过期就更新它，不绕过它。

**可复制块**：`当前状态_空壳.md`（含 token 硬预算与头行追加制）。

**效果**：新窗开工八步里的"读状态页"30 秒完成；冲突裁决有唯一上位文件；决策人手机上扫一眼第四节就知道今天要拍几块板。

**要点**：预算是灵魂——没有 ≤1500 token 的硬约束，一页纸三周就长成十页，又回到漂移原点。
