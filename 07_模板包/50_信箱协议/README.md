# 50_信箱协议 — 换工具不换协议：人机之间的唯一显式通道

**问题**：人一关聊天窗，"交代过的事"就没了；今天用 A 工具明天换 B 助手，经验全留在旧会话里带不走。

**方案**：项目里划一个目录当**信箱**——派单、回报、引擎告警全落成文件；任何 agent（本地 CLI、云端助手、常驻巡检）接进来都**只读这个目录**，不加平行通道。

**可复制块**：`信箱_目录壳/`（协议 README＋派单/回报样例＋常驻巡检提示词壳）。

**三条铁律**（协议的灵魂）：
1. **元数据级**——只放编号/标题/一句话卡点/状态/链接；录音、健康数据、代码正文**永不入信箱**（隐私不出机，协议才能公开）；
2. **文件即消息、只追加不覆盖**——重开用 `-r2` 新文件；
3. **一次事件一个发信方**——提醒只从一处发（看板自动化），杜绝双头轰炸。

**效果**：新 agent 上岗零培训（读 README 即会）；跨机迁移＝拷目录；事后审计＝翻文件。
