# 00_居士白话包 —— 不会建、也不想学建的人，从这里进

> 由来：内测启动前三轮干跑（AI 扮演五十岁零基础居士）测出的分界——
> **10~60 六包空壳是给"自建者"的**（看得懂 pathspec、愿意填占位符的人）；
> **居士走不通空壳路线**，只能走"AI 内嵌引导"：全部内容已在指令里，不依赖包内其他文件。
> 决策人裁定：此分界固化入母包，母包随之升 v1.1。

## 这东西怎么用（给带教人，不给居士看）

1. 居士电脑上建一个文件夹，起名叫《我的AI系统》——这是唯一前置动作。
2. 打开 `00_开场指令_AI带你建家底.txt`，**全文复制**，粘给他常用的 AI 对话框（电脑客户端或文件能力强的 AI 最好，网页 AI 配记事本也行）。
3. 之后**居士只说话，不动手**：AI 按指令替他建《我的系统》六个文件、教他派单、替他办第一单。（唯一例外：AI 在他电脑上建不了文件时，会退一步把内容一段段贴出来，请他自己复制去建——只有这一步要他动手，其余照旧。）
4. 指令里已内嵌六份文件内容（开工规矩/当前状态/任务清单/记事本/交代与回话/踩坑记）、三条铁规，以及动手前的那次自查和做不到时的两条退路；**10~60 编号文件夹居士不提不碰**。

## 一单文字任务怎么算办完了（带教判据，四条都要齐）

1. **东西要自己打开看过**。使用者口头说"建好了"不算数；带教的或 AI 得把那六个文件逐个读一遍，名字对得上、内容齐全、该留空的地方标着"回头填"，才算这一条过了。读不到就打明共和使用者说这一条还没验过，别替他签"已完成"。
2. **清单里至少有一件事带着三四条"什么样算做好"**。没有标准的事不该进清单。
3. **当前状态那三行更新过**：最近在办什么、办到哪一步、下一步等什么。
4. **第一单要留下能拿给人看的东西**。比如替他写的通知，要真的落在成品那个子目录里，找得到、打得开。

四条缺一条，就算这单没办完。前三条是账面，第四条是实物；只看账面最容易把"流程走完了"当成"事办成了"。

## 话说一半断了，下次怎么接着办（要带四样，不只一句）

重新开口时，把这四样一起递给 AI，缺一律先补问、不要凭猜往下做：

1. 这一单要办什么；
2. 什么样算做好；
3. 东西放在哪里；
4. 已经做完哪几步，还剩哪几步。

**光靠《当前状态》那三行接不上**。它记的是大进度，不记某一单的具体条件和成品位置。断得久了，再把《任务清单》《记事本》《交代与回话》一起递给 AI——这三份合起来才说清"当初怎么定的、答应对哪几条、东西交给过谁"。

这四样不要求使用者背下来：他会说人话就行，缺哪一样由 AI 主动问。带教的人在旁边，替他补齐即可。

## 与六包空壳的关系

| | 居士白话版（本包） | 六包空壳（10~60） |
|---|---|---|
| 给谁 | 零概念、只要结果的人 | 要自己搭系统、懂工具的人 |
| 形态 | 一段可整份粘贴的指令（自包含） | 待填占位符的骨架文件 |
| 扩展性 | 跑通后按《当前状态》续用；想升级再迁到空壳 | 六包全量：分片/看板/信箱/案例库 |

**两套口径一致**：白话版六文件＝空壳六包的降维投影（状态页→《当前状态》、看板→《任务清单》、分片→《记事本》、信箱→《交代与回话》、案例库→《踩坑记》、规约→《开工规矩》）。居士跑通后若要走进阶，直接换 `10_开工规约/` 起步，概念不断档。

## 红线照旧

不出本机、不建云端账号、AI 不自作主张外发——白话版指令第三行已把"没我点头不许替我决定发给谁"写死。

## 本次改动（2026-10-16，依决策人本轮裁定「四条补充并入白话包」）

本包两件各补了几段：

- **开场指令**：动手建文件前先由 AI 自己核一件事——能不能在使用者电脑上真的把文件建出来，这件事不回头问他；做不到时给了两条退路，能读不能写就把内容一段段贴出来请他自己复制，连读都读不到就停在这一步、明说这条还没验过。拿不准自己能不能建的，按读不到那条办。
- **本说明**：一单文字任务算不算办完的四条判据（账面三条加实物一条），以及话说一半断了、下次接着办要递的四样。
- 「居士只说话，不动手」那句补了唯一例外，免得和上面那条退路两头说两种话。

⚠ **发布用的压缩包还没跟着重打，现在落后这两件。** 重打包和改动登记要动这个目录以外的东西，不该由我们这次擅自办；已经报给项目里负责协调的人，等定由谁来办。**六包空壳（10 到 60 那一层）一字未动。**

**本次只动文字**：未邀真人试用、未做落盘演练；这套静态核对不能当成"旁人可复制"的实证。
