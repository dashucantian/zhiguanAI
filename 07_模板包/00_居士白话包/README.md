# 00_居士白话包 —— 不会建、也不想学建的人，从这里进

> 由来：内测启动前三轮干跑（AI 扮演五十岁零基础居士）测出的分界——
> **10~60 六包空壳是给"自建者"的**（看得懂 pathspec、愿意填占位符的人）；
> **居士走不通空壳路线**，只能走"AI 内嵌引导"：全部内容已在指令里，不依赖包内其他文件。
> 决策人裁定：此分界固化入母包，母包随之升 v1.1。

## 这东西怎么用（给带教人，不给居士看）

1. 居士电脑上建一个文件夹，起名叫《我的AI系统》——这是唯一前置动作。
2. 打开 `00_开场指令_AI带你建家底.txt`，**全文复制**，粘给他常用的 AI 对话框（电脑客户端或文件能力强的 AI 最好，网页 AI 配记事本也行）。
3. 之后**居士只说话，不动手**：AI 按指令替他建《我的系统》六个文件、教他派单、替他办第一单。
4. 指令里已内嵌六份文件内容（开工规矩/当前状态/任务清单/记事本/交代与回话/踩坑记）与三条铁规；**10~60 编号文件夹居士不提不碰**。

## 与六包空壳的关系

| | 居士白话版（本包） | 六包空壳（10~60） |
|---|---|---|
| 给谁 | 零概念、只要结果的人 | 要自己搭系统、懂工具的人 |
| 形态 | 一段可整份粘贴的指令（自包含） | 待填占位符的骨架文件 |
| 扩展性 | 跑通后按《当前状态》续用；想升级再迁到空壳 | 六包全量：分片/看板/信箱/案例库 |

**两套口径一致**：白话版六文件＝空壳六包的降维投影（状态页→《当前状态》、看板→《任务清单》、分片→《记事本》、信箱→《交代与回话》、案例库→《踩坑记》、规约→《开工规矩》）。居士跑通后若要走进阶，直接换 `10_开工规约/` 起步，概念不断档。

## 红线照旧

不出本机、不建云端账号、AI 不自作主张外发——白话版指令第三行已把"没我点头不许替我决定发给谁"写死。
