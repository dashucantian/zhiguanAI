# 登记分片区（一事一文件 · 本目录规则文本，复制到你的项目即用）

> 治的病：决策/订正都记在同一本"大流水账"里——多窗共写必撞行、覆盖、归因不清。
> 法：**一条裁定/一次订正＝一个文件**，文件名即编号，永不共写。

## 编号与命名

- 决策裁定：`D-<MMDD>-<窗号><序号>.md`（例 `D-0927-P3a.md`）；订正勘误：`KZ-<MMDD>-<窗号><序号>.md`。
- 日期＋窗号＋当日字母天然唯一；**取号先查本目录末件**，撞号不回改原稿，由后发现方在索引处留证注记。

## 写作纪律

1. **只追加不改写**：文件落定后若需修订，加"订正注记"段，不抹原文；
2. 首行必须是 `# 编号｜一句话标题`（生成器靠它建索引）；
3. 内禀三段：**裁定/事实 → 缘起（哪个事故/哪次口头）→ 已同步面（哪些文件随之改了）**；
4. 文末记：`记录窗口｜Session｜取号方式`。

## 索引

`00_总索引.md` 为**派生视图，自动生成勿手改**——重跑 `python 生成索引.py` 即修复；它的"未提交"状态不算滞留事故（豁免判据）。

## 与大文件的关系

遗留的《决策日志》《勘误台账》**冻结为历史档**：旧条不回迁，新条一律走分片；大文件仅在既有窗收口时顺带补"分片索引指针"。
