# 60_案例库 — 把踩坑从"聊天记忆"变"随身资产"

**问题**：AI 会话一关，最贵的东西（踩坑根因、被否方案、裁定缘起）就蒸发了；下任窗口重新踩一遍。

**方案**：三类卡＋一个目录纪律——**判语卡**（决策：判决/依据/被否方案/可复用教训）、**踩坑档案**（现象→根因→解法→排查顺序）、**复现路径**（外人照单可重建）。

**可复制块**：`判语卡_空壳.md`＋`踩坑卡_空壳.md`（每条经验一文件，编号 `001_`起）。

**写作纪律四条**：不虚构（可溯源到日志/当事人）；引用必带出处日期；发布前脱敏；**无依据的判断一律标"定性推断"**。

**效果**：规约每条纪律都能指到一张事故卡（纪律不再靠嘴）；新人/新窗两天读完 20 张卡＝老员工；这套卡本身就是对外教学的教材（公案）。
