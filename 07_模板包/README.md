# 个人人机建构模板包 v1（导入即得的六件原子模板）

> 来源：一个「个人人机建构」项目的实战沉淀（2026-09，多窗口并发两个月、五起撞号/搭车事故全部反哺成规）。导出对外版时本行可留可删——除项目名与人名外，全包无任何真实身份数据。
> 总纲一句话：**人掌目标与验收，AI 掌结构与执行；审查权不离人，经验必成文。**
> 本包与各家 AI 工具无关（CLI/IDE/网页窗均可），`AGENTS.md` 为开放格式入口，多数 agent 工具自动识别。

## 这是什么

一个人（不限技术水平）给自己的 AI 工作流装一套**可审计的操作系统**：
任务有编号、状态有一页纸、决策有分片、冲突有裁决规则、经验有案例库——
AI 跑得快，人随时看得懂、接得住、撤得回。

## 半小时起步（先尝甜头，再谈纪律）

1. **五分钟**：复制 `20_状态页/当前状态_空壳.md` → 改三行（当前重心／在途／候裁）。
2. **十分钟**：按 `40_任务看板/README.md` 建一张任务表（飞书多维表格/纸表均可），录入 3 条任务，每条**必填写验收标准**。
3. **十五分钟**：开一扇 AI 窗口，把 `10_开工规约/开工规约_空壳.md` 填好后放进项目根目录（或改名 AGENTS.md 指向它），派最小一单：立旨→AI 执行→你勾验收。
4. 跑通即入门。其余包（分片/信箱/案例库）**用到时再装**，装一包读一包 README。

## 六包清单（按采纳顺序）

| 包 | 解决什么问题 | 一句话效果 |
|---|---|---|
| `10_开工规约/` | AI 每次开工不知道规矩、多窗互踩 | 开工八动作＋并发五纪律，事故率断崖 |
| `20_状态页/` | "我们到哪了"散落在聊天记录里 | 一页真相，谁开窗先读它，冲突以它为准 |
| `30_登记分片/` | 决策/订正记在共享大文件里必撞车 | 一事一文件、日期窗号编号，天然免撞 |
| `40_任务看板/` | 任务提醒靠人肉、承接靠运气 | 状态机＋自动化流程：到点自催、防误捞 |
| `50_信箱协议/` | 换工具/换 agent 经验就丢 | 文件即消息、只放元数据，换脑不换协议 |
| `60_案例库/` | 踩坑随会话关闭而蒸发 | 每条判语一卡：问题+规则+缘起，可检索 |

## 三条红线（可复制性的边界，任何改装都不豁免）

1. 隐私数据（录音／健康／个人档案）**不出本机、不进任何云端上下文**；对外分发一律空壳。
2. AI 不得自行把判断升格为规则——**升格权在人，且可随时撤回**。
3. 一切对外数字与权威声称须独立核校，**单源不采信**。

## 验收本包是否成立（硬判据）

一位项目外的人，**半日内**只凭本包搭起"状态页＋任务看板＋一扇 AI 窗口"并跑通一单闭环。
不过＝回炉改模板，不改判据。反馈通道见 `50_信箱协议/`。
