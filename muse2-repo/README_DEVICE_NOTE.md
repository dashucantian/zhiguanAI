# 目录命名说明（2026-09-05）

本目录（`muse2-repo/muse2-master`）的名称为**历史遗留命名，保留不改**（2026-09-05 宗国法师拍板）。

**重要事实**：本仓库代码实际服务于本项目**在用设备 Muse S（第 3 代）**——
- 蓝牙广播名形如 `MuseS-XXXX`（例：MuseS-E8D8）；
- 依赖的 OpenMuse 库设备类名为 `MuseS`（Muse S Athena）；
- 数据工厂 device_info.json 的 device_model 字段为 `Muse S`。

目录名中的 "muse2" 不代表设备型号，请勿据此推断本项目使用 Muse 2 设备。
市场调研文档中出现的 "Muse 2" 均指市场上真实存在的另一款产品（引用记录，与本设备无关）。
