## 收拢时顺手修掉的三处实测缺陷

1. **`verify_mandala_variants.py` 不带参数默认只跑 3 个变体**（其 :166 写死
   `["s1","v2abyss","v3immersion"]`），而 `vr_mandala.html` 注册表在册 **6 个**
   ⇒ 六变体终审（09-19 裁"丙"）实际漏判两个。现由 `vr_闸总跑.py` **从注册表读键名**
   再传入，不再维护第二份清单（单一正源）。
2. **`verify_guided.py` 硬编码另一棵工作树** `BASE = C:\Users\tiand\OneDrive\zhiguanAI`
   ⇒ 从 D 盘跑验收时截图写进 OneDrive 那棵树。同族坑在 `verify_mandala_s1.py:36`
   注释里早记过并修过，这份漏了；现改为按文件位置反推仓库根。
3. **`validate_console.py` 的 PASS 文案写死"console.html"**：带参数验别的页面时，
   末行仍打印"PASS: console.html 静态校验通过"——按规约 §五.4"验收脚本的判据也要被验收"
   记此一笔；**未改该脚本**（属他线共用件，改法候裁）。

## 跑法

```
python vr_备场.py --start          # 服务没起时：按文档口径拉起（8777/8778）
python vr_gates/vr_闸总跑.py       # 全跑；退出码 0＝全过
python vr_gates/vr_闸总跑.py --only mandala   # 只跑某一项（名字前缀匹配）
```

`交互锚定` 一项会起一次**模拟**会话并保存，随后按法师两次裁过的同口径
（模拟数据／验证自产＝删除并如实报）自清四件套并在日志里报出删了哪些。
