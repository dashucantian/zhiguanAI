# 止观AI 最小可行自进化闭环 · 实施蓝图

> **整理**：AI（本会话）· **日期**：2026-09-19 · **版本**：v1
> ⚠️ **git 状态**：本目录被 `.gitignore:183` 整目录排除，**未入库**。配套脚本 `attribution_v0.py` 同目录。若需纳入版本控制，请法师授权后挪至受控目录。
> **方法论来源**：Astar（arXiv:2608.27287，surrogate RM/三级提示）＋ AgentEvolver（arXiv:2511.10395，自提问/自导航/自归因）。只取方法论，不照搬工程。

---

## 0. 设计原则（先立规矩）

1. **走 Astar 的"元学习"轻路，不走 AgentEvolver 的"训模型"重路**：不训练任何模型、不碰 GPU，让系统从自身会话历史里自动沉淀"哪个参数改动有效"。
2. **核心瓶颈是反馈标签太贵**（D 级判据只有法师体感一句话）→ 整个设计围绕"把人验每一轮降级为机器筛＋人验少数"。
3. **守红线**：大模型不进实时环（判语001）；本闭环是"对配置的元学习"，在实时环之外；AI 无提案自动生效权（改 §四ter 红线）。
4. **挂现有闸门**：自进化循环接到现有阶段闸门之下，不另起炉灶（对齐 S1 收口＝法师真机一句话的闸门文化）。

---

## 1. 闭环五段总览

```
        ┌──────────────────────────────────────────────┐
        │              法师：闸门确认                      │
        │          （只审高价值样本／定期复盘）             │
        └───────────────▲──────────────────────────────┘
                        │ D级标签（稀疏、贵）
   提案 ─▶ 执行测量 ─▶ 代理打分 ─▶ 自归因 ─▶ 经验池更新
 (AI生成)  (跑闭环)   (EEG自动)   (哪步有效)  (越用越强)
   ▲                                              │
   └─────────────── 检索历史经验 ◀────────────────┘
```

| 段 | 对应 AgentEvolver 机制 | 止观AI 极简实现 | 成本 |
|----|------|------|------|
| ① 状态/动作形式化 | — | 可调参数结构化分级（L1/L2/L3） | 一次性 |
| ② 提案 | Self-Questioning | 经验池 RAG → 本地小模型生成候选改动 | 低（本地模型） |
| ③ 执行＋代理标签 | — | 跑闭环，客观 EEG 信号当便宜代理打分 | 中（真机/模拟） |
| ④ 自归因 | Self-Attributing | 规则+统计：哪参数对应深放松 | 低（纯 Python） |
| ⑤ 经验池更新 | Self-Navigating | (状态,提案,结果,归因)四元组可检索 | 低 |

---

## 2. ① 状态与动作形式化（前提）

把可调参数**结构化分级**，让 AI 按"先定方向再落动作"提案，别在裸参数空间乱撞（Astar 三级提示思路）。每个参数带取值范围 → 一个"演化方向"＝`(L1,L2,L3,新值)`，可存储/检索。

| 级 | 层 | 参数示例 |
|----|----|---------|
| L1 | 场域层 | 场景 variant、雾密度、角半径、透过率 |
| L2 | 反馈环层 | τ EMA 窗口、呼吸频率、脑电映射方式 |
| L3 | 音频层 | 节拍频率、音量包络、变化率限幅 |

---

## 3. ② 提案（Self-Questioning 极简版）

**不靠 AI 凭空想**，基于历史经验池做 RAG 式提案：
1. 从经验池检索"相似基线 + 曾失败/成功"的会话
2. 本地小模型据此生成 1~3 个候选改动（例："多次 Alpha 阈值触发后音量突变导致出戏 → 提议 L3 变化率限幅 0.5→0.2"）

---

## 4. ③ 执行＋低成本代理标签（关键！解决瓶颈）

跑闭环会话，采集客观 EEG 指标（Alpha/Theta/Beta 功率、θ/β 比、进入深放松时间）。
- **用客观信号当"便宜代理打分"**（surrogate label，Astar surrogate RM 思想）：机器秒级给每个配置打分
- **只在高价值样本上请法师打 D 级标签**——把标注成本从"每次都要人"降到"大部分机器筛、少数人验"

代理打分依据（参考 `neuradock_simulator.py` 三态定义）：**meditate ≈ Alpha＋Theta 俱高、Beta 低**。

---

## 5. ④ 自归因（Self-Attributing 极简版，不用真 GRPO）

一条会话里"哪个参数改动对应深放松结果？"。MVP **先用规则+统计**做"关键步骤归因器 v0"：
- **组间差异法**：改某参数前后/有该参数 vs 无，对比平均深放松占比（effect size）
- **方向一致性**：应用了某提案的会话，成功率是否高于未应用者
- 输出 `key_step=τ_ema, confidence=0.6` → **先给法师看、人工校准归因器**（数据少时不可直接采信）

> 配套脚本 `attribution_v0.py` 已实现上述两种方法，纯 Python＋numpy，无 GPU。

---

## 6. ⑤ 经验池＋更新（Self-Navigating 极简版）

把 `(状态,提案,结果,归因)` **四元组**存进可检索经验池。每轮提案前检索相似历史 → 提案质量随数据增长自动提升。**这就是"系统随数据越用越强"的闭环**。

---

## 7. 每条记录的数据 schema（先定这个，闭环才能沉淀）

```json
{
  "session_id": "20260919_s001",
  "user_baseline": {"alpha_power": 42.3, "theta_beta_ratio": 1.1},
  "config": {"scene_variant":"s1","fog_density":0.05,"tau_ema":10,
             "breathing_rate":4.5,"alpha_threshold":60,"beat_freq":12,"vol_ramp":0.5},
  "proposal": {"L1":"反馈环层","L2":"音量包络","L3":"变化率限幅0.5→0.2"},
  "outcome": {"deep_state_ratio":0.68,"time_to_enter_min":3.2,"alpha_above_pct":55},
  "proxy_label": 0.72,          // 机器代理打分（自动）
  "human_d_label": null,        // 法师D级标签（稀疏、贵）
  "attribution": {"key_step":"tau_ema","confidence":0.6},
  "success": true               // 归因后标记
}
```

## 8. MVP 边界：该做 / 不该做

**✅ MVP 只做：**
- 先选 **1~2 个参数**（建议 τ + Alpha 阈值），只跑通"提案→执行→代理打分→归因→经验池"一整圈
- 哪怕只有 **5~10 条数据**也验证闭环能转起来
- 用现有本地小模型（千问/deepseek）＋规则统计做归因器 v0

**🚫 MVP 不碰：**
- ❌ GPU / 真 RL 训练（AgentEvolver 那条重路）
- ❌ 改实时反馈环（守判语001）
- ❌ AI 自动生效提案（所有改动经法师闸门确认）

---

## 9. 风险与纪律

| 风险 | 对策 |
|------|------|
| **数据太少**，归因不可靠 | MVP 阶段归因器输出**必须人工校准**，不直接采信 |
| 过拟合到个别会话 | 至少跨 3+ 用户基线验证才认某参数有效 |
| 自动改生产配置 | 提案→人验→生效，三段分离，AI 无"自动生效"权限 |
| 与现有闸门冲突 | 自进化循环挂到现有阶段闸门之下，不另起炉灶 |

---

## 10. 建议启动步骤（4 步跑通第一圈）

1. **建 schema**：把四元组落到一个 JSONL（可复用 `task_records.json` 目录习惯）
2. **补代理打分规则**：用现有 EEG 指标定义"成功"的机器判据（如 deep_state_ratio > 基线＋X%）
3. **手写 5 条历史样本**人工标注，跑通归因器 v0 并让法师校准一次
4. **接本地小模型提案**：经验池 RAG → 生成候选改动；挂到现有阶段闸门下

## 11. 配套脚本说明

`attribution_v0.py` —— 最小可跑的自归因器原型（纯 Python＋numpy，无 GPU）：
- `python attribution_v0.py`：内置合成样本数据，开箱即跑，看输出样例
- `python attribution_v0.py --data sessions.jsonl`：读真实四元组 JSONL
- 实现**代理打分**（基于 alpha/theta/beta）＋ **组间差异法 / 方向一致性法**两种归因
- 输出参数有效性排名 + 置信度（样本少时自动降置信并告警）
