## 方向2·人机协作治理框架/标准

- **AGENTS.md**：24.6k★，已入 Linux 基金会 Agentic AI Foundation，6 万+ 仓库采用，Claude Code 2026-09 原生跟进（**已互证**：36氪、SegmentFault、网易、腾讯云开发者社区等 ≥4 独立源确认 v2.1.277 起支持，原〔单源待校〕撤销）；MIT。**与开工规约同构但只有指令层**——无仲裁／无编号登记／无判语库。**行动：我方规约兼容 AGENTS.md 格式，零成本被各家 CLI 识别。**
- **GitHub Spec Kit**：138.7k★，MIT。constitution→specify→plan→tasks→implement→converge，阶段人审 gate——与我方"立旨→执行→验收"对应度最高，但单窗口单任务。可借 constitution 模板。
- **Anthropic Skills 规范**：177.9k★（规范本身 license 空缺·单源待校）。"目录＋SKILL.md＋渐进加载"——我方案例判语/规约可按此格式封装分发；progressive disclosure 省 token 思路直接可用。
- LangGraph HITL（42.2k★ MIT）：interrupt＋checkpointer＝机器版状态文件；我方 L1 是"人可读写版 checkpointer"，可借其字段语义。
- **总结论（独创性判定）**：指令层已标准化、流程层单任务化、运行时层治理嵌代码——**"规则文件＋多窗口分工＋状态文件仲裁＋编号决策登记＋判语案例库＋审查权不离人"六位一体的个人治理式制度，全网无完整同类品，方法论独创性声明成立**；但须显式对接 AGENTS.md/Spec Kit 同构部分，不重复造轮。

## 方向3·低门槛交互形态

- **模板市场机制（n8n：官网一手 12,573 个模板）**："导入即得完整行为"的原子化打包＋按**场景**（非工具）分类——适配度最高，直接照此设计模板包。
- **规约卡片社区（prompts.chat 171k★/22k fork）**：一条规约＝问题＋可复制文本块＋效果说明的卡片写法。
- 零代码平台（Dify 157k★、扣子教程生态）：**"模板＋10 分钟视频"是普通人唯一验证有效的入口**；教程热恰证明编排门槛仍在——我方"零画布零 JSON"路线避开此坑。
- LM Studio/Ollama：装机 5 分钟但选型劝退——只作隐私敏感用户可选后端。

## 方向4·社区实践与组织形态

- 多 agent 窗口分工叙事已成型（Anthropic 官方初创指南、"一人军队"访谈）——理念背书可直接引用。
- **非软件行业（信仰／非营利）用操作规约管理 AI 的案例基本空白**——教会侧只有伦理政策声明。**止观AI 可成"信仰/非营利场景 AI 规约"首个模板，这是差异化空位。**
- 数字花园运动（learn in public、低承诺渐进贡献）——适合非技术人群心理门槛的传播形态。
- **发布组合建议**：GitHub 匿名化 **Template repo** 为核心分发件（搭 AGENTS.md 中立格式快车）＋数字花园式公开构建日志做传播＋飞书群承载内测反馈沉淀回仓库。仓库是模板不是产品，fork 即自建系统，无需治理投票——最贴"个人主导、可复制"。
