# 监督三查清单 v1（`6213b8d6` 用）

配套：《监督位委任状 v1》。本清单只管"怎么查"，不管"查什么算对"。

## 一、三查逐条做法

| 查 | 做法（命令级） | 通过判据 |
|---|---|---|
| 件在库 | `git ls-files -- <路径>` | 输出非空 |
| 数可复算 | 照来件写的取法跑一遍 | 复算值＝来件值；不等即"未命中" |
| 结论有出处 | 点开 `文件:行号` 或 `git show <号>` | 原句能在该处读到 |

## 二、六类常见"看起来对其实不对"

1. **件在盘不在库**：`??` 状态当"已入库"。
2. **数取自候选而非 staged**：报"20 件"而 `--numstat` 只 19 行。
3. **同一数两个口径**：片数与单数混算。
4. **"未验"被写成"通过"**：取不到数却报 OK。
5. **引用条目不匹配**：拿标题判条文存在性，不去读正文。
6. **链接断**：搬迁后旧链接失效，仍当可回溯。

## 三、抽检频次与范围（起步）

- 范围：**我近三笔提交**＋"已落"的对外件。
- 首轮试跑：见回执函所列三笔。
