## 一、先立边界：借什么、不借什么

判语 013 在前，融贯才成立。本书第二篇的四副透镜是**南传阿毗达摩（微观心路）、中国干支（宏观时空周期）、西方占星（子人格象征）、现代 RDoC/神经科学（实证生理）**。本项目依对齐方案早已裁定：

- **借**其第二篇的**方法论骨架**——透镜＝建模范式，各照一段"存在波长"，每副透镜自带明示盲区（"隐状态自知"），篇末以"立体 CT 扫描"示范多透镜对**同一系统**的互证；
- **不借**其任何一家的**结论与数值**——干支/占星不入数据管线（对齐方案 §七-2，书自裁 ΔR²≈0），"金旺克木""火土刑克"一类语义一律不进界面、不进字段；五相与频带**不预设任何真值映射**（"入定＝Alpha 高"即越层）。

一句话：**本方案重构的是"回顾层怎么组织观察"，不是"系统信什么"。**四透镜在此只作分析区的**组织参照**，与隐显方案 §178-③"书之四透镜收敛法作矩阵组织参照"是同一条既有授权的落地。

## 二、解构：我们的信号族各自照在哪段波长上

把现行采集—保存链的全部分析素材（回顾层可读，纯读）按书的"波长覆盖图"方法排一遍，每段都按书例附**自曝盲区**：

| 波长段 | 透镜类比（仅借结构） | 本项目素材 | 照见什么 | 自曝盲区（界面须显） |
|---|---|---|---|---|
| 毫秒—秒：逐息动力学 | 阿毗达摩（微观生灭） | 波形/频带功率时序、marker 事件微序列、临界慢化指标（ZG-050） | 一坐之内的入流、中断、恢复——"刹那级"事件结构 | 无语义、无体验：知道抖了，不知道为何抖 |
| 坐—日—周：宏观节律趋势 | 干支（**只借"宏观周期波长"这一格位置**） | 跨坐时长/HRV 基线漂移/头动负荷趋势、质检指标、累计练习负荷 | 长程节律与季节窗（睡眠、负荷周期）——趋势不是铁口 | 无微观事件机制；**命理语义零导入**；不作宿命判词（判语 012：痛苦/低谷不解读为相变前兆） |
| 象征—叙事：第一人称报告 | 占星（**只借"叙事象征层波长"格位**） | 自评卡（水面/天色/注意力品质/不适/一句、D1 裁定后加回「这一坐的相」词行）、experience 事件流 | 行者自己看见的那一坐——唯一的第一人称波长 | 巴纳姆与确认偏差风险：只记不评、镜子不评判；不与生理段互改写 |
| 生理—硬件：实证还原 | RDoC/神经科学 | PPG/脉搏、设备与接触状态、干净度、信号链元数据 | 硬件事实在场与数据可信度 | 测不到 D（功夫/阶位），照不到第一人称意义——B≠S |

**解构结论**：现行回顾素材不是缺数据，是**四段波长各说各话**——仪表归仪表、自评归自评、趋势没人铺。这正是书第二篇导引所治的"盲人摸象"病。

## 三、重构：分析区两件套（C1 原问"呈现形态"的回答）

### 3.1 单坐「四透镜 CT 卡」（回顾页分析区新增，纯读）

仿书篇末"对同一灵魂的立体 CT 扫描"：**同一坐，四栏并置，不求统一故事**。

```
┌ 会话 20260925_xx  ·  四透镜 CT ─────────────────────┐
│ [逐息]  第14分钟 marker"睁眼"后 Alpha 跌落 4.2dB，  │
│         90 秒恢复（长于本坐均值）→ 登记慢化假设     │
│ [节律]  本坐时长低于近7日中位；前夜睡眠未登记        │
│ [叙事]  自评：水面=起浪 天色=微明 一句"腿痛顶不住"  │
│ [生理]  接触良好，干净度 92%，头动两起              │
│ ────────────────────────────────────────────       │
│ 收敛点：叙事"起浪" ↔ 逐息跌落 ↔ 生理无异常 → 互证   │
│ 分歧点：节律段无法解释恢复慢 → **登记测量盲区假设**  │
│ （每栏常驻小字：本段看不到什么） 无分数·无排名·不判 │
└────────────────────────────────────────────────────┘
```

- 每栏摘要由既有端点组装：`/api/session/{sid}/manifest`＋`/api/session/{sid}/events`（含 npz `meta.self_report`）；**不新建写路径、不碰入库**；
- "收敛/分歧"两行为本书"大一统觉醒"段的工程化：**四种说法不是四件事，是同一系统在四段波长上的投影**；收敛作印证（判语 011 证据分级），**分歧不标失败，如实登记为"测量盲区假设"**（隐显 §178-② 既有纪律）；
- 五相词只做**注脚层**：页底一行"此坐素材按入/照/运/融/出过程相归档索引"——用《词汇表》自有词，不作评判。

### 3.2 多坐「印证矩阵 v1」（承隐显 §178，四透镜作列分组参照）
