## 二、设计空间与硬约束（所有变体一体遵守）

**色板**：只用 `PALETTE` 五色系（black/goldFar/goldMid/goldNear/center），不得引入新色相——黑金是场域的身份。

**S1 纪律（现阶段全部变体适用）**：
- 完全静态：任何 per-frame 动画一律禁止（空间呼吸是 S2 的事，验收判据＝两帧差 ≤1.0/255）
- 无粒子、无 bloom 后处理、无脑电数据流、无音频
- 金线材质只允许 `LineBasicMaterial`＋AdditiveBlending（jsm 无 lines 模块，粗线不可用）
- 不使用任何外部素材文件（图片/模型/音视频）——一切构图由生成器函数产出

**构图语法（借自 The Journey 的形式取证）**：中心辐射、多层同心、对称、黑底描金、纵深靠"远处沉入黑暗"（雾）而非透视特效。

**修习语义（我们自己的，不可让渡）**：中心光点＝注意力原点（所缘），必须存在且极克制（小球一枚，无光源）；场景是"道场"不是"界面"——不放任何功能性 UI 进 3D 空间。

**性能预算**：draw call ≤ 6；rosePoints 单层 seg ≤ 2160；Pico 为硬约束，无头验收通过≠真机流畅，大参数须真机复核。

## 三、VARIANTS 条目 schema

```
键名: {                       // 小写无连字符，如 v4stupa
  label: 'V4 · 中文题名',      // HUD 显示
  cam: [x,y,z],               // 相机＝立姿眼高 1.6 附近，z 正值在坛后方
  fog: 0.022,                 // 黑雾密度：0.015 通透 ~ 0.06 沉浸
  inner:  {…} | null,         // 近身层（胸腹高，所缘）；null＝不建
  middle: {…} | null,         // 主坛层（直立前方）
  ground: {…} | null,         // 大地层（平铺脚下）
  orb: { r, color:'center', glow, followInner:true | pos:[x,y,z] }
}
// 层 cfg：
{ k:8,          // 玫瑰线参数：k 偶数→2k 瓣（k=4 八叶，k=8 十六叶）
  r:2.6,        // 玫瑰线半径（米）
  seg:1440,     // 采样段数（越大越圆滑）
  rings:[2.8,1.9,0.9],        // 同心环半径列表
  spokes:[2.8,3.35,32],       // 辐条 [内径,外径,条数]（可省）
  color:'goldMid',            // PALETTE 键名
  op:0.8,                   // 不透明度 0~1
  pos:[x,y,z] }               // 层位置（middle/inner 用）；ground 用 y:{高度}
```

## 四、新变体制作流程（五步）

1. **写设计意图**（一句话）：这个构图让修习者感到什么？（例："被坛城包裹"vs"远望坛城"vs"面对一具大坛"）——先有意图后有参数。
2. **填 VARIANTS 条目**：按 §三 schema 写一段条目，三层几何＋相机＋雾＋光点。参考已收口三例的差异化维度：s1＝三层俱全纵深；v2abyss＝大地主角化；v3immersion＝单层大坛浓雾。
3. **交付整合**（见 §五分工）：由 W1 合入 `vr_mandala.html` 注册表（**本地模型不直接改此文件**，单一写者纪律）。
4. **跑验收**：`python verify_mandala_variants.py <新键名>`；判据不过→回第 2 步调参（金色占比>15%＝太满刺眼，<0.3%＝太虚；黑底<85%＝雾太稀或线太多）。
5. **进对比页**：截图并入 compare.html，交法师 Pico 真机逐变体体验，**最终取舍只有法师能定**（D 级判据："我进入了一个地方"）。

## 五、分工与协同模式

| 角色 | 职责 |
|---|---|
| **本地模型**（LM Studio：27B / 3.6 / Ornith 任一） | 出**设计**：按 §二约束＋§三 schema 产出新变体条目＋一句话意图＋预期像素表现。每次 1~3 个变体，键名自定不与现有冲突 |
| **千问 W1**（本窗口） | 工程整合：合入注册表、跑无头验收、像素判据把关、git 提交、维护 SOP 与对比页；对本地模型产出做**约束合规审查**（越界即退回并说明哪条） |
| **法师** | 任务发起（"让本地模型做 N 个 XX 感觉的变体"）、真机体感终审、取舍定夺 |

**模式 A（推荐起步）**：法师在 LM Studio 聊天窗粘贴 §六任务书→模型输出条目→法师整段转给 W1（或直接告诉 W1 去 `localhost:1234` 拉取）→W1 整合验收。
**模式 B（全自动）**：LM Studio 开本地服务器（Developer 页 Start Server，默认 `http://localhost:1234`）后，W1 可直接经 API 向本地模型下发任务书、回收条目、批量整合——**当前实测服务 OFF，启用后 W1 即可演示此链路**。

## 六、任务书模板（复制给本地模型）

```
你是 VR 禅修场景的构图设计师。为"止观·曼荼罗场域"设计 2 个新构图变体。

技术背景：场景由 Three.js 程序化生成，全部金线由玫瑰线 r=|cos(kθ)|·R、
同心环、辐条构成；黑底＋黑雾（远处沉入黑暗）；不用任何图片素材。

每个变体输出一个条目，格式严格如下（JS 对象字面量）：
键名: { label:'V? · 题名', cam:[0,1.6,z], fog:0.0xx,
  inner:{k,r,seg,rings:[],spokes:[ri,ro,n],color,op,pos:[x,y,z]}|null,
  middle:{…}|null, ground:{…}|null,
  orb:{r,color:'center',glow,followInner:true|pos:[x,y,z]} }

硬约束：color 只能取 goldNear(#f0d2b4 暖金)/goldMid(#d4af5a)/goldFar(#6b5630 暗金)；
k∈{4,8}；seg≤2160；op∈[0.3,0.95]；fog∈[0.015,0.06]；cam.y≈1.6；
至少一个层非 null；完全静态（不做动画）；中心光点必须存在。
构图语法：中心辐射、多层同心、对称、黑底描金。
语义：这是禅修道场不是界面——构图要引导注意力（收拢/放开/深入），不是炫技。

已收口三例供差异化参照（勿雷同）：
s1 三层纵深（近身八叶所缘+前方十六叶主坛+脚下大地坛）
v2abyss 大地深渊（巨大暖金莲瓣铺满前景，小主坛悬于 z=-11 地平线）
v3immersion 单坛沉浸（一具 z=-3.4 大十六叶坛占满视野，fog 0.055）

请设计意图先行：每个变体先一句话说明"让修习者感到什么"，再给参数。
输出 2 个变体，键名 v4__ / v5__。
```

## 八、红线

1. 本地模型**不直接编辑** `vr_mandala.html`（单一写者/并发纪律）；只产出条目文本。
2. 不引入外部素材（版权红线＋程序化是本项目的路线，v0.3 裁定④）。
3. 不碰 S1 纪律（动效/粒子/数据流一律 S2+ 由 W1 施工）。
4. 变体不删除不覆盖既有条目；注册表只增不改（s1 基准参数是验收回归锚）。
5. 涉义理的构图语义（如佛形、文字）须法师勘定后方可入表。
