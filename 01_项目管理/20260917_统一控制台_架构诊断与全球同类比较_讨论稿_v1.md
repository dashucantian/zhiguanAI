# 止观AI 统一控制台 · 架构诊断与全球同类比较（讨论稿 v1）

## 〇、给法师的十行结论

1. **控制台本身是"能用的"，而且有几处做得比同类开源项目好**（零构建单页、质量先行、SSE 广播注册表、数据诚实性 L1、VR 单数据源）。问题不在"写得糙"，而在**边界与真相**。
2. **"统一"名实不符**：34 个后端接口里，EEG 采集/实验占绝大多数，**AI／知识库／项目驾驶舱接口为零**（全文件检索 qwen/llm/agent 零命中）。《数字大脑 V1.0》六层、《三年战略》八项工程第 8 项要的"项目驾驶舱"，今天是一份 09-01 就停更的 markdown。
3. **一处动摇科学地基的实测缺陷**：入库脚本把滤波前原始列丢掉了，而元数据却写着"pre_filter_available: True"。**Zen-EEG/02_raw 里名为 `eeg_raw.npz` 的文件，其实只有 1–40Hz 因果带通后的数据，且不可逆**——《三年战略》关口 A「任意样本可完整追溯」当前不成立。（§二 S1，修复约 1 行代码）
4. **约 660 MB、79 个会话从未入库**，且躺在 git 工作树内的 `report/` 目录（红线7 的历史事故就发生在这个目录）；真正的数据工厂在 OneDrive 里，而 OneDrive 客户端正在运行、那份副本内含 564 个机密学员文件（779.5 MB）与 101 个原始脑电 npz（767.6 MB）。（§二 S2／D2）
5. **同一件事写了两三遍**：适配器、模拟源、会话对象、事件流、入库卡、tick 渲染，全部各有一份"平行路径"。代价已经付过一次——09-13 的推流故障必须修两遍，而**前端第二个流的 onerror 至今仍是空函数**。
6. **状态有四个互不相通的定义**（报告分类器／VR 的 H-A′ 滚动分位／闭环奖励逻辑／五相 zx_phase）。操作者看到的数与修习者体验到的数不是同一个数，复盘时无法对齐。
7. **全球同类调查的结论很清楚**：消费级（Muse/Mendi/Sens.ai/BrainCo…）走"设备＋订阅＋封闭生态"，且**证据极薄**——Kimura 2024：神经反馈总体 SMD 0.27，**但对假反馈对照的 8 项 RCT 无显著合并效应**；Muse 的两项产品级 RCT 一阳（次要终点全为零）一阴；BrainCo／Neurable／Mendi 的产品级证据几乎为零。开源侧（BrainFlow/LSL/MNE/OpenViBE/BCI2000）走"分层核心＋插件＋自描述数据"，**活得久的都是"配置冻结＋数据自描述＋有机构锚"**。
8. **"禅师标注的深定数据集"须分两半看，且已更正三次**：**数据这一半已被三个学术组占据**（van Vugt／Kaplan／HKU，均未公开）——**宣称"首次做禅僧脑电"会一查即破**；**最大的冥想脑电语料其实已存在**（Interaxon 自家 Muse Meditation Dataset **n=4,191**，2024 年发在 *Imaging Neuroscience*），但它是**消费级用户库、不是禅师标注**；而**"原始＋禅师标注＋开放许可"那一格确实是零**（DataCite 检索 jhana 数据集 **0**；中国科学数据银行冥想 EEG **0**；唯一开放的禅师数据集**只有特征没有原始**）。**这一格是本项目真正的护城河，而它最容易被自己浪费掉**（因为 §三 的缺口全在"数据之后"）。
9. **改进不必重构**。研究给出的最小有效动作只有四条：`APIRouter` 拆路由＋类型化配置、设备能力描述符＋合成/回放源、一条版本化的事件/溯源记录、一个 CI 闸门。按本项目的体量，**P0+P1 约 3–5 人日即可把"地基"补回**。
   ⚠️ **另有一项现实风险值得提前看**：**本项目在用的 Muse S 已停产**（目录仅剩 Muse 2 与 Muse S Athena）；且 **Berger 效应（α 反应性）在 Muse 2 上约为研究级设备的一半（3.779 vs 7.962）**——而闭环奖励逻辑正建立在 α 反应性之上。这两条会把"第三阶段再决定硬件"提前（见 §八-11）。
10. **另有两项须法师核实的边界事项**（本 AI 不擅断）：①OneDrive 是否确在同步 Zen-EEG（涉硬约束①"绝不出网"）；②本次调查中本 AI 有两次触及 L3 边界（详见附录 C），已如实登记待处。

### 1.2 数据流（实测）

```
Muse S（BLE）─┬─ bleak（BleDirectReceiver）──┐
              ├─ BLED112（BleBgapiReceiver）─┤
              ├─ TCP（NeuraDock TcpReceiver）┤── buffer.add_eeg()
              ├─ 模拟（MonitorSimulator）────┤   去直流 EMA + 1–40Hz 因果带通
              └─ 回放（ReplaySource）────────┘   （滤波在接收器内，先滤波后入缓冲）
                          │
                    DataBuffer（muse_local_server.py）
                     ├─ compute_band_power()  ← 内部 2.0s 节流（:805）
                     ├─ compute_vitals()      ← 每 12 tick
                     └─ save_bin() → report/local_YYYYMMDD_HHMMSS.npz + .report.html
                          │                    （含 eeg_pre_filter 仅真机 17/97 会话）
                    ▼
   MonitorSession ── EventBroadcaster ──┬─ /api/monitor/stream（SSE，4Hz）
   （0.25s tick）                       └─ VRSession → /ws/vr（WebSocket）
                    │
                    └─ ClosedLoopController（声音决策，按 bands 签名去重）
                          │
   ExperimentSession ── EventBroadcaster ──┬─ /api/experiment/stream（SSE，0.5Hz）
   （run_closed_loop）                     └─ VRSession → /ws/vr
                          │
                          ▼
   console.html 5 页签 ←→ 34 个 HTTP 接口
                          │
                          ▼（点"一键入库" 或 复制命令手跑）
   ingest_session.py ──→ C:\Users\tiand\OneDrive\Zen-EEG
                          02_raw/<ZEN-ID>/{eeg_raw.npz, report.html, device_info.json, session_note.txt}
                          03_quality_control/…, 01_registry/session_registry.csv（6 列）
```

**两条实测事实**（后文反复引用）：

- **F1｜滤波后置**：缓冲里的 `eeg` 已是"去直流＋1–40Hz 因果滤波"之后的数据（`ble_receiver.py:284–319`，20260908 讨论稿 §八 已实测确认），`eeg_pre_filter` 是 L1 补救列。
- **F2｜节流隐式**：`MonitorSession` 每 0.25s 调一次 `compute_band_power()`，而该函数内部 `if time.time()-last_bp_time < 2.0: return`（`muse_local_server.py:805`）→ **4Hz 的传输承载 0.5Hz 的数据**；闭环决策器因此必须在 `console_server.py:754` 用 bands 签名去重，否则平滑会快 8 倍。控制回路的真实速率由另一个模块的早退决定，**无接口声明、无测试**。

### 1.3 五页签能力矩阵（实测）

| 页签 | 做的事 | 不做的事（与战略要求对照） |
|---|---|---|
| 采集工作台（`monitor`） | 会话登记、4 种数据源、纯监测／闭环模式下拉、波形／频段／PSD／PPG／IMU、质量门控、稳定性条、保存、质检、一键入库 | 无采集协议内建（5 分钟基线＋45–60 分钟正式段未结构化）、无同意书版本绑定、无测试后表单强制 |
| 配置管理（`config`） | JSON 编辑／校验／保存／备份／快照列表 | 无配置版本号自动写入数据元（`signal_chain` 目前靠代码常量，非配置驱动） |
| 历史数据（`history`） | 报告表、场景筛选、实验日志组 | 只读浏览；无趋势、无个体纵向对比、无批次质量汇总 |

**结论**：控制台 = **采集工作台 + 三个只读附属页**。它统一了"采集"，没有统一"工厂"，更没有"驾驶舱"。

## 二、架构诊断：19 项结构性问题

> 分级口径：**S** 动摇科学地基或数据资产；**A** 架构性（会持续产生代价）；**B** 工程性（可靠性/安全）；**C** 体验与卫生。每条给"证据 → 代价 → 修复成本"。

### S 级（4 项）

#### S1｜归档数据丢失滤波前原始列，而元数据声称"可用" —— 唯一一条动摇科学地基的实测缺陷

**证据链（三层，全部实测）**
1. **落盘**：`ingest_session.py:212` — `np.savez(dest/"eeg_raw.npz", eeg=eeg, timestamps=timestamps, meta=meta)` —— **只写 `eeg`，未写 `eeg_pre_filter`**。
2. **归档实物**：`Zen-EEG/02_raw/ZEN-20260911-P001-S13/eeg_raw.npz` 实测 `keys=['eeg','timestamps','meta']`，**无 `eeg_pre_filter`**。
3. **元数据自述**：同一文件的 `meta.signal_chain` 写着
   `{'chain_tag':'v12_bp_1_40','highpass_hz':1.0,'lowpass_hz':40.0,'filter':'butter2_causal','zero_phase':False,'dc_removal':'ema_alpha_0_008','notch_hz':None,'pre_filter_available':True}`

**代价**
- 文件名叫 `eeg_raw.npz`、`meta` 说"滤波前原始值可用"，**实际都不成立**——比 20260908 讨论稿 §八 记录的原缺陷更严重：那时只是"名实不符"，现在变成了**元数据主动声明一个不存在的副本**。
- 因果滤波（单向）**不可逆**：`<1Hz` 次慢波已永久丢失；`>40Hz` 与任何毫秒级 ERP/时序分析在本批数据上不可用。将来若要研究"入定前后的慢波/极慢波"，**原始仓库里根本没有那份数据**。
- 《三年战略》第一年第一项资产"原始数据只读仓库"、关口 A「任意抽取一个样本，都能完整追溯其同意书版本、设备、基线、正式数据、环境记录、质量报告、清洗版本和导师标注」——**当前不成立**。
- 存量口径还不一致：`S02–S06/S08/S12` 的 `meta` **完全没有 `signal_chain` 字段**（L2 存量标注未落地），同一仓库里两种口径并存。

**修复成本**：`ingest_session.py` 增加 3 行（`if "eeg_pre_filter" in d.files: np.savez(..., eeg_pre_filter=...)`）＋ 存量注册 `chain_tag`；回归用一个既有 npz 跑一次断言 `keys == ['eeg','eeg_pre_filter','timestamps','meta']`。**这是全部 19 项里性价比最高的一处。**

#### S2｜约 660 MB / 79 个会话从未入库，且躺在 git 工作树内

**实测**：本地暂存区 `muse2-repo/muse2-master/report/` —— 97 个 npz、**804.7 MB**（其中真机 `device=muse` 18 个、374.2 MB）；`Zen-EEG/02_raw` —— 33 文件 / 144.2 MB；登记表 13 行。→ **约 79 个会话、660 MB 从未进入数据工厂**，含真机长会话（`local_20260911_005621.npz` 4,294 秒 / 79.1 MB）。
**代价**：①这些文件既非"原始仓库"（在 git 工作树内）、也无版本控制保护（`*.npz` 被 `.gitignore` 排除）、也不是备份对象；②红线7 的历史事故（09-09 误删法师 2.7 小时真机会话）**就发生在同一个目录**；③报告 HTML 与 npz 混放（98 + 97）。
**修复成本**：一次性归集脚本（显式文件名白名单，遵红线7）＋ 登记表补录；半天。

#### S3｜工程可复现性缺口：无环境锁、回归防线不在版本控制内、无 CI

**实测**：①仓库**无 `requirements.txt`／`pyproject.toml`**（本机实际装：fastapi 0.141.1 / uvicorn 0.52.4 / numpy 2.5.2 / scipy 1.18.1 / bleak 3.0.2 / websockets 17.1 / cryptography 50.0.1 / mne 1.12.1）；②`output/`（864 文件 / 51 MB，含 17 个 `verify_*.py` 与全部实测证据）与 `experiments/`（177 文件）被 `.gitignore` **整体排除**；③`test_console_e2e.py`、`compare_configs.py`、`openloop_experiment.py`、`verify_recording.py`、`console_profiles.json` 均未入库；④无 `.github/`，无 CI；⑤`__pycache__` 中同时存在 `cpython-312` 与 `cpython-314` 痕迹 → 环境漂移已实际发生。
**代价**：《三年战略》关口 B「相同数据、相同版本应得到相同输出」在第二台机器上**无法验证**；换机/协作者接手时，"防线"随 output/ 一起消失。
**修复成本**：`requirements.txt`（10 分钟）＋ 把 `verify_*` 与 `selftest` 收进 `tests/`（半天）＋ 一个本地 CI 脚本或 GitHub Actions（半天）。

#### S4｜"大脑状态"标签缺少解释边界与弃权路径（红线9／战略边界相关，须法师裁定用词）

**实测**：`console.html:336/408` 把 `report_generator.classify_state` 的输出直接显示为「**大脑状态**」，取值含「**冥想 Meditative**」（`muse_local_server.py:885` 的中英对照表）；前端取空格前中文部分（`console.html:1003`）。
**风险**：①这是**用 4 通道干电极、2 秒 epoch 的频段比值给"是否在冥想"下判断**——正是《三年战略》§七 明列的"不把某个频段变化直接等同于禅修境界"的边界；②标签**无置信度、无质量同轴显示、无"不可判定"输出**，与关口 D「模型可弃权」相反；③报告 HTML 已固化该措辞，属"已发生的一次解释"。
**注**：控制台确实做了质量门控横幅（`updateQualityBanner`），这是加分项；问题是**门控与状态标签不同轴**。
**④ 尤其要注意：它与本项目自己已立的判语冲突**——**判语 009（2026-09-09 已定）**把反馈闭环定位为"**可观测、可复盘的大脑状态镜子**"，并明确"**判定权在实修证量**，不以设备指标或论文切片为标准"。「大脑状态：冥想」是一个**判定**，不是照见。
**修复成本**：改词（如"信号特征分类（未经校准）"）＋ 增加"不可判定"档 ＋ 与质量门控联动；**用词须法师定**，属§四 判定权范围。

### 诊断补充 A′：三项"已立德、未落地"——决策都在，载体都不在

> 这是本报告**最需要更正第一印象的一节**：项目在**科学认识论上比同类更清醒**（判语 009／011 已经把消费级神经反馈的负向证据吸收进决策），**但这些决策在控制台与数据侧一个都没有载体**。问题不是"不知道该怎么做"，而是"知道却没有地方做"。

| 已立的决策 | 出处 | 需要的载体 | 现状 |

**留存下来的产品的五条设计原理**（这是"设计原理"一栏的真正答案）

1. **一个数、一个隐喻、亚秒级回路**：Muse 用音景（"安定→鸟鸣，散乱→风雨"），Sens.ai 标称 <200 ms 反馈延迟。**没有一个活下来的产品让用户去读原始频谱。**
2. **反馈必须是"外围、非阻断"的**：Narbis 的镜片变暗但"不会暗到打断阅读/写作业"——反馈**叠在活动之上**，而不是与活动竞争；Muse Premium 的 "External Audio" 让你在 Spotify/Calm 之上听反馈。
3. **硬件是订阅漏斗，不是产品本身**：Muse 卖内容与 AI 教练，**并且允许你完全不戴头环就用 App 冥想**；Sens.ai 把首期会员打进 $1,250。
4. **消费者拿不到原始数据；数据访问权＝护城河**：所有 C 端赢家都藏起原始 EEG，开放只给研究者（Muse 研究工具、Mendi 的研究申请、BrainBit 的免费 SDK）。
5. **"健康/wellness"措辞是监管盔甲**：Narbis 写"wellness tools… not intended to diagnose, treat, cure"；Emotiv 写"不作为 MDR 2017/745 定义的医疗器械销售"。
> **反直觉的一条**：**没有证据表明"游戏化"或"假反馈对照"能提升留存**——与留存相关的设计是"低摩擦＋付费内容库"。

**科学证据（对本文最重要的一段）**

- **消费级设备＋正念冥想：Treves et al. 2025, *JMIR* 元分析**（16 项 RCT，N=763，**11/16 用 Muse**）：心理困扰 **g = −0.16（p=.03）**；认知 **g=0.07（p=.48）**；正念 **g=0.02（p=.83）**；生理 **g=0.11（p=.57）**。原文结论：**"声称消费级设备能让参与者调节自己的大脑、加深其禅修，目前不被证据支持"**，且效应可能只是 **"神经暗示（neurosuggestion）"**。
- **ADHD 领域已整体转负**：Westwood 2025 *JAMA Psychiatry*（38 RCT，n=2,472）：可能盲评下总症状 **SMD 0.04（−0.10~0.18）**；标准方案 **0.21（0.02~0.40）**；唯一显著的神经心理指标是加工速度 0.35。Arnold 2021 双盲假反馈 RCT（N=144）：**两组都改善 d=1.5，但真反馈并不更优（d=0.01, p=.965）**。
- **失眠**：Schabus 2017 *Brain* 双盲安慰剂对照——**神经反馈不优于假反馈**，"不能推荐为 CBT-I 的替代"。
- **设备效度**：Ratti 2017 *Front Hum Neurosci*——Muse 的**睁眼/闭眼重测 PSD 比值 1.125–1.225（两台"医疗级"设备为 0.975–1.025），且 Visit 1 频谱中观察不到 α 峰**（该文未报相关系数；⚠️ 对照的两台"医疗级"设备是作者自家产品）；消费级系统最易受眨眼/肌电伪迹影响。
- **批评方**：Thibault & Raz 2017 *Am Psychol*——驱动临床改善的"更像是心理社会参数（动机、期望），而非神经生物学基质"。学界的回应是 **CRED-nf 检查表**（Ros et al. 2020 *Brain*，**由批评方与被批评方共同署名**）。
- **fNIRS 侧**：Mendi 最常被引的 Boere 2024 只验证**传感器**，且其头条结果**与作者假设相反**；营销常引的"22 项研究证明 fNIRS 神经反馈改善抑制控制"实为**任务诱发前额激活的观察性综述**，**该主张不成立**。

- **Muse 是唯一真正的生态**：**SDK 曾被撤回**（GitHub `sccn/labstreaminglayer#30`，2019-07-18 开、2019-12-09 关、39 条评论；Interaxon 原话："我们不再提供 SDK……他们所需的技术支持量我们难以持续承担……"；其后遗症 issue 一直拖到 2024-10 仍未关），**2026 年又恢复**（测试/原型许可＋商用许可＋研究通道；**但两个在营页面自相矛盾**）。
- **第三方已在其上做生意，而且不止一家**：官方 SDK 伙伴页列出 **Myndlift（临床向神经反馈，自称"数千名临床医生与个人在用"）**、**Mind Monitor**（作者 James Clutterbuck，**$14.99 一次性买断、无订阅**，v2.4.5／2026-09-13）、Semse Aware、OptiBrain、OptiTrain；消费向还有 **Narbis**（$270 眼镜＋$10/月，为 Muse 2/S 集成设计，其临床版也支持 Muse 硬件）。→ **Muse 是唯一一个"别人能在上面建持久商业产品"的消费级脑电平台**（代价：官方社区 `community.choosemuse.com` **302 跳转到 reddit.com/r/museheadband**——它关掉了自己的论坛）。
- **⚠️ 一条与本项目直接相关的事实：Muse S 与 Muse Original 已不在售**（站点目录仅剩 Muse 2 与 Muse S Athena 两款；`muse-s` 商品页消失，只剩 $39.99 的保护壳）。**本项目在用的设备型号（Muse S 第 3 代）已停产**——这属于"硬件连续性"风险，见 §5.5 与 §八-11。
- **另一条会限制用法的硬件事实**：Mind Monitor 的 FAQ 原文——**"Interaxon 只允许同一时间一个 App 连接 Muse"**。本项目现在的拓扑（PC 采集 → WebSocket → 头显）不受影响，但将来若想"控制台与手机 App 同时连"，这条路是被厂商协议堵死的。
- **研究通道是最硬的资产**：ClinicalTrials.gov 上 Interaxon 作为申办方/器械方出现在 **≥6 项**研究中。
- **可量化的收益**：它成了消费级神经反馈科学的默认仪器（Treves 元分析里 11/16）——**也成了那门科学最终没能验证的那个产品**。
- **Emotiv** 是最开放的商业厂商，回报是十年第三方 BCI 项目；**Mendi／Sens.ai／BrainCo／Neurable／Hapbee／Narbis 都是封闭孤岛**（无公开 API、无开放数据、无第三方应用）。
- **对整个品类最锋利的一条生态批评**：*PLoS One* 2024 范围综述（**916 项**使用消费级 EEG 的研究；Emotiv 最多，其后 NeuroSky MindWave、OpenBCI、Interaxon Muse）发现**"设备验证"是倒数第二常见的用途类别**——**开放/廉价硬件被大量当作仪器使用，却几乎从不被检验**。→ 这句话既是对同类的批评，也应当是本项目的自我要求。
- **生态的最终定性（本节结论）**：**Muse 的生态是"开发者/伙伴生态"，不是"用户社群"。** 依据：它宣传"**50 万+ 人在用**"，而其官方社区入口（**它自己不托管**，`community.choosemuse.com` 302 跳转到 Reddit）订阅数 **642（2025-02-15 存档值，已约 19 个月未更新）**——**约为宣称用户数的 0.13%**（约 1/750）。两种读法都可成立：要么真实用户量远小于宣称，要么**消费级脑电冥想即便在品类第一名也几乎没有持久社群**。**而这正好定义了我们该学什么**：Muse 真正的资产是 **SDK＋伙伴（Myndlift／Narbis／Mind Monitor）＋RRID＋n=4,191 数据集**这一套"研究者与开发者基础设施"，不是"社区运营"。

**六类失败模式**

1. **过度宣称 → 引用漂白**：把无关文献与自报 App 内数据（"8 周后专注 +42%"）当证据陈列。
2. **安慰剂／"神经暗示"**：品类最大的威胁，也是绝大多数产品**根本不去检验**的那一项。
3. **信号质量**：多毛部位干电极；Ratti 2017 的 Muse 全频段虚高与最差重测信度。
4. **模态混淆**：Hapbee（磁场）、Core（触觉＋心率）、Reflect（EDA＋ECG）、Thync（刺激）被普遍误当作"神经反馈"。
5. **流失与"8 周悬崖"**：人人引用 8 周方案，**没有一家公布留存率**。
6. **监管与伦理风险**：BrainCo 是最尖锐的案例（研究机构指其 2019–20 年哈佛商标/姓名问题、创始人不实头衔、与国有资本关联、EEG 上云、校园部署引发 2020 年 Big Brother Award）；但其 **专注欣仍是中国的 II 类医疗器械**（ADHD 辅助训练）——**西方 C 端厂商靠"wellness"措辞绕开的那条路，它走了另一条**。

**平台给出的四条可移植结论**

1. **活得久的四个共同点**：①**冻结的文本配置＋带迁移的数据 schema**（BCI2000 `.prm`、FieldTrip `ft_checkconfig` 会**校验并升级**旧配置）；②**描述符/约定式注册**（OpenViBE descriptor、EEGLAB 文件名约定、BCI2000 `PipeDefinition`）；③**自描述记录**（BCI2000 把完整状态向量逐样本写进 `.dat`；EEGLAB 用可执行的 `history` 脚本）；④**有机构锚**（INRIA／UCSD／Radboud／UC Davis／Wadsworth）。
2. **死掉的不是因为架构丑**：BCILAB 失去主推人＋测试放在**另一个仓**里、无入库闸门；Neuromore 的许可是"不得产生商业价值"＋**强制闭源后端**，第三方结构上无法贡献（节点图不是问题）；bci.js／muse-js／Timeflux 都是**单人维护、无机构锚**。**mne-realtime 是健康样本**：把实时关切拆成独立包，再被 MNE-LSL 有意取代。
3. **LSL 已是事实标准**：liblsl 暴露**稳定 C ABI**（十年前的二进制仍可用）；时钟每 5 秒重同步，**NTP 式滤波，十次包交换／200 ms，保留最低 RTT 的偏移**，官方称多数网络硬件下残差"远小于 1 ms"。**但它无法知道设备端延迟**，且**不是面向互联网的传输**。
4. **⚠️ 延迟数字不可引用**：本次调查**未能取得**任何可信的"LSL vs MQTT/gRPC/WebSocket/ZeroMQ 对比基准"，也**未能取得**"神经反馈端到端延迟预算（<100 ms 之类）"的原始出处。**项目既有调研中如有此类数字，应复核来源**（本文不引用）。

### 4.3 "统一控制台"这一工程范式：五个契约

调查了六个成熟系统（Home Assistant／Node-RED／Grafana／LSL＋LabRecorder／BrainFlow／OpenBCI GUI）与三个科学装置控制栈（EPICS／Tango／Bluesky＋ophyd）。**结论：所谓"统一控制台"不是一种界面，而是五份契约。**

| 系统 | 状态模型 | 扩展机制 | UI 与核心的分工 | 配置的版本化 |
|---|---|---|---|---|
| **Home Assistant** | 事件总线＋状态机（`state_changed`）＋服务注册表＋1 Hz 定时器；Area→Device→Entity 层级 | 集成＝Python 包＋`manifest.json`（域、版本、依赖、**钉住的 pip 依赖**、发现键、codeowners） | **前端是独立产品/仓库**，移动优先 PWA | UI 驱动的 **config entry**，有显式生命周期（loaded／setup error／setup retry／migration error／failed unload），**版本升级必须写 `async_migrate_entry`**；注册表**只认不可变 unique_id（序列号/MAC），明确不接受 IP/主机名** |
| **Node-RED** | 消息＝普通 JS 对象（`payload`、`_msgid`） | 节点＝npm 模块：`RED.nodes.registerType`＋`this.on('input')`＋`this.on('close')`；编辑器半边在 `.html` | 编辑器是运行时提供的独立应用，**palette 即插件面** | 流程 JSON 导入导出；**无逐节点 schema 迁移**，节点须"对消息属性宽容" |
| **Grafana** | **Data frame**＝通用列式契约；仪表盘＝JSON 文档 | 三类插件（data source／panel／app）；`plugin.json`；**签名**才能进目录 | 面板/数据源是核心查询渲染引擎之上的纯插件 | **Provisioning-as-code**：`provisioning/` 下 YAML＋环境变量替换＋每数据源 `version`＋`prune: true`；**已 provision 的仪表盘不能从 UI 存回**，文件永远覆盖数据库 |
| **LSL／LabRecorder** | **流＝样本＋XML 元数据**：`name`／`type`（**首选检索键**）／`channel_count`／`nominal_srate`（或 `IRREGULAR_RATE`）／`channel_format`／`source_id`（唯一→崩溃自动恢复）／`uid`／`session_id`／`hostname`；扩展 `desc` 携带通道标签/单位/放大设置 | 每个设备一个 `App-*` 仓库；Resolver 按**内容**发现，不需要 zeroconf | **没有单体 GUI**：Outlet/Inlet 库＋录制器＋各自独立的查看器 | LabRecorder 配置文件设定 Study Root、**BIDS 文件名模板**（`%p/%n/%b/%s/%a/%m`）、**必需流清单**（缺流显红）＋TCP 远程控制 API |
| **BrainFlow** | 一个 `BoardShim` API＋规范化二维数组；`get_board_info`、EEG 通道、采样率、marker；`DataFilter`／`MLModel` | 加板卡有文档流程；**Playback File／Streaming／Synthetic 三种 dummy 板＋模拟器供 CI** | 纯库无 UI；~30 个板卡族在一个接口后 | 每板卡版本化 preset；无 UI provisioning |
| **OpenBCI GUI** | 控件读共享全局结构；每个面板从下拉选一个控件 | **fork＋PR**：加 `W_*.pde` 并在 `widgetManager.pde` 注册、重命名全局下拉回调 | GUI 即控制台；导出 CSV/BDF+ 与 MATLAB | 按数据模式存/取 JSON，但**每个控件要自己在 `save()`/`load()` 里手工注册下拉** |
| **EPICS** | 分布式发布订阅：IOC 做真实 I/O，把 Process Variable 经 Channel Access／pvAccess 发布，客户端订阅 | IOC 里的设备支持＋记录类型；模块/扩展 | **硬分**：IOC/设备层 ├ 操作界面 ├ 归档与高层服务 | IOC 数据库是配置管理下的文件 |
| **Tango Controls** | Device/DeviceClass/DeviceServer；设备暴露 **State**（ON/OFF/FAULT/ALARM/UNKNOWN）、Commands、类型化 **Attributes**、**Properties** | 写设备服务器类（C++/Java/Python），POGO 生成骨架，Astor 管进程 | 客户端分离：Taurus、ATKPanel、**Taranta(web)**、REST、MATLAB/LabVIEW | **TangoDB 即配置与名字服务**：名字查找让"设备换机器"对客户端不可见；属性键值存储**带历史（默认深度 10）**；HDB++/SNAP 归档 |
| **Bluesky＋ophyd** | ophyd＝硬件抽象（Device 聚合 channel，`read/set/trigger`，读数按 **kind** 标记 primary/config/engineering）；RunEngine 发出**文档流**：RunStart（`uid`/`plan_name`/`scan_id`/用户元数据）→ EventDescriptor（**schema**：键、单位、精度、**硬件配置**）→ Event（`seq_num`/`data`/逐读数 `timestamps`）→ RunStop（`exit_status`：success/abort/fail） | Plan 是可复用生成器；回调**订阅**文档流做实时可视化/处理/落盘（"可插拔 I/O"）；suitcase 导出，Tiled 访问 | 教科书式三层：**设备层(ophyd)／扫描引擎(RunEngine)／界面(订阅者)** | 元数据在执行时采集，存进**不可变、自描述**的文档；数据"可回溯重放" |

> 注：调查中曾尝试核对名为 **SECI** 的装置控制系统，**未找到任何对应项目（UNVERIFIED，疑为记忆误植）**；同类的真实系统是 EPICS／Tango／Bluesky／Sardana(ALBA)／DOOCS(DESY)／Karabo(EuXFEL)／SICS(PSI)。

**由此提炼出"统一控制台"的五份契约**（本节是全篇最可迁移的部分）：
1. **身份/注册表**——稳定不可变 ID（HA `unique_id`、TangoDB 名字、LSL `source_id`）；**绝不以 IP/名称作键**。
2. **一份规范的数据＋元数据信封**——HA 状态对象、LSL `stream_info`、Grafana data frame、Bluesky document。
3. **一套生命周期协议**——manifest → configure → setup → unload → migrate（HA）；`registerType`（Node-RED）；`plugin.json`＋签名（Grafana）；每设备一个 App 仓库（LSL）。
4. **一份在版本控制下的 provisioning 制品，且"UI 所有"与"文件所有"只能选一个**（Grafana 把这个痛写进了文档）。
5. **一道护栏＋质量阶梯**——LSL 的必需流清单；HA 的 bronze→platinum 质量阶梯（并明确 HACS 插件**未经审计**）。

**对 1–2 人项目的诚实取舍（调查方给的结论，本文照录）**：
- **现在就该做（以"天"计）**：①**冻结一份 run/session 文档 schema**（照 Bluesky：start／descriptor／events／stop），每会话一个 JSON sidecar——**投入 1–2 天，是可得杠杆最高的一改**，它让后续所有看板、导出、AI 数据集成为可能；②**按契约而非文件数拆分**——继续一个 FastAPI 文件＋一个 HTML 文件**完全可以**，真正带来扩展性的是**驱动注册表**（`{name: driver}`＋`capabilities()`）与"由 `/api/panes` JSON 渲染面板"的 UI；**文件超过约 1500 行再拆**；③**显式设备状态枚举＋心跳**（Tango 的 ON/OFF/FAULT/ALARM/UNKNOWN ＋ HA 对未注册实体的 `unavailable`）；④**一份带 `version:` 与 `migrate()` 的 git 版本化配置文件**；⑤**一个合成/假板卡**（BrainFlow synthetic、LSL `SendData`）；⑥**append-only JSONL 事件日志，UI 只是订阅者**（防止"UI 持有真相"这一经典失效）。
- **以后可考虑**：**接 LSL**。官方文档称"市面上多数 EEG 系统已兼容 LSL"；把采集端暴露为 LSL outlet，让 **LabRecorder 当采集控制台**，即可白得溯源、BIDS 文件名模板、必需流护栏与崩溃恢复，本项目控制台则回归"实验/分析层"。成本 `pylsl`＋元数据 XML，约 1–3 天。
- **明确不要做**：带 manifest **与**签名/目录管道的第三方插件沙箱（HA/Grafana 解决的是你没有的规模问题）；通用节点图编辑器（Node-RED——那是在造编辑器）；容器"应用商店"＋监督进程；需要 fork＋PR 的编译型控件 ABI（OpenBCI GUI 的模式诚实但每个贡献者都很贵）；完整 Tango/EPICS 设备服务器栈（**只在超过约 5 台设备且多用户并发时才值得**）。
- **一句话**：**HA、Grafana、Bluesky 的机器各花了 5–15 人年以上；要拿的是它们的"制品"——schema、注册表、生命周期词汇、质量阶梯——不是它们的机器。**

### 4.5 冥想脑电的科学证据边界

> **本节与项目自身的关系**：项目**已经**吸收了其中最要紧的一条（JMIR 2025 元分析 → 判语 009"镜子非训练器"、判语 011 文献分级三规则、宣发红线）。本节的作用是**把边界补齐、把数字补准、把规范写成可执行清单**，而不是重复已经知道的事。

**（一）"入定能不能从脑电看出来"——证据的真实状态**

| 研究线 | 代表工作 | 样本与设计 | 现在能说什么 |
|---|---|---|---|
| 禅僧 α 波（源头） | **Kasamatsu & Hirai 1966**（日本，Zen 僧） | 小样本，当时的方法学标准 | 历史意义大；**按今日标准不足以支撑判别** |
| 长期修习者的 γ | **Lutz et al. 2004 *PNAS*** | **8 名**长期藏传修习者 vs 新手；慈悲禅期高幅 γ | 现象成立；**原始 EEG 未公开**；n=8 训练不出模型 |
| 寺院内采集（可行性已证） | **Kaplan／Mikhaylets 2026 *Sci Rep*** | **51 次会话／36 位男性修习者**，在 Sera Jey＋Gaden Jangtse 两个"科学中心"内采集 | 含**寺院本地伦理批准**＋**知情同意译为藏文**；**数据未公开** |
| 僧侣 vs 在家人 | **HKU 佛学研究中心＋港理工 2025 *Behav Sci*** | 20 位比丘（5–28 年参话头）vs 18 位在家人，**128 通道** | 组间差异可研究；**数据未公开** |
| 僧团互动与辩论 | **van Vugt 等（Groningen，2019／2020／2025）** | 印度 Sera Jey 网络；**僧侣既是被试也是共同作者** | 方法学范式（**把修习者做成共同作者**）值得抄 |
| jhana／入定层次 | **Chowdhury et al. 2025 *NeuroImage***；**van Lutterveld／Ingram／Sacchet 2026** | **各 1 名被试**（后者被试本人即共同作者） | **至今仍是个案报告；不存在可复用的"入定 EEG 判别标准"** |

**结论**：**"入定"今天不是 EEG 上已被建立的判别目标**，而是一个**待标注、待积累的建模目标**——与《三年战略》"应视作待验证的建模目标，而非已经成立的结论"完全一致。控制台的「大脑状态：冥想」标签（S4）是这条线上唯一的越界处。

**（二）神经反馈有效性的总体证据**

> **⚠️ 先把两条"流传甚广但不存在"的文献钉住**（两条均经两个独立索引各查一遍，命中 0）：①**"Ros et al. 2020，正念冥想与 EEG 微状态"不存在**（Ros 无任何冥想/正念索引记录；真正的微状态研究出自 Zarka 2024／Zanesco 2021）；②**"Brandmeyer & Delorme 2018，闭环 FMθ 神经反馈减少走神"不存在该题名**——真实的 2018 年那篇是**观察性**研究（专家 vs 非专家，经验采样），无反馈操纵、无 RCT、无假反馈。**凡在本项目任何文档中见到这两条引用，应登记订正。**（`Ros et al. 2020 *Brain*` 仅指 **CRED-nf 检查表**，那是真实文献。）

1. **冥想＋消费级设备（对本项目最直接）**：**Treves et al. 2025 *JMIR***（16 RCT／N=763，**11/16 用 Muse**）。**完整报表**：心理困扰未调整 **g=−0.29（−0.47~−0.11）**，中度报告偏倚校正后 **g=−0.27（−0.44~−0.10）**；认知 g=0.31（0.01~0.61）**校正后不显著**；**探索性脑靶标 g=−0.01（−0.39~0.36）**；被试内脑靶标 g=0.12（−0.1~0.34）不显著。原文核心句：**"mechanistic modulation of brain targets was not found"**；**16 项消费级 RCT 中"没有一项设了假神经反馈"**；**21 项研究中 19 项未评估不良反应**。
   ⚠️ **须核对**：本项目既有文档（判语 009、日志 009）引用的是"k=11, g=−0.16, P=.03"这一子集值，与上述**完整报表值不一致**——**建议由 W2 抓原文核对一次，并在判语卡上加一条注记**（属"外部事实独立核校"，不是改判语结论）。
2. **健康成人神经反馈的"全场最佳统计"（新增，建议作为对外引用的头号数字）**：**Kimura et al. 2024 *Imaging Neuroscience***（综述 41 项 RCT；**合并 15 项 RCT／569 人 → 总体 SMD 0.27（95% CI 0.10–0.44）**，但**在与假神经反馈对照的 8 项 RCT 中未发现显著合并效应**）。一句话概括全领域：**对着弱对照有效应，对着假反馈就消失。**
3. **ADHD**：**Westwood 2025 *JAMA Psychiatry***（38 RCT／n=2,472）——可能盲评下总症状 **SMD 0.04**；标准方案 0.21；**唯一显著项是加工速度 0.35**。**Arnold 2021** 双盲假反馈 RCT（N=144）——**两组都改善 d=1.5，真反馈并不更优（d=0.01, p=.965）**。
4. **失眠（决定性的一条，此前被低估）**：**Recio-Rodriguez et al. 2024 *Front Neurosci*** PRISMA 系统综述＋元分析（7 RCT）——**PSQI 合并效应 0.57（95% CI 0.13–1.01）方向利于对照组**；失眠严重度 −0.13（−0.44~0.18）为零。结论："**表面神经反馈相较各类对照条件未产生额外收益**"。
   **Schabus 2017 *Brain* 的细节更值得记住**：其**操作检验通过了**（SMR 功率 19.64 vs 8.75，**F(1,17)=20.54, p<0.001, ηp²=0.547**），即**被试确实学会了调制目标指标，但所有客观多导睡眠指标全部为零**。→ **"学会了调制指标"与"结果改善"是两件事**——这一条直接适用于本项目的闭环逻辑。
5. **冥想神经反馈的 RCT 现状（一句话：设计干净的假反馈对照试验极少，且越干净越阴性）**：
   - **Brandmeyer & Delorme 2020**（双盲，N=24，12 真／12 假；**假反馈＝回放配对真反馈被试的录音**，设计诚实地道，8 次训练）：FMθ 增长 **真反馈 r²=0.49, p=0.05 vs 假 r²=0.14, p=0.36**（剔除 3 名无反应者后 r²=0.85, p=0.001）；行为上 n-back 正确反应更快，但**正确率交互为零（F=0.14, p=0.71）**，SART 与 local-global 均无显著结果；**全文未报告任何效应量**（勿替它算 Cohen's d）。**且它是 64 通道 BioSemi 实验室放大器，不是消费级头环。**
   - **Chow et al. 2017 *Mindfulness***（随机，N=61，单次 15 分钟）：仅全频段 α 阳性，**无行为组间差异，未报效应量**。
   - **Lee E et al. 2024 *J Korean Med Sci***（**随机双盲**，N=38 压力人群）：PSS **6.45±0.95 vs 3.00±5.54, P=0.037** 有利于神经反馈，但**抑郁与睡眠两组同等改善、无组间差，压力激素与 qEEG 均无显著差异**——**即便是唯一一项在主要自评终点上达到显著的双盲消费级冥想神经反馈试验，在生理层面也是一片空白**。
   - **其余全是**：无对照、或以"无反馈/冥想 App"作假对照（不是 sham）、或对这类对照为阴性。三项新的阴性 RCT：**Jahani et al. 2026 *J Am Coll Health***（**N=137，三臂 RCT，8 周**，压力 F(2,134)=0.269, p=.765，结论"**消费级神经反馈相较传统引导冥想无可测优势**"）；**Fernandez-Crespo 2025**（N=40，焦虑 MD=0.1，p=0.868）；**Golshan 2025**（偏头痛，N=101 入组／61 分析，组间差置信区间全部过零）。
   - **在跑的关键试验（说明证据短期内不会落定）**：**NCT06208787**（KU Leuven，随机单盲 真反馈 vs 假训练，**N=80，2025-08-08 已完成但未发布结果**）——**这是最对题的已注册假对照 EEG-NF 冥想试验**；**NCT07055217**（MGH，四盲，真 vs 假 mbNF，**N=100，招募中**）；**NCT06901232**（MGH，三盲，N=90）；**NCT06542640**（BIDMC，四盲 rt-fMRI-NF vs sham，N=300）。
6. **fNIRS 侧**：最对题的 ADHD 试验是**阴性的**——**Barth 2021 *Sci Rep***（随机，**N=67 成人 ADHD**，30 次训练）"三组同等改善，提示安慰剂/非特异效应"；**Yang 2024** 随机假反馈对照（N=62）"训练组与假反馈组无差异"。公允的反证：**Mihara 2021 *Neurology*** 是 fNIRS-NF 迄今最好的 RCT（双中心双盲假对照，N=54 皮层下卒中，3 米起立行走组间差 **7.33 s（95% CI 0.83–13.83）**）——**模态本身不是空的，空的是消费级 ADHD 主张**。
7. **Mendi 的"22 项研究"**：实为 **Kohl et al. 2020 *Front Neurosci***（22 项、N=441、**全适应症**、**叙述性综述、无合并效应量**），其自述结论是"**仍缺大型 RCT……关于特异性或潜在临床效用下结论为时尚早**"。**且存在利益冲突**：Kohl SH 与 Mehler DMA 均申报"**接受 Mendi Innovations AB 的咨询报酬**"（PMID 40799719／39428887）。→ **其证据基础部分来自它自己付费的顾问。**
8. **⚠️ Alpha-Theta"巅峰表现"协议不构成证据基础**：其谱系是 **Peniston & Kulkosky 1989**（未述随机化或盲法，样本量未报）与 **Saxby & Peniston 1995**（**N=14**），并已在期刊上被拆解（**Graap & Freides 1998**，质疑样本是否独立）。随机检验既少又阴性：**Gruzelier et al. 2014** 把舞蹈学生随机分到 A/T 神经反馈、HRV 生物反馈、舞蹈编排或无训练，结论"**三种干预对舞蹈表现均无影响**"——**而 Gruzelier 正是该协议最主要的倡导者**。**健康成人 A/T 神经反馈没有元分析、没有系统综述、也没有显示表现或健康获益的假对照 RCT。**（本项目闭环用的是 α 阈值奖励＋θ/β 调节拍，**与该协议不是同一回事**，引用时应分开。）
9. **批评方与方法论回应**：**Thibault & Raz 2017 *Am Psychol***——驱动改善的"更像心理社会参数（动机、期望），而非神经生物学基质"。**CRED-nf 检查表**（Ros et al. 2020 *Brain*，**批评方与被批评方共同署名**）要求报告盲法、假反馈对照、不良反应与"目标指标是否真被调制"。**判语 011 规则③ 与它同向**，但目前只是判语卡，不是清单。
   ⚠️ **另有一条对本项目最有利、也最该先回答的外部结论**：**Hayat et al. 2026 *Front Artif Intell***——冥想风格**在被试内高度可区分，但跨被试泛化很差**，明确"对建立**被试无关**的冥想分类系统构成挑战"。→ **任何"跨人通用入定模型"的主张都必须先回答这篇**；反之，**"一人一校准"（本项目 202607 借鉴核验表 §一 已列为强支持项）恰好是唯一被证据支持的路线**。

**（三）消费级硬件的现实约束（数字比上一版更准）**

- **Ratti 2017 *Front Hum Neurosci*** 的准确内容：**未报告任何相关系数**，只有 PSD 叠加图与重测 PSD 比值；**Muse 睁眼/闭眼重测比值 1.125–1.225，而两台"医疗级"设备为 0.975–1.025**；且 **Muse 在 Visit 1 频谱中观察不到 α 峰**。对比设备是 Muse ＋ **NeuroSky MindWave** vs B-Alert ＋ Enobio（**没有 Emotiv、没有 g.tec**）；⚠️ 且**两台"医疗级"设备是论文合著者自家的产品**（引此文献时须注明）。
- **Krigolson et al. 2017 *Front Neurosci*（新增，最有用的一条）**：Muse 的 **P300 幅度 1.37 µV，而研究级放大器为 10.47 µV**（奖励正波 2.57 vs 5.67 µV）；**蓝牙延迟 40 ± 20 ms**。→ **蓝牙抖动是闭环延迟主张的一条硬天花板**；本项目"亚秒级反馈"的说法若要写进任何对外文本，必须以这两组数字为前提。
- **睡眠侧的一个反讽（供判断 Muse 的宣传）**：Lanthier 2025 *Sleep Adv*（N=56，同步 1 级 PSG、PSG 对 Muse 盲评）实测 **整夜 Cohen's κ=0.76**（N1 期 κ=0.41 最弱），但**偏差是系统性的**（TST +6.7 分钟、深睡 +15.2 分钟），且 **SOL/SE 存在比例偏差——睡眠越差、精度越低**，对失眠终点恰好方向相反。
- **"消费级头环够不够用"的两组对立证据（都要看，别只引一边）**：
  - **不利侧（本次共得四项独立结果）**：①**Kleeva 2024 *Front Neurosci*** 与 **Mikhaylov 2024 *Sensors*** 均把 Muse 排在信号质量末位；②**Kleeva, Ninenko & Lebedev 2024**：Muse S vs NVX-36 凝胶电极，**δ 频段 r=0.067（p=0.535，不显著）**、α r=0.519；③***Brain Informatics* 2025**（EPOC X vs **Muse S** vs Mindtooth）："**Muse S 表现最弱，神经指标基本不相关**"，且舒适性优势"**并未伴随信号质量改善**"；④**Lee et al. 2026**：Muse 2 的**运动鲁棒性最低、个体 α 峰误差最大（0.32 Hz）、数据丢失最多**，且 **Berger 效应 3.779 vs DSI-24 的 7.962**。
  - **有利侧**：**Lee et al. 2026 *Sci Rep***（N=30，Muse2 vs BrainLink Pro／NeuroNicle FX2／MindWave Mobile2，以 **DSI-24（21 电极）**为基准）认为消费级设备的 **α 节律特征与抗噪性与研究级设备"可比"**——但 Muse2 在**眨眼/咬肌块丢失 3/30 名被试**、头部运动块丢失 1/30。
  - **⚠️ 对本项目最要紧的一个数字**：**Berger 效应（α 对睁闭眼的反应性）在 Muse 2 上只有研究级设备的一半左右（3.779 vs 7.962）**——而本项目的整个闭环奖励逻辑**正是建立在 α 反应性之上的**。这直接关系到"1.0 dB 奖励阈值是否落在噪声底之上"（见（三）末尾的 UNVERIFIED 项），也关系到 S4 的"不可判定"档该怎么设。
  - **诚实的框架**：**Muse 的测量科学"做睡眠分期够用、做细粒度 EEG 偏弱"**；本项目要做的 α 细粒度判别属于**偏弱的那一侧**。
- **开源硬件到底差多少（生态论证的最佳数据点）**：**Frey 2016**：OpenBCI Cyton 与 g.tec g.USBamp 接入**同一信号**——**Pearson R 0.9965–0.9983（全部 p<0.001）**；P300 AUROCC **0.918 vs 0.961**（p<0.01）；负荷指标 0.853 vs 0.860（不显著）。**价格 €800 vs €20,000。** → 这是文献里"开放硬件几乎一样好"的最强证据，也是本项目**将来要产出可公开数据集时选硬件的依据**。
- **项目自身 09-10 的实测**（灵敏度提 4.9 倍、噪声也提 4.9 倍；法师"会闪、有跳跃感、对禅修构成扰动"）与上述"消费级宽带虚高／信度最差"**方向一致**——红线8 因此不只是经验，而是有文献支撑的纪律。
- ⚠️ **UNVERIFIED（本次未取得可信来源，故本文不引用任何数字）**：①Muse 级干电极在 5–10 分钟窗口上频段功率的 **ICC／重测信度具体数值**；②可靠检出 **0.5–1.0 dB α 变化**所需的最小可检测效应（MDE）。**这两项应列为下一步文献任务**——它们直接决定"闭环奖励阈值 1.0 dB"是否落在噪声底之上。（Ratti 的"无 α 峰"与 Krigolson 的幅度差是已有的两个警示信号。）

### 5.2 三条被验证的设计原理（我们做对了一半）

1. **一个数、一个隐喻、亚秒级回路，绝不让用户读频谱。**
   → 我们做对了：VR 端只给场域感与光球（不显示频谱），音景式反馈（节拍＋音量）。
   → 我们没做完：**闭环回路的真实频率是 0.5 Hz（§1.2 F2）**，而"亚秒级"在本项目既未测量也未声明；且**操作者界面反而全是频谱与 dB**——两种用户模型混在一个产品里没有分开（20260908 §九 已经点出"用户模型不同"，但只解决了载体分离，没解决"两个视图的定义不统一"，见 A6）。
2. **反馈必须外围、非阻断。**
   → 我们做对了：声音默认静音、节拍 8–14 Hz 缓变、四维分工（底色/中程/短程/现实锚）刻意避免扰动——**这与 Narbis"变暗但不打断"是同一原理，且做得更细**。
   → 风险：09-10 的教训（灵敏度提 4.9 倍→闪动跳跃、"对禅修构成扰动"）**正是违反这条原理的实例**，而它发生在我们自己身上。红线8 是对的原理，但它是被事故教出来的。
3. **硬件是漏斗，数据访问权是护城河。**
   → 我们天然符合：不卖硬件、数据不出网。
   → 但**"数据访问权"我们还没有把它当资产经营**：没有 schema 版本、没有可见的数据字典落地、主索引 6 列、79 个会话未入库（S1/S2/A7）。**护城河现在是敞着的。**

### 5.4 生态位判断（**对项目最重要的一段，含两处需要更正的预期**）

初判"禅师标注的深定脑电数据集这个生态位基本是空的"——**两次核查后须更正为"数据是'半占位且几乎全不公开'，而'原始＋禅师标注'那一格确实为零"**：

- **数据这一半已被占，但都不是禅寺主导、且几乎全部未公开**：荷兰 Groningen 的 **van Vugt**（印度 Sera Jey 寺院网络，**藏传僧侣既是被试也是共同作者**，10 位僧侣合著，2019 *Prog Brain Res*／2020 *Mindfulness*）；莫斯科 **Kaplan／Mikhaylets**（**在寺院与闭关房内采集**，Sera Jey＋Gaden Jangtse 两个"科学中心"，**51 次会话／36 位男性修习者**，伦理由寺院科学中心批准、**知情同意译为藏文**，2026 *Sci Rep*）；意大利 **Pisa/CNR（Neri 2024）**（**寺院内 23 位修习者**，3 位僧侣共同作者）；**香港大学佛学研究中心＋港理工**（**20 位比丘 vs 18 位在家人，128 通道**，2025 *Behav Sci*）；斯里兰卡森林道场（Nissarana Vanaya，2021 *Mindfulness*）。经典源头是 **Kasamatsu & Hirai 1966** 的禅僧 α 研究。
- **⚠️ 但"公开的禅师标注数据集"确实存在一个（我最初说"没有"，须更正）**：**Mendeley `10.17632/pthdhf2dwm`**（泰国 Burapha 大学，泰国国家研究委员会资助）——**60 位受戒泰国僧侣**、64 通道 Neuroscan、30 分钟冥想切成 6 个 5 分钟段，**CC BY 4.0 完全开放、无需注册**；**但只发布特征（band power），没有原始 EEG**——**无法重新参考、无法重做伪迹处理、无法换窗**。另有 IEEE DataPort `10.21227/960a-x684`（7 位 Vipassana，含受戒 ≥10 年僧侣，用 **Muse**；CC BY 4.0 但**登录墙且作者不回信**）与 **OpenNeuro `ds003816`**（HKU 慈心禅，48 人、128 通道 actiCHamp、**CC0**，**共同作者含受戒僧人 Ven WONG Goon Fui**，但被试是在家人）。
- **⚠️ 但必须补一条会削弱"语料空白"结论的事实（第三次更正）**：**现存最大的冥想脑电语料是一家商业公司自己发布的**——**Banville et al. 2024 *Imaging Neuroscience*** 分析 Interaxon 自有用户库，公开了 **Muse Meditation Dataset（n=4,191）** 与 **At-home Muse Unlabelled Sleep Dataset（n=1,020）**，合计"**5200 人以上**"，且合著者含 Gramfort、Engemann 等方法学学者；Interaxon 还要求研究者在 Methods 中引用其 **RRID（SCR_014418）**。→ **"大规模冥想脑电"这一格并非无人占据，占的是厂商；而"原始＋禅师标注＋开放许可"那一格仍然为零。** 两者不矛盾，但对外表述必须区分："**最大的冥想语料已存在，但它是消费级用户库、不是禅师标注的深定语料**。"
- **⚠️ 且该公司的研究者通道是"配给制"**：官网称研究工具体系"**请联系我们**"（联系表单后方），开发者申请"**按季度审核，且只回复我们能支持的人**"——**SDK 虽恢复，支持仍然稀缺**，这正是 2019 年撤回的同一个张力。
- **因此"零"的位置非常明确（三条硬证据）**：**DataCite 全库检索 `title:"jhana"` 且 type=dataset → 0 条**；**科学数据银行（中国最大国家数据仓）→ 无任何中国冥想 EEG 数据集**；**唯一开放的禅师数据集只有特征、没有原始数据**。→ **"原始＋禅师标注＋公开许可"的那一格，目前没有任何占据者。**
- **模型这一半是真空白**：**没有任何机构拥有"深定深度"解码模型**；jhana 文献至今是 **n=1 案例**（Chowdhury 2025 *NeuroImage* 1 位；van Lutterveld／Ingram／Sacchet 2026 停止研究 1 位，且被试本人即共同作者；另有 Mikhaylets 2023 N=3、Potash 2025 现象学＋连接性）。
- **"禅师标注"这个标签归寺院所有**，而归**任何先建立关系的那家实验室**——**决定性资产是"寺院科学中心"关系（Sera Jey／Gaden Jangtse 是先例），不是算法**；它买不到，也快不了（2–3 年信任建设，不是工程冲刺）。**Sera Jey  monastic university（Bylakuppe）事实上是全球枢纽**，同时喂养三个西方实验室（Pisa/CNR、莫斯科 Kaplan、Groningen van Vugt）；**僧人 Ngawang Norbu 同时是 Neri 2024、van Vugt 2019/2020、Mikhaylets 2026 的共同作者——他是本领域最关键的守门人**。
- **没有任何寺院自己运营 EEG 实验室或持有神经数据集**（对法鼓山／DILA、佛光山、慈济、新加坡 KMSPKS、灵隐寺、龙泉寺的核实均为负）→ **资产是关系，不是记录**。
- **中国/台湾寺院侧未见 EEG 研究计划**：法鼓山、佛光山、慈济均查无 EEG 项目。现存的是**文本型数字弘法**：法鼓山 LLM 问答（108ai.ddm.org.tw）、**DILA 數位典藏＋CBETA**（旗舰开放藏经）、佛光山 foguang.ai（翻译平台）、慈济 60immex VR 文化、**杭州云林数字佛典研究院（灵隐寺，2026 成立，免费发布《徑山藏》数字化）**。**离本项目最近的同行者是香港大学（Gao Junling＋僧人共同作者，采用 CC0）——那是合作者或最近的竞争者，不是既得利益者。**
  **🚨 一个必须记住的陷阱**：**`eeg.dila.edu.tw` 是"環境教育"（Environmental Education），不是脑电（electroencephalography）**；法鼓山"心靈環保研究中心"是环境/可持续方向，只做外链。**不要在这上面建立任何"神经"主张。**
- **两条会对本项目产生实质影响的更正**：①**Sanguinetti 的 SEMA 实验室做的是经颅聚焦超声，不是 EEG**——无消费设备、无产品、无数据集；**Tiny Blue Dot 基金会只出钱、不做设备也不做数据集**（但其 **RFP 强制要求预注册＋FAIR 数据/代码计划**，资助上限 **US$90 万/3 年**，第 5 轮 2026-09 开放——**这是本项目最现实的外部资助路径**；另有 **Mind & Life Europe 的 EVA 奖**，2 年期、不许列薪金与管理费、强制伦理审批）。②**Shamatha Project 是 60 位在家人，不是僧侣**（BioSemi 88→73 通道，2007，站点已休眠，无仓、无数据共享声明）。
- **⚠️ 对本项目 AI 前提最直接的一条外部约束**：**Hayat et al. 2026 *Front Artif Intell***——冥想风格**被试内高度可分、跨被试泛化很差**。→ **"跨人通用入定模型"这条路先要回答它**；而**"一人一校准＋个体基线"恰好是唯一被证据支持的路线**（与本项目 202607 借鉴核验表 §一 的结论一致）。
- **本项目既有调研未覆盖上述诸线**（在 `04_研究调研` 下检索 van Vugt／Kaplan／Sera Jey **零命中**）——**存在"误以为自己是首例"的风险**。

**由此得出四条对外口径建议（须法师裁定）**：
1. **绝不宣称"首次做禅僧脑电"**——一查即破（van Vugt／Kaplan／Neri／HKU 在册）。
2. **可以诚实宣称的是**："**原始、禅师标注、纵向、公开许可**的中国禅修与长闭关 EEG 语料 ＋ **LSL 兼容的采集标准与公开基准**"——**这正是 DataCite／科学数据银行／Mendeley 三处都留空的那一格**（现有唯一开放禅师数据集只有特征；中国国家数据仓为零）。
3. **落地前先在免费语料上把管道跑通**：**OpenNeuro `ds003969`**（98 人、五种传统、BioSemi 64 通道/1024 Hz、**CC0**、41–60 GB）与 **`ds001787`**（12 专家＋12 新手，**带"专注度评分"标注**，可直接当"深度"目标的现成标签）、`ds003816`；**这些不花一分钱就能让清洗/标注/建模管道先成型**。
4. **风险须先认清**：①资深修习者稀少，n=8 级数据训练不出可辩护模型，需 **30–100+ 次仪器化良好的会话**；②消费级单通道头环**支撑不了 jhana 级主张**（本项目的 Muse 属"偏弱的那一侧"）——若要产出可公开语料，**应选 OpenBCI 级开放硬件**（Frey 2016：Cyton 对 g.USBamp 的 **R=0.9965–0.9983**，价格 €800 vs €20,000）；③**跨传统标签一致性（四禅八定 vs TMI 十阶）本身是一个研究课题**；④**禅寺标签是信誉资产，一次过度宣称即毁**；⑤**接近寺院要通过"寺院科学中心"或已有桥梁（HKU CBS／Sera Jey），不要冷招募僧侣**——本领域每一项成功研究都是这样做的。

### 5.5 结论：本项目真正的优势与真正的短板

**优势（少见且值得保）**：①**真实禅法体系＋专业标注者**（别人买不到）；②**VR/WebXR 闭环**（全球几乎空白，且有 09-10 以来细颗粒的设计迭代记录）；③**质量先行与数据诚实性的意识**（`signal_chain`/`pre_filter` 这套东西，在 C 端产品里一家都没有）；④**多源可换与离线回放**（使方法可复现的雏形已在）。

**短板（全部在"数据之后"）**：数据契约（schema/版本/主索引）、研究规范（CRED-nf/盲法/预注册/BIDS）、工程闸门（CI/环境锁/测试入库）、以及**把"禅师标注"这件事变成可控流程的工具（标注工作台）**——**而这四样恰好都是"控制台"该承载的第二阶段内容**。

**⚠️ 另有一项此前未被提出的现实风险（硬件连续性）**：**本项目在用的 Muse S（第 3 代）已从 Interaxon 在售目录消失**（目录仅剩 Muse 2 与 Muse S Athena，`muse-s` 商品页只剩保护壳）。三年战略原定"第三阶段再决定硬件"，但**在用设备停产会把"决定硬件"从第三阶段提前**——备件、替换型号（Muse 2 仍在售但为同代 4 通道、Athena 的 fNIRS 无验证）、以及"是否转向 OpenBCI 级开放硬件"这三件事，建议在 P0/P1 期间一并评估（见 §八-11）。

> 一句话：**我们的独特性在"场域与标注"，我们的欠账在"契约与闸门"。控制台现在的样子，只服务了前者的一半，完全没有服务后者。**
