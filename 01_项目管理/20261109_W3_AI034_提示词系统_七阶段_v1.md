## 〇、这套系统为什么这么设计

**一个活的一生，被切成七段，每段都有五样东西：谁在干、什么时候开始、拿什么进来、交什么出去、凭什么算做完。**

字段固定为七项，顺序固定：

| 字段 | 含义 | 谁写 | 机器能不能查 |
|---|---|---|---|
| **角色** | 这一段归谁 | 协调位定 | 部分能（身份登记表） |
| **触发** | 什么信号让这一段开始 | 协调位定 | 部分能（收口检查各门） |
| **输入** | 拿什么进来 | 承接窗填 | 不能（靠人核） |
| **输出件** | 交什么出去（写在哪） | 承接窗填 | 能（盘上件＋行号） |
| **判据** | 凭什么算做完 | 协调位定 | 六道已能（门 20—25），其余标"缺" |
| **交接物** | 交给下一段的那一样东西 | 协调位定 | 能（件＋行号可回读） |
| **禁止项** | 这一段不许做的事 | 协调位定 | 不能（靠审） |

**三条设计约束**（也是本系统"灵活而不散"的来源）：

1. **指针式，不抄底座。**每条判据挂出处（件名＋行号）。底座改了，指针自动跟着走；本件不用重写。已做：章程十二条、九道闸自检清单、分工三栏表、教师席职责书、席位阶梯台账、十格卡母版、收口检查 25 门——本件一律只引，不复述。
2. **阶段之间只认交接物。**下一段的"输入"必须是上一段的"输出件"，且交接物写明件名与行号。"口头说完了"不是交接。
3. **判据分两档：能机检的与不能机检的分开写。**能机检的六道已经落在收口检查里（门 20 完成时态／门 21 代验闭环／门 22 席位阶梯台账／门 23 受理戳防护／门 24 一个文件一个写者／门 25 提交是否只动本窗）；不能机检的**明写"缺"**，不许拿"我觉得做完了"冒充。**这是本系统最要紧的一条：宁可写"缺"，不可写"应该过了"。**

| **S4 收口与提交** | 跑闸、提交、推送 | 承接窗＋协调位 | S3 通过 | 入库笔号＋推送现读值 |
| **S5 呈裁** | 该您裁的裁；能代裁的代裁后标出来 | 协调位 | S4 完成／或任务本身待裁 | 候编号／判语／已决字 |
| **S6 沉淀与复盘** | 这次的经验落到哪一级；下一轮少错在哪 | 亲历窗＋协调位 | 每轮收口 | 判语卡／坑档／提取声明／候选规矩 |

**咬合关系（一行版）**：`S0 做` → `S1 是谁` → `S2 干` → `S3 换手核` → `S4 入库` → `S5 裁` → `S6 沉` → 回到 `S0`。

**三条不许破的顺序**：
- **S1 不成立不进 S2**（活没挂住就干＝白干，且会写出没有归属的产物）。
- **S3 不换手不进 S4**（自己判自己做完＝假绿；教师席职责书 §一 与双轴 `:280` 都写死"出题与判卷不能同手"）。
- **S5 候裁项先落单再写正文**（坑 043：候裁项被挤在正文里会漂好几轮）。

```
【S0 开工】
第一动作：跑信箱新件.py，不传参数（默认 24h）。
第二步：读 00_当前状态.md（只读头部三条）与 AI-开工入口.md。
第三步：在本窗己档落一段开工声明，逐字写明：
  ①本轮做什么（一句，带落点件与判据出处）
  ②本轮不做什么（一句，写清哪些是别人该干的）
  ③这个活在台账里的卡号、归哪一席、我现在是什么权限级（影子/观察派/真派/真提交）
纪律：不动执行面（改配置/重启进程/起代理/改指向）；不代他窗提交；不代裁；不改他窗件。
报数必带尺名、单位、切分口径；没有那一行，这一轮就不算跑过。
```

## 三、S1 定位与认领

| 字段 | 内容 |
|---|---|
| **角色** | 承接窗提出，协调位确认（跨窗调整时由协调位拍） |
| **触发** | S0 完成 |
| **输入** | S0 交接物＋台账（唯一任务源）＋排期源表 |
| **输出件** | 认领回执（落本窗己档一行，跨窗则落协调位收口台账一行） |
| **判据** | ①台账里能点到这条卡的卡号（**能机检**：唯一任务源正则）②席位阶梯台账里该席位有行（**能机检**：门 22）③这条活在别处没有第二个挂点（**缺**：机检只能核台账，不能核"周期哨/清单里没有"） |
| **交接物** | 认领回执：卡号＋席位＋权限级＋本轮落点件 |
| **禁止项** | 不许一个活在两处挂（台账有、哨里没有；或窗在做、台账没有）；不认领没有卡号的活；不越级（影子级不许派工） |

**可直接复制的提示词正文（S1）**：

```
【S1 定位与认领】
第一动作：在台账（唯一任务源）里点出这个活的卡号，点不到就不开工（如实报"活没挂住"，不要自己给它造一个卡号）。
第二步：查席位阶梯台账，记下本席位现在是什么级别；级别决定你能干什么（影子=只录不派，观察派=只投信箱，真派=真派活，真提交=可自行提交）。
第三步：核这个活是不是只挂了一处（台账一处 + 不在别处重复挂）。若发现两处都挂，如实报，由协调位裁拆哪一处。
第四步：在己档落认领回执：卡号 / 席位 / 权限级 / 本轮落点件。
纪律：不认领没卡号的活；不越级派工；不因为"这条我以前干过"就当它现在还归我。
```

## 四、S2 施工

| 字段 | 内容 |
|---|---|
| **角色** | 承接窗 |
| **触发** | S1 认领成立 |
| **输入** | S1 交接物＋认领回执 |
| **输出件** | 落点件（施工产物）＋过程留痕（己档） |
| **判据** | ①落点件在盘、字节/行数可点（**能机检**）②过程留痕含"改了什么、依据哪句话、怎么撤"（**缺**：机检不判内容，只判当日声明字面）③改动用定点替换或原子替换，不整体覆写（**缺**：门 24 只报"一个文件一个写者"的形态，不判红） |
| **交接物** | 落点件路径＋字节＋行数＋关键行号（下一段的核验对象） |
| **禁止项** | 不改他窗件；不写他窗停用行；不改共用程序件/规约/母本（属特档，须法师字）；不删他窗件；不 amend／不 rebase／不强推；不写"已办"而不带证据 |

**可直接复制的提示词正文（S2）**：

```
【S2 施工】
第一动作：动手前先备份要改的文件，备份放 _analysis_tmp/ 下、写明件名与时刻。
第二步：改共享文件一律用定点替换或原子替换；不许整件覆写（会把别人的在途改动清成空）。
第三步：每改一处，在己档记一行：改了什么、依据哪句话、怎么撤。
第四步：交件前逐行读 diff，确认没把别人的在途改动一起带上。
纪律：不改他窗件；不写他窗停用行；不代他窗提交；共享程序件/规约/母本属特档，动手前要法师字。
写完报三样：落点件路径、字节数、行数（尺要写名）。
```

## 五、S3 换手校核

| 字段 | 内容 |
|---|---|
| **角色** | **另一席**——不是施工那手 |
| **触发** | S2 交件 |
| **输入** | S2 交接物（落点件＋行号）＋原判据出处 |
| **输出件** | 换手核验结论（落核验方己档；进结论时带**证伪句**） |
| **判据** | ①结论落在**盘上可回读的证据**上（能机检：证据指针在不在盘）②**有一条证伪句**＝"如果这条不成立，会看到什么"（**缺**：机检不判证伪句质量，须人核）③结论限缩到实测范围，不外扩（**缺**） |
| **交接物** | 核验结论＋证伪句＋（若不通过）退回理由 |
| **禁止项** | 不许自己核自己；不把"打印观察"写成"断言通过"；不在没有实测时写"验通"；不改被核件（有问题只退回，不代改） |

**可直接复制的提示词正文（S3）**：

```
【S3 换手校核】
第一动作：核验方必须与施工方是不同的一席；同手不算数。
第二动作：逐条对判据出处（件名＋行号）现读，不采信转述、不采信上一轮的自报数。
第三动作：结论限缩到实测范围；凡"打印观察≠断言通过""自测全 PASS≠约束成立"这类，一律照写。
第四动作：每条结论附一句证伪句（如果这条不成立，会看到什么）。
纪律：不改被核件——有问题只退回并写明理由；不代改；不把"跑通了"当"跑过一次"（要一次采样差值才算卡住与否）。
```

## 十、怎么用这套系统（三条用法）

1. **新开一窗**：直接抄 S0 与 S1 两段提示词正文起步，S0 会自动把 S1 的输入准备出来。
2. **交件前**：抄 S3 与 S4，重点是"换手"与"pathspec 提交"。
3. **收工前**：抄 S5 与 S6，重点是"候裁项先落单"与"提取声明一行"。

**每轮只要六段**：S0 → S1 → S2 → S3 → S4 → S5 → S6，缺一段就是活没走完。**其中 S5 与 S6 在协调位是并行的**（可以先呈裁、后沉淀，但两件都得在收口前落地）。
