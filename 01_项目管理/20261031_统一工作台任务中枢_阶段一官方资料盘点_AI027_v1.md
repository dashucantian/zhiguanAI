### Claude Desktop

官方帮助文档说明可安装本地 MCP 桌面扩展，并查看连接状态、日志与权限故障信息。它证明的是 Claude Desktop **作为 MCP 工具客户端**的入口；查到的资料没有定义从另一个工作台向 Desktop 会话发 prompt、寻址或中止 turn 的外部控制 API。官方帮助页未给出可对应本机的客户端版本。本机版本 `2.19675.0.0` 仅为法师所给 EasyCLIProxyAPI 截图中的显示值（盘上观察级，不是本窗 About 实测）。W3 观察记录只发现 `claude-desktop.exe` WindowsApps alias，未读配置、未连 MCP。〔官方：[Local MCP Servers](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop)；[Desktop Extensions 安全说明](https://support.claude.com/en/articles/13364135-use-claude-cowork-safely)〕

**接口方向提醒**：既有止观AI看板源码是 Streamable HTTP `/mcp`，供 Qoder 连接器调用；Claude Desktop 的本地扩展机制与该 HTTP 端点是否可直接互通，本轮未核。不得把 MCP 工具调用误写成 Claude Desktop 的远程代理控制能力，也未尝试连接或加桥接器。

### Codex

官方 App Server 文档描述 JSON-RPC 线程／轮次、事件通知、审批请求与回应、`turn/interrupt`；失败和中断分别有终态。Codex CLI 发行说明列 `0.164.0`（2026-10-23），这是 CLI 版本参考，非本机 Codex 桌面端实测版本。官方材料还说明 App Server schema 会随安装的 CLI 版本生成，因此后续必须取本机版本，不能把网页示例当成稳定固定 schema。官方 `codex exec` 面向非交互任务，并受 sandbox／审批策略控制。W3 的只读命令发现中，`codex` 未在当前 PowerShell PATH；这不能证明未安装。〔官方：[App Server](https://learn.chatgpt.com/docs/app-server)；[Changelog](https://learn.chatgpt.com/docs/changelog)；[Codex as a platform](https://developers.openai.com/blog/codex-as-a-platform)〕

### OpenCode

官方 Changelog 列 `2.2.0`（2026-10-27）。Server 文档说明 `opencode serve` 提供 API，含会话创建、发消息、异步 prompt 和 `/session/:id/abort`；可用 HTTP Basic Auth 配置保护，并能从 health 端点读取服务版本。权限文档定义 `allow`、`ask`、`deny` 及一次／本会话批准选项。W3 观察中 `opencode.ps1` 可解析至 Roaming npm；没有运行版本命令、启动 server 或请求接口。〔官方：[Changelog](https://opencode.ai/changelog)；[Server API](https://dev.opencode.ai/docs/server/)；[Permissions](https://docs.opencode.ai/docs/permissions/)〕

### Qoder

官方 CLI Release Notes 列 `1.1.81`（2026-10-29）；这是 CLI 发行号，不代表 Qoder 桌面客户端版本。官方 SDK 文档支持会话、事件流和工具许可规则；`interrupt()` 用于停止当前 turn，`stopTask()` 用于停止后台任务，二者不同。SDK 权限回调 `canUseTool` 不应单独当作全量执行审计，诊断文档建议记录 SDK／CLI 版本、session_id、结果和错误。W3 的只读 PATH／常见目录探测未找到 `qoder`，不证明客户端不存在。〔官方：[Qoder CLI Release Notes](https://docs.qoder.com/release-notes/qoder-cli)；[SDK permissions](https://docs.qoder.com/cli/sdk/permissions)；[SDK how it works](https://docs.qoder.com/cli/sdk/how-it-works)；[SDK troubleshooting](https://docs.qoder.com/cli/sdk/troubleshooting)〕

### 千问办公（QwenWork）

按法师所给界面（「日常／工作」「定时计划」「技能」「连接」「查看云端任务」）与阿里云帮助资料，识别为千问办公桌面端，而非 Qwen Code CLI。官方桌面更新记录列 `1.4.0`（2026-10-28）；本机截图未显示应用版本。官方资料区分桌面本地调度与 Web 云端定时任务；桌面任务执行后可查看执行记录／独立会话，本地调度在电脑睡眠或关机时不会按时触发。Windows 电脑控制有“每次询问”（官方默认）、“自动”“禁用”等设置；系统磁盘权限与电脑控制策略是不同权限面。截图可见“全部访问”，但本轮未核清该标签具体绑定哪项权限，不能将其等同于“电脑控制自动”。官方资料未找到可由外部工作台启动／取消桌面在途任务的公开 API；来信排队不是取消证据。〔官方：[桌面更新日志](https://docs.qwenwork.cn/release-notes/desktop)；[桌面定时任务](https://help.aliyun.com/zh/qwenwork/qwenwork-scheduled-tasks-desktop)；[电脑控制](https://help.aliyun.com/zh/qwenwork/computer-use)；[系统设置](https://help.aliyun.com/zh/qwenwork/system-settings)；[Windows 安装说明](https://help.aliyun.com/zh/qwenwork/desktop-usage)〕
