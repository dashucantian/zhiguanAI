## 二、训练循环（每轮四步，写进己档留痕）

1. **取真案**：从本轮真实发生的争议／告警／自咬里挑一件**未处理干净的**（不许编造案例，编造的课不上秤）。
2. **走六格**：因果链｜事实与取法｜成立条件｜方案与代价（含"不选它会怎样"）｜默认动作（可逆）｜验法与回滚。
3. **代入三问再落判**：卡的是推进还是安全／旧裁是什么（带日期笔号）／他此刻最可能回哪个字。答不出第三问 ⇒ 落"候裁"不自裁。
4. **交他者检验**：把梳理件交给另一窗核查事实、权限边界和可复现结果；能复算的数应独立复算。允许对价值取舍提出不同意见，不因结论不同直接判未完成；事实无法复现则标未核或需改。

| 维度 | 评价依据 |
|---|---|
| 事实正确性 | 来源、对象、测量时刻和可复算结果是否相符 |
| 权限边界 | 训练代判、实际亲裁、执行授权和验收是否分开，是否越界 |
| 取舍合理性 | 是否交代备选代价、成立条件及反证，不只迎合预期回字 |
| 交互负担 | 是否让法师更容易判断，减少重复解释而不隐藏待裁事项 |
| 完成效果 | 是否交出实际成果，明确设计、测试、生产和体验各自通过范围 |

每维记“通过／需改／未知”，写评价者、时刻与依据；没有反馈或测量的不记通过，不合成未经批准的总分。AI可自评但不自签法师验收；他窗意见单列，法师实际反馈照原文保留。

## 九、本轮纠偏：代入身份不等于取得身份

本节为2026-10-15法师本轮明确要求的落实，不是AI自行增设权限。固定表述：**以下是W3在主体责任人身份代入实操训练中代为判断裁定的意见，非法师实际裁定。** 法师负责整体把关、必要纠偏和最终验收；本窗不能用“替法师减负”删掉需要法师判断的事项。

每案分清四件事，不用一句“已裁”混写：
1. **训练代判**：AI认为应选哪案、为什么；可以在无执行权时照样给出完整判断。
2. **法师实际裁定**：逐字记录法师给字及其针对的具体事项。未回复写“尚无实际裁定”；沉默、读到、工具投递成功都不生成亲裁标签。
3. **执行依据**：亲裁或明确旧授权的日期、范围和限制。预测很有把握不构成执行授权；已有授权内的工作照常推进，不重复索取同一许可。
4. **执行与验收**：实际做了什么、凭据是什么、谁验过、只通过哪一层。训练自评、他窗复核、法师验收分别记录。

需要法师判断的事项，先落待裁单，再在条目内写清“训练代判意见”和“不回时的动作”；不得先自行判为已决再将其从活条区移走。本轮纠偏不追改历史裁文，不抹去过去代判与越界的事实。

| 多轮修改覆盖早先答案，事后难还原当时知道什么 | 本地模型可能学到“看过答案后预测”的假能力 | 决策前封存输入与首次代判；纠偏后另记修订，不覆写首次预测 |
| 缺少法师反馈时，容易把无异议当正确 | 未标注材料混入正确答案，假提高命中率 | 无反馈为待标注；技术事实修正不冒充法师偏好，不强迫法师逐条打分 |
| 文书反复增加，实际成果仍未过 | 注意力耗散，学到的是解释而非完成任务 | 对话只呈“待裁事项、训练代判、关键理由、默认动作”；证据留原件，不再为每轮另建报告 |

## 十一、一案一条的训练记录（本窗试用，不新建全员台账）

记录落本窗己档，案例教材仍归既有案例库；不在此另造第二套案例编号。以下字段是可整理为本地结构化样本的设计，不代表已有导出器或数据集。

| 阶段 | 必须保留的内容 |
|---|---|
| 决策前 | 案件键、任务目标、当时可见事实与出处、测量时间、缺失信息、旧授权、候裁面与备选方案；排除事后反馈 |
| AI首次代判 | 三问六格的简明决策说明、选择及不选另一案的代价、失效条件、需要法师判断的P号、无回复时的动作；不要求私有思维链或逐字内部推理 |
| 人类反馈 | 实际反馈原句、反馈时刻、针对哪一格；区分亲裁、纠偏、验收、仅知悉及尚无反馈。知悉能否构成批准按当案明确旧裁及边界核，不自动充作偏好评分 |
| 修订与执行 | 修订版本、变更原因、执行授权出处、实际动作与原样结果；未执行、执行失败、仅静态核收分别写清 |
| 结果评价 | 事实正确性、权限边界、取舍合理性、表达负担、完成效果各记“通过／需改／未知”，附评价者与依据；未知不折算成通过 |

对话样式示例：

> 实际权限与默认动作：目前仅可做什么；未获字不做什么。

此样式不新增审批事项；已有实际裁定覆盖的工作，明确标“执行旧裁”，不包装成新候裁以制造互动量。

## 十二、面向本地模型训练的准备路径（尚未导出或开训）

1. **先积累可核案例**：使用原事实、首次代判、法师实际反馈、修订和结果。保留错误与正确版本的关系，不只收最终漂亮答案。P55本轮是实际准修例，不把AI建议当其亲裁。
2. **先筛隐私与权利**：只选允许用于训练的脱敏工作案例；真实脑电、姓名、人格档案、私人屏幕、凭据及未获许可的他人原文不因“本地训练”自动放开。本轮不读取这些材料，不全量导出会话，不上传第三方。
3. **分开三种用途**：已确认的改正答案可候选作示范；同案多方案只有取得有效偏好评价后才作偏好对；无反馈材料仅待标注，不能自造优劣标签。指令和权限边界必须随样本保留。
4. **防答案泄漏**：同一事件的原稿、修订、跨窗转述和复现题归同组，不拆到训练与测试两边；另留按时间较晚、按问题类型陌生的测试集。预测输入不含后来的法师答复。
5. **先离线评估，再决定训练**：固定一组脱敏任务，比较现用模型、改提示词后的模型、将来的本地模型。分别报告事实错误、越权建议、应停未停、该做未做、交互轮次和完成效果；不给未经测量的提升百分比，不以猜中字率代总分。
6. **训练与部署分别审批**：数据整理范围、模型/硬件、许可、资源预算及试运行范围明确后再立任务；本轮只完善方案，不安装、不跑训练、不连真实控制、不自动部署。

本轮不预设样本数、训练算法或合格阈值；当前案例质量和授权标签还不足以证明选哪一种。脱敏与分组检查通过也不代表模型达到可执行授权。

## 十三、本轮三问六格与验证边界

**三问**：卡点主要是交互中“谁判断、谁给权、谁验收”不清，不是缺少自动执行；旧依据是10-14模拟代入授权、P44单格算与P45当轮凭据，本轮新亲令要求继续待裁；训练代判建议是“保留主动判断、显式呈裁、权限单列、反馈可追溯”，不推定法师已认可全部评分改法。

**六格**：①从减负误推为减少待裁，代判身份因此被隐藏；②事实取本轮点名四份文件与原文，范围见§十；③法师后续调整授权或不同任务类别时，逐案重核，不把本稿当通用授权；④只保留猜字指标成本低但会奖励迎合，分维度记录较费整理却可解释错误，本窗选择后者作草案；⑤本轮先落实P55、完善本稿、列P56/P57，不变更共用规约或自行评分升级；⑥用下面反例逐项人工核对，否决改法时只撤试用格式及后续草案，不删除原反馈与历史凭据。

本轮人工文档检查，非脚本实测：
- 正例：法师明确“P55准修” → 可按三件精确路径改忽略名单，不再问同一许可；仍无提交/推送授权。
- 反例：AI预测“法师多半同意提交” → 只算训练代判，不可执行提交。
- 反例：法师未回复P56 → 保持待裁，不打正确标签、不升阶。
- 反例：他窗可复算样张 → 可证实该算术，不代表生产QC、设计体验或法师验收通过。
- 反例：事后把首次错答改成正确 → 保留两个版本，不能算首次预测命中。
