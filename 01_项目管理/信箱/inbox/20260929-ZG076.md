## 二、三项工作

### ① 新增数据源「NeuraDock 指标 API（HTTP）」（旁证源）

- 输入形态建议与 TCP 那条**分栏**：本栏只收 `IP:端口`（或允许整条 URL 但须剥 `http://` 与尾斜杠），**拼路径由程序负责**（`/api/v1/metrics`）。
- 取数方式二选一或并存：轮询 `/api/v1/metrics`（页面自报 `window_sec 4`、`step_sec 1`，**1 秒节奏够用**）；或订阅 SSE `/api/v1/stream`（省轮询，但断线要能自恢复）。
- 面板上须与自研 α/θ/β **并排显示、明显区分**，建议标注来源与 `app_version`、`session_state`、`quality.grade`。
- **质量不足时按对方口径显示 `blocked`／不出分，我方不得补值、不得插值**（对方已声明"质量不足时返回 blocked，不会补值"，我方要保留这个语义）。

### ② 修「地址解析无兜底导致界面永久滞留」

- 位置：`console_server.py` 约 **712–716 行**——对地址串按**第一个冒号**切分后直接取整作端口，**无异常兜底**；用户粘贴 `http://…` 时切出的"端口"含非数字，取整即抛。
- 前端：`console.html` 约 **1683 行**在发请求**之前**就写"正在连接数据源…"，故后端异常时界面**永久停留且无报错**。`console.html` **1066 行注释**已记录过同类滞留（断流/代理空闲/服务端饥饿），本条是**同一现象的第二个成因**。
- 要求：**格式非法 → 1 秒内中文可读报错并说明期望格式**；后端异常须回传前端并结束"正在连接"态；顺带把 1066 行那类既有滞留一并纳入同一错误通道（不强制扩大范围，若判断超界请在回执说明）。

### ③ 写死旁证源边界（三句，进注释与数据字典）

1. **该源只输出算好的分数与质量，不含原始脑电**（`raw_eeg_exposed: false`）⇒ **不参与 `qc_pipeline.py` 任何判定，不替代原始流入库，不进 Zen-EEG 数据工厂**。
2. **其指标公式与权重对方未公开**（`formula_version: null`）⇒ 我方只作**并排旁证与差异观察**，**不采信为真值、不据此改我方阈值**。
3. **该 API 随对方桌面程序生命周期浮动、端口不固定** ⇒ 任何会话存档须**同时记下当次端口与 `app_version`**，否则事后无法复现。
