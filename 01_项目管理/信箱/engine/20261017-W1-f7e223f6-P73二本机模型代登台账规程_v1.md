## 一、第 0 步：先现查监听与进程名（这一步本身不许省）

命令原文（Git Bash，本窗 22:44—22:45 就是这样跑的）：

```
cmd //c "netstat -ano -p tcp" | grep -E "1235|50219"
powershell -NoProfile -Command "Get-Process -Id <上一步查到的PID> | Select-Object Id,ProcessName"
cmd //c "netstat -ano -p tcp" | awk '$NF==<PID>'
```

PowerShell 侧更短的两条（等价）：

```
Get-NetTCPConnection -State Listen -LocalPort 1235,50219 | Select-Object LocalAddress,LocalPort,OwningProcess
Get-Process -Id (Get-NetTCPConnection -State Listen -LocalPort 50219).OwningProcess | Select-Object ProcessName
```

**判据（三条全过才继续）**：
- 1235 与 50219 的 `LocalAddress` **只出现 `127.0.0.1`**（`0.0.0.0`、网卡地址、`192.168…` 一律算违规）；
- 进程名＝转发侧 `Bionic`、模型侧 `llama-server`（名字换了就要查清是谁，别默认同一个服务）；
- 这两个 PID 名下**没有任何一条连到本机之外的会话**（第三条命令列出的所有行都应是 `127.0.0.1`）。

本窗 10-17 22:45:18 现势留底：1235→PID 7268（Bionic，常驻 277.4 MB）只绑 `127.0.0.1`；50219→PID 31552（llama-server，常驻 8,904.8 MB）只绑 `127.0.0.1`；该两 PID 名下共三条监听，全是回路，**零条对外会话**。
⚠这一组数是**活的**（PID 会随重启变、常驻会浮动），只在那一刻成立，下一次跑**必须重取**，不许沿抄本段。

## 三、第 2 步：让本机模型出这一行——请求体一律走文件

**硬动作（W3 实测过的坑，别再踩）**：中文不许写在命令行参数里。系统 ANSI 代码页会把参数改写，模型收到的是乱码。正确做法＝**先用 UTF-8 写成一个文件，再 `--data-binary @那个文件`**。

```
# 1) 用 UTF-8 写请求体（本窗用 Write 工具落文件，不用 echo）
#    文件内容形如：{"model":"qwen3.8-27b","messages":[{"role":"user","content":"…"}],"max_tokens":…}
curl --silent --show-error --max-time 90 ^
     -X POST "http://127.0.0.1:1235/v1/chat/completions" ^
     -H "Content-Type: application/json; charset=utf-8" ^
     --data-binary @请求体.json -o 应答.json
```

**四条都要判，不许只看有没有回话**：
1. 退码＝0；
2. `应答.json` 按 UTF-8 解得开、中文不乱；
3. `choices[0].finish_reason` 是正常结束（不是被截断）；
4. 端点串里是 `127.0.0.1`——**粘成 `localhost` 也要先解析确认落在回路，规程一律直接写 `127.0.0.1`**。

模型只负责**把要登记的话组织成一行**；它写出来的行**先当草稿**，没回读核对之前，不算已登记。
