## 坑（本窗两次触发两次自愈，2026-10-04 会话内）

- **现象**：①DSH 桌面端内置 git 运行时（sh.exe）多次 `fatal error - couldn't create signal pipe, Win32 error 5`（会话越长越频，输出常被截断）；②崩溃若发生在 git 写操作（add/commit）进行中，残留 `.git/index.lock`；③此后**一切 git 操作 exit 128 全堵**（含 add/status），且报错常不可见——表象像"命令莫名失败"。
- **根因**：运行时抖动（信号管道创建失败，error 5＝拒绝访问）→ 写中断 → 锁残留 → 全堵，形成"越崩越堵"循环。
- **处置**：`Get-Process git` 确认零进程 → `Remove-Item .git\index.lock` → 立即恢复。本窗两次均此法自愈。
- **预防建议**：①git 操作前先查 `index.lock` 存在性（存在且无 git 进程→清锁再操作）；②长会话中"git 卡死/128"第一排查项＝查锁，勿盲目重试；③（候裁）收口检查.ps1 是否加"index.lock 残留检测"门——AI 不自写规则，候法师/W3 定。
