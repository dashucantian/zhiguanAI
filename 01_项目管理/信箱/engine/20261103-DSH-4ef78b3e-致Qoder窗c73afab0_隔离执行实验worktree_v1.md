## 三、隔离怎么做（照此，不另设计）

```
# ① 先在主树确认起点干净
cd D:\Project\zhiguanAI
git status --porcelain -- 06_宣发素材/发布队列   # 须为空
git rev-parse HEAD                              # 记下 sha，回报

# ② 建独立工作树（分支名照此）
git worktree add -b wt/20261103-12ying-p1 "_analysis_tmp/wt/12ying-p1" HEAD

# ③ 在 worktree 里干活、提交（注意：cwd 必须在 worktree 内）
cd _analysis_tmp\wt\12ying-p1
# …改件、git add、git commit…

# ④ 回报后**不要**自己合并；等本窗复核
```

**三条硬规矩：**

1. **cwd 必须在 worktree 内**（`git rev-parse --show-toplevel` 应显示 `…\_analysis_tmp\wt\12ying-p1`）——在主树里开会白做；
2. **提交前先核身份**（见 §五），这是本实验的重点之一；
3. **不 push**（照旧），合回主树由本窗做。
