## 二、所以乙要改的不是一处，是三处

| 要改 | 有没有落点 |
|---|---|
| ① `base-url` → `https://opencode.ai/zen/go/v1` | ✅ 有，一行 |
| ② **发 `x-opencode-session` 头** | ❌ **无落点**——该组结构只有 `base-url`／`keys`／`models`／`name`，**无 `headers` 键**；全局 `passthrough-headers: false`（`:280`） |
| ③ 改模型名（`deepseek-v4.1-flash-free`→`deepseek-v4.1-flash`；`gpt-6-astra` 在 Go 目录里**不存在**，须删或换） | ✅ 有，但连带影响配这两个别名的客户端 |

**②是硬阻。** 改了①②不齐，只会把「429 免费额度到顶」换成「400 缺头」——**从"能看懂为什么失败"变成"看不懂为什么失败"，严格更坏**。

## 三、另有两条路（我不自行选，报法师）

### 案一：把那组**删或禁用**（最小、可撤）

**理由**：它今天 **0 成功**（管家记 31 次全败：付费 402／免费 429），**留着只占位并误导**——它挂着一个叫「OpenCode Console」的名字，看着像能用。

- **好处**：不再有人拿它试；不再误解「Go 接不上是因为路径」。
- **风险**：若有客户端配置引用了它的别名（`止观-日常`／`止观-重活`），删后那些调用会变成「模型不存在」而不是 429——**但它们今天本来也是失败的**，功能上无损失。
- **可撤**：改前备份 `config.yaml`，一字即可恢复。

### 案二：开 `passthrough-headers: true`＋改路径＋改模型名

**只有 OpenCode 客户端可能通**（它自己带 session 头），**Codex／Claude Code 不带**，仍 400。

- **风险**：`passthrough-headers` 是**全局开关**，一开影响全部 provider，不只 opencode 这一组。**为救一个从没成功过的组，动全局行为，不划算。**

### 案三：**不碰 CPA，走管家 8791 代理**（我推荐这条）

管家代理本来就能**自动补 `x-opencode-session`**（它自测里有这条断言）。所以正确的接法不是修 CPA，是：

```
客户端 → 管家代理 127.0.0.1:8791（补头＋记账）→ Go 真上游
```

**这条同时解了甲（DSH 指代理）与乙（CPA 那组）**，且只需要动客户端指向，不需要动 CPA 的 provider 配置。

**代价**：要客户端改指向；DSH 侧仍须法师一句（改的是本会话运行时）。
