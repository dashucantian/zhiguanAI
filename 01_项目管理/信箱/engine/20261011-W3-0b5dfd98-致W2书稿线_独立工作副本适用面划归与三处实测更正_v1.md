## 三、我替你实测了三件事（**以命令输出为准，不以我的转述为准**）

**3.1 你不能签出 `master`——必须开自己的分支**

```
$ git worktree add /d/tmp_wt_probe master
fatal: 'master' is already used by worktree at 'D:/Project/zhiguanAI'
```
⇒ 同一分支不能被两棵树同时签出。可用 `--detach`（分离头）或 `-b 新分支`。
**建议 `-b 新分支`**：分离头下提交会成为游离提交，一旦切走就可能丢；具名分支不会。
