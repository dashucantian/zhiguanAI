## 一、一句话形状

**零点不是"停"，是一个有回复力的吸引子。**段 3 演的就是：从零点被拉离 → 沿正或负的一极摆开 → 靠惯性过冲 → 衰减回中。摆的过程本身即"运相承载变化"，回中后的安静即"绝对安静仍是坐标原点"。

由此得两条硬指标，本段一切设计都为它们服务：

| 指标 | 说法 | 可验形式 |
|---|---|---|
| 张力 | 偏离后**会自己回来**（有回复力，不是开关切换） | 段末 `abs(t) ≤ ε`，且回中是衰减的、不是瞬时的 |
| 动量 | 回来时**会过冲**（不是一条单调曲线归零） | `t` 序列符号至少翻转一次 |

## 二、载体＝张力层（一阶阻尼振荡）

`t` 为标量张力位，范围 `[−1, +1]`，`t=0` 即零点。段 3 内按二阶动力学走：

```
每帧：vt += (-k * t - c * vt) * dt      // k＝回复刚度，c＝阻尼
      t  += vt * dt
```

段 3 起点给一次初速度（`vt = v0`，`t` 从 0 起步），此后不再外力推——**偏离是一次性的，回中是被动力学拉回来的**，所以"过程"看得见，且不是脚本播放的动画。

**参数按段长归一，不直接写 `k`／`c`。**理由：`SEGSEC` 默认 20s、闸门档 `segsec=2`，同一组绝对刚度在 2s 里只走完五分之一摆 ⇒ 判据 10 的"符号翻转"在快档下必不成立。故写两个无量纲设计量，运行时由段长反推：

```
N    = 2      // 段内摆回数（须为整数，理由见下方"段末归零是构造成立的"）
zeta = 0.34   // 阻尼比：<0.7 才有可见过冲；越接近 1 越不回摆
ω_d  = 2πN / SEG ;  ω_n = ω_d / sqrt(1 - zeta^2)
k    = ω_n^2 ;  c = 2 * zeta * ω_n
v0   = firstPeak * ω_d / exp(-zeta*ω_n*τp),  τp = atan(ω_d/(zeta*ω_n)) / ω_d
```

实数两档对照（**10-12 落码后实测已回填**，见下方"实测"栏）：

⚠**先更正一处我自己算错的段长**：`SEG` 不是 `segsec`，而是**变化段自身的时长** `STAGES[2].dur = SEGSEC × SYNTH_SEQ.length`（代码现势 343-349 行）。默认档 `segsec=20` ⇒ 段3＝**80s**；闸门档 `segsec=2` ⇒ 段3＝**8s**。上表早先按 20s／2s 立算，`ω_d`、`k`、`c`、`v0` 与整条时线因此都偏了 4 倍，照下面重出。

| 档 | 段3 时长 | ω_d | k | c | v0 | 解析首摆 | 实测峰（60fps） |
|---|---|---|---|---|---|---|---|
| 默认 `segsec=20` | 80s | 0.1571 | 0.02790 | 0.1136 | **0.2078／s** | 0.85 | ≈0.787（同一离散比例） |
| 闸门 `segsec=2` | 8s | 1.5708 | 2.7899 | 1.1358 | **2.0783／s** | 0.85 | **0.7866（实测）** |

默认档时线（按 80s 重出）：峰谷 `+0.85(7.79)／−0.55(27.79)／+0.36(47.79)／−0.23(67.79)`，过零在 `20／40／60／80s`，**符号翻转 4 次**（＝2N，非上一轮写的 3 次）。一摆周期 40s——比三路呼吸（34／26／13s）还慢，正合总则 3「一切新增运动周期 ≥20s」。
**段末归零是构造成立的，不是靠阻尼衰减凑的**：`ω_d·seg3 = 2πN` ⇒ `t(seg3) = (v0/ω_d)·e^(−ζω_n·seg3)·sin(2πN) ≡ 0`。判据 10 的 `ε` 只用来挡帧对齐误差，取 `ε=0.02`；**首摆之外各摆的幅度**才由衰减定（`e^(−ζπ) ≈ 0.34` ⇒ 每摆约为前一摆的三分之一）。
⚠`N` 取整数是这一层的结构前提（为的是"段末必在中线上"）；改成非整数即 §八 反证 c10c。
⚠**实测峰 0.7866 ＜ 解析 0.85，差 7.4%，根因是积分形不是公式错**：页面用半隐式欧拉 `vt += (-k·t - c·vt)·dt; t += vt·dt`，逐帧复算（node）给出 30fps→0.7741／60fps→0.7866／90fps→0.7909，**与页面实测 0.7866 逐位对上**；同一复算的段末残值 0.00070 与翻转 4 次也与页面读数一致 ⇒ 三方互证成立。帧率间离散幅度约 ±2%，真机 72／90fps 落在 0.787–0.791，**本窗不改 `v0` 去凑 0.85**（凑了就把"设计意图量"又变回绑帧率的快照），改为把 `firstPeak` 读作名义幅、实测以判据 10 落档。
⚠`zeta` 的下界由"不适即停"看着（欠阻尼→摆不停）；上界由判据 10 的"须翻转"看着。两端都有反证，见 §八。
⚠`zeta` 的下界由"不适即停"看着（欠阻尼→摆不停）；上界由判据 10 的"须翻转"看着。两端都有反证，见 §八。

`t` 的**符号**决定偏向哪一极：`t>0` 走四对的"阳面"，`t<0` 走"阴面"。两极始终同时在场——一极占优时另一极以等量反向退为背景，这就是"张力"而不是"切换"。

## 三、四对落成参数，四对留空候义理〔法师 10-12 追认「可」〕

八对按"能否只用**场景里已有的物理量**表达、且不引入价值判级"过一遍：

| 对 | 落不落 | 绑到哪个已有量（默认档倍率＝1／偏移＝0） | 正向（`t>0`） | 负向（`t<0`） |
|---|---|---|---|---|
| 动静 | **落** | 三路呼吸的**相位速率**（`rate` 进累加相位式，**不是**乘在输出上） | 动：相位略快（±10%） | 静：相位略慢 |
| 阴阳 | **落** | `scene.fog.density` **绝对**偏移（现势 0.025，呼吸摆幅 0.0040） | 露：雾略薄（±0.0035） | 藏：雾略厚 |
| 明暗 | **落** | `glow.scale` **相对**倍率（现势 1.0，呼吸 ±4%） | 明：晕略张（±6%） | 暗：晕略敛 |
| 显隐 | **落** | 三层材质 `op` 的**相对**共同倍率（现势 0.85／0.55／0.70，呼吸 ±4%） | 显：结构浮出（±10%） | 隐：退回雾中 |
| 苦乐 | **留空** | — | — | — |
| 得失 | **留空** | — | — | — |
| 善恶 | **留空** | — | — | — |
| 美丑 | **留空** | — | — | — |

**量纲一栏（相对／绝对）是这一表的目的，不是脚注**：`op`／`glow` 走相对倍率，是为了保持三层 0.85／0.55／0.70 的既有比例（那比例属已认可构图，绝对偏移会把中层推进负值或把内层顶出 1.0）；`fog` 走绝对偏移，因为它是密度不是比例。

**动静轴的实现形（本稿第二次自纠）**：现势三路都是 `sin(2π·t/period + phase)`，`t` 直接取墙上时钟。⚠**把倍率乘在输出上只会改幅度、不会改快慢**——初稿写"只乘在下游输出上"是错的，与上一条 `k/c` 同族的错（都是把"量值"与"速率"混了）。要动快慢只能累加相位：

```
phi += (2π * dt / period) * rate ;  rate = 1 + t * weight
```

⚠**但累加式与墙上时钟原式不逐字节等价**：现势 `dt` 有 `Math.min(dt, 0.5)` 钳大间隙（防跳变），一旦被钳，累加器就**永久落后**墙上时钟。⇒ **默认档（不带 `?tension=`）必须仍走原式 `sin(2π·t/period + phase)`**，只有 `?tension=pos|neg` 才切累加器，且切入时把 `phi` 初始化成原式此刻的相位以保证连续。这条是判据 9（默认档逐字节）的承重前提，不是风格偏好。

**后四对为何留空（照实说，不是回避）**：这四对的词本身带价值／修持判级。把它们做成一个可量化的场景偏移，等于用画面给一坐判定级——直接撞红线②（不显示修持评分）与三原则「组织证据不裁定」。本窗的处置是**留其"张力"的形式，不采其"内容"**：四对一律不进参数字典、不进阈值、不进闭环。
**先例同形**：四透镜形状 1 落地时同样是"三栏留空候义理"（`45d73e8`），只 RDoC 一栏可直验。
⚠留空 ≠ 本窗否认这四对是张力。本窗不自裁其场景对应，**候义理线／法师一句**；届时若落，须先过红线②这一关。

**为什么四对而不是一根总旋钮**：四轴各有独立权重与响应速度（雾最慢、光晕最快），`t` 一个标量驱动四轴按各自权重与滞后展开，画面才是"多对一起摆"而非"整体变亮变暗"。权重写在注册表里（§五），代码内不写死。

## 四、默认档一寸不让（本稿的承重墙）

1. **无 `?tension=` ⇒ 张力层恒 `t=0`，倍率＝1、偏移＝0 ⇒ 场景输出与现势逐字节相同。**S1 回归锚"两帧差 0.0000"、静态纪律（无粒子／无 bloom／无定时器）全部**照旧绿**，且本层不得成为它们的例外。
2. **三路呼吸的常量（`amp:0.0040`／`period:34`／错相 120°／`tau=周期/6`）与 `v4lotuspond` 几何一字不改**——张力层只作用在这些量的**输出形**上（三路改走相位累加、雾走密度偏移、光晕与透明度走相对倍率），常量本体与参数源仍是单一正源。
3. `?tension=pos|neg|off` 为显式三档，`pos|neg` 定 `v0` 的符号，**默认 URL 永远是零点**。
   ✅法师 10-12 追认「**成立**」⇒ 底账 §八.8 那条自约（"默认 URL 永远是零点且不许调"）**就此销案**；静态闸不会反打本设计。
4. **不适即停**：`|t|≤1` 为硬钳位；速率钳位**写成无量纲倍式** `|vt| ≤ maxSlew · firstPeak · ω_d`（`maxSlew=1.8`），**不写"每秒"也不写"单帧"**——见 §五末注，这条是本稿第三次自纠；任一轴偏移越界即钉在边界并记 `tension_clipped` 事件；`?tension=off` 一键全关。真机首跑须法师在场（金口#7）。

## 五、进注册表的方式（红线⑦）

在 `VARIANTS.v4lotuspond` 内**同一对象**下新增一节，与 `fog`／`op`／`glow` 同源，闸从注册表读：

```js
tension: {
  N: 2, zeta: 0.34, firstPeak: 0.85,   // 设计量；k/c/v0 由段长反推（§二），不写死
  maxT: 1, maxSlew: 1.8,               // 钳位：|t|≤1；|vt|≤maxSlew·firstPeak·ω_d（无量纲）
  axes: {
    dongjing: { channel: 'phaseRate', weight: 0.10,   unit: '相对' }, // 相位速率 ±10%
    yinyang:  { channel: 'fog',       weight: 0.0035, unit: '绝对' }, // 密度 ±0.0035
    mingan:   { channel: 'glow',      weight: 0.06,   unit: '相对' }, // 光晕 ±6%
    xianyin:  { channel: 'opacity',   weight: 0.10,   unit: '相对' }, // 三层同倍率 ±10%
  },   // 苦乐／得失／善恶／美丑：刻意不在 axes 内，留空即账面（§三）
}
```

**为什么写 `N/zeta/firstPeak/maxSlew` 而把 `k/c/v0` 交给反推**：`k`／`c`／`v0` 都是有量纲、绑段长的数（`v0 ∝ 1/SEG`，见 §二 表），写进注册表就等于存了一份"当前段长下的快照"，段长一改（`segsec` 就是干这个的）账面与运行时分叉。`N`／`zeta`／`firstPeak`／`maxSlew` 是设计意图本身，跨两档同形。
`maxSlew` 这条按倍式写、既不用"每秒"也不用"单帧"：
- **写"单帧"错在帧率**——30fps 下一帧 0.033s，正常首摆的每帧变化量随帧率漂，把一个正常值判成越界。
- **写"每秒"也错在段长**——上一轮我改成 `|vt|≤1.4 每秒`，当时以为"帧率无关"就稳了；其实段3 短则 `v0` 大（`v0 ∝ 1/段3`，闸门档 8s 下 `v0=2.08/s`），**1.4/s 会在起手就把运动钉在钳位上**，两档根本不同形。倍式 `maxSlew·firstPeak·ω_d` 在两档下分别得 **0.240 与 2.403**，对名义 `v0`（**0.208 与 2.078**）都是同样 20% 余量——**这才是"两档同形"在钳位层的落点**（实测 `clipped=false`，钳位未咬）。

- ⚠**不新增变体条目**（张力是层，不是变体）。若日后要做成对比版，须进 `status:'留档'` 机制，由闸过滤，**禁在 `vr_gates/` 里另写一份清单**（红线⑦；`verify_mandala_variants.py:169` 那处旧病灶仍未修，归 W3）。
