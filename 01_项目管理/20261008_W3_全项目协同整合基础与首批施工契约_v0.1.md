## 1. 战略主线与成功标准

宗旨沿用 AI-开工入口.md:6：修行体系是根，人机协同设施是器；AI组织证据，人裁定结论；协作而非控制；观察与反馈优先。

三条工作流共同服务可复刻、可日常使用的应用：
1. 体验流：The Journey 设计理念与风格形式研究 → 虚实互解互构的设计转译 → VR样段 → 体感验证 → 完整使用路径。
2. 证据流：采集质量与来源 → 记录与入库 → 从此学习/评估 → 有边界的反馈 → 复盘。学习发生不等于有效益。
3. 协作流：意图 → 任务与授权 → 承接 → 施工 → 检验 → 独立复核 → 必要的人验收 → 版本交付 → 反馈修订。

阶段完成看三个结果，不看文件数量：用户实际入口得到认可版本；各窗无需重问全部背景即可续工；项目外使用者依交付材料能完成指定流程。第三项尚未由本轮验证。

### 1.2 依赖与反馈循环

- 数据主线给反馈主线提供可信输入及用途边界；设计主线给反馈主线提供体验目标与表达边界。两者缺一，均不能把真实脑电直接映射成修持评价。
- 协同主线支撑全部任务的授权、承接、证据与版本关系；不要求先建完所有工具才能推进离线设计和合成试验。
- 反馈主线用合成数据先验证机制，获批后再做在场真机验证；真实异常回到数据/设计契约修订，而非临时调参后抹去失败记录。
- 生态主线形成“提出需求→分工承接→可复刻交付→自愿试用→分类反馈→独立复核→法师裁定→版本改进”的循环；义理意见、使用障碍、安全事件和测量发现分别处理。
- 普及化与文明基座是长期愿景；当前阶段承诺的是一个可进入、可退出、可恢复、可追溯的完整流程，不宣称生态智能或通用效果已经成立。
