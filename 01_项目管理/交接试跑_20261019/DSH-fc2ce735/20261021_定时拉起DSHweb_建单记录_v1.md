## 二、为什么不是裸跑 `dsh --profile web`（这一条要说明白）

`dsh --profile web --help` 现读＝**"Serve the DeepSeek Harness browser UI"**，参数 `--host／--port／--no-open`——它是**起一个 Web 服务**，不是起界面进程。所以裸跑每 2 小时会有两个副作用：端口已占时反复失败刷日志、`--open` 默认还会每 2 小时弹一次浏览器。
故包了一层 `dsh_web_wake.ps1`，只做三件事：
1. **先探端口** `127.0.0.1:48000`（＝`DSH_WEB_URL` 的端口）：**能连＝已在跑 ⇒ 只记一行、不拉**（幂等，避免堆积）；
2. 不能连才 `Start-Process dsh.cmd --profile web --no-open --port 48000 -WindowStyle Hidden`；
3. 结果一律追加到 `_analysis_tmp\dsh_web_wake.log`，**不改任何项目件**。
