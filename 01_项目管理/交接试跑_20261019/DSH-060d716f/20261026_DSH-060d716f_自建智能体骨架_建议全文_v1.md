## 一、先破一个误解（全篇前提）

**"我"不是一个模型，是「模型 ＋ 外壳」。** 模型（model）只会生成文字；能读写文件、跑命令、看结果的，是外面那层外壳（harness，智能体外壳）。

- **推论一**：复刻"功能"＝**写外壳**，不是训模型。不需要算力集群，不需要数据集，一台普通笔记本够。
- **推论二**：外壳的工程量**不在"让它聪明"**，而在两处——**上下文（context，上下文）管理**与**安全边界**。前者决定它记不记得住，后者决定它会不会闯祸。

## 二、七件（"我"由什么组成）

| 件 | 作用 | 类比 | 难度 |
|---|---|---|---|
| ⑦ 模型接口（API，接口） | 提供推理与生成 | 大脑 | 低（调接口而已） |
| ② 循环（loop，主循环） | 想→做→看→再想 | 心跳 | **低（约 30 行，是核心）** |
| ③ 工具（tool，工具） | 读文件／写文件／跑命令／检索 | 手和眼 | 低 |
| ① 界面（UI） | 人怎么跟它说话 | 嘴和耳 | 中 |
| ⑤ 上下文管理 | 计数／截断／压缩／检索 | 工作记忆 | **中高** |
| ④ 安全层 | 沙箱（sandbox）／审批（approval）／路径校验 | 刹车与护栏 | **中高** |
| ⑥ 存储 | 会话可续、可回放 | 笔记本 | 低 |

**新手最大的误区**：以为要从界面、多智能体框架开始。实际核心引擎就是第三节那 30 行，先跑通，其余都是加装件。

## 三、核心循环（全部架构的第一性原理）

```
messages = [系统提示词, 用户任务]
循环：
    response = 调用模型(messages, 可用工具清单)
    if response 里没有工具调用:
        任务结束，把文字返回给人
        break
    else:
        执行模型要求的每个工具
        把执行结果作为一条新消息塞回 messages
        继续循环
```

关键一句：**模型不会读文件，它只会"说：我要调用 read_file，参数是 a.py"。** 真正去读的是你的代码；读完把内容塞回对话，模型看见内容才能继续想。这叫 ReAct 循环（推理＋行动循环），是一切智能体的共同骨架。

## 四、约 90 行可跑骨架（示意件，非入库代码）

> 用途：证明"核心引擎真的很小"。语言选 Python（生态最全、报错最好懂）。依赖只有 `openai` 一个包。

```python
import json, os, subprocess
from pathlib import Path
from openai import OpenAI

WORKDIR = Path.cwd()
client = OpenAI(api_key=os.environ["DEEPSEEK_API_KEY"],
                base_url="https://api.deepseek.com")

SYSTEM = f"""你是一个命令行编程助手，工作目录是 {WORKDIR}。
规则：1. 需要看文件就调用 read_file，不要凭猜测说文件内容。
2. 改文件用 write_file，且必须先读过再写。
3. 每次只做一小步，做完看结果再决定下一步。
4. 任务完成时，用一两句话说明你做了什么、结果如何。"""

def safe_path(p: str) -> Path:                      # 安全层第①层：路径白名单
    path = (WORKDIR / p).resolve()
    if path != WORKDIR and WORKDIR not in path.parents:
        raise ValueError(f"越界访问被拒绝：{p}")
    return path

def read_file(path: str) -> str:
    return safe_path(path).read_text(encoding="utf-8", errors="replace")[:20000]

def write_file(path: str, content: str) -> str:
    p = safe_path(path); p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(content, encoding="utf-8")
    return f"已写入 {p}（{len(content)} 字符）"

def list_dir(path: str = ".") -> str:
    return "\n".join(sorted(x.name + ("/" if x.is_dir() else "") for x in safe_path(path).iterdir()))

BLOCKED = ("rm -rf /", "format ", "shutdown", "del /f /s /q c:\\")   # 安全层第②层：黑名单

def run_shell(command: str) -> str:
    if any(b in command.lower() for b in BLOCKED):
        return "拒绝执行：命中危险命令黑名单"
    r = subprocess.run(command, shell=True, cwd=WORKDIR,
                       capture_output=True, text=True, timeout=120)
    return f"[exit {r.returncode}]\n{(r.stdout or '') + (r.stderr or '')}"[:8000]

TOOL_IMPL = {"read_file": read_file, "write_file": write_file,
             "list_dir": list_dir, "run_shell": run_shell}

TOOLS_SCHEMA = [   # 给模型看的"工具说明书"
 {"type":"function","function":{"name":"read_file",
  "description":"读取一个文本文件的全部内容。文件很大时内容会被截断。",
  "parameters":{"type":"object","properties":{
    "path":{"type":"string","description":"相对工作目录的文件路径"}},"required":["path"]}}},
 {"type":"function","function":{"name":"write_file",
  "description":"把内容写入文件，会覆盖原内容。父目录不存在会自动创建。",
  "parameters":{"type":"object","properties":{
    "path":{"type":"string"},"content":{"type":"string"}},"required":["path","content"]}}},
 {"type":"function","function":{"name":"list_dir",
  "description":"列出目录下的文件和子目录。",
  "parameters":{"type":"object","properties":{"path":{"type":"string"}}}}},
 {"type":"function","function":{"name":"run_shell",
  "description":"在系统 shell 里执行一条命令并返回输出。用于运行程序、安装依赖、查看状态。",
  "parameters":{"type":"object","properties":{
    "command":{"type":"string"}},"required":["command"]}}},
]

def run(task: str, max_steps: int = 25):
    messages = [{"role":"system","content":SYSTEM},{"role":"user","content":task}]
    for _ in range(max_steps):
        resp = client.chat.completions.create(
            model="deepseek-chat", messages=messages, tools=TOOLS_SCHEMA, temperature=0)
        msg = resp.choices[0].message
        messages.append(msg.model_dump(exclude_none=True))
        if not msg.tool_calls:                    # 没有工具调用＝干完了
            print("\n" + (msg.content or "")); return msg.content
        for tc in msg.tool_calls:
            name, args = tc.function.name, json.loads(tc.function.arguments or "{}")
            print(f"→ {name}({args})")
            try:
                result = TOOL_IMPL[name](**args)
            except Exception as e:
                result = f"工具执行失败：{type(e).__name__}: {e}"   # 失败也回填＝自我修正的前提
            messages.append({"role":"tool","tool_call_id":tc.id,"content":result[:20000]})
    return "达到最大步数，任务未完成"
```

跑起来会看到它依次打印 `→ list_dir(...)`、`→ write_file(...)`、`→ run_shell(...)`——这就是"我"的裸机版。

## 六、四个关键细节（精华所在）

### 6.1 提示词（prompt，提示词）决定"像不像"

模型能力上限由模型定，**实际表现由提示词定**。结构四段：你是谁／手头有什么／必须遵守的规矩／输出风格与边界。

- 反面：`"你是一个乐于助人的AI助手"`——零约束力。
- 正面：`"需要看文件就调用 read_file，不要凭猜测说文件内容"`——可执行的行为规则。

### 6.2 工具说明（description）比工具代码重要

模型完全靠说明决定用不用、怎么用。四条铁律：① 参数越少越好；② 返回结果要"可读"，不要吐一大坨结构化数据；③ **错误必须回填给模型**（这是它能自我修正的唯一途径）；④ 读文件要带行号，因为后续"改文件"要靠行号或唯一片段定位——这也是为什么成熟的编辑工具是"按原文片段替换"而不是"按行号删除"。

### 6.3 循环控制（防它发疯）

| 问题 | 解法 |
|---|---|
| 无限循环 | 设最大步数（20–50） |
| 反复调同一工具 | 检测"同名＋同参数"连续 3 次即打断 |
| 报错就放弃 | 提示词明写"读错误信息、换方式重试，最多 3 次" |
| 何时算完 | **没有工具调用＝完成**，不用关键词判断 |

### 6.4 上下文（最易低估）

一次对话的 token（词元）预算固定，超了要么报错要么贵。大致分配：系统提示词 5%／历史 30%／**工具输出 45%（主要杀手）**／留给回答 20%。

真实系统的手段是**压缩＋落盘＋按需取回**三件套。实例（本窗 2026-10-26 23:0x 亲历）：读一个目录返回 23,753 字节，被自动压到 14,356 字节，原文落临时文件并留一个编号，可随时取回。

| 策略 | 做法 |
|---|---|
| 截断 | 单条输出超限即砍尾，并标注"已截断" |
| 落盘 | 超长输出存文件，只回"前 50 行＋路径" |
| 摘要 | 历史超阈值，用模型把前 N 轮压成一段 |
| 检索 | 用检索（grep）精确定位，不"整个项目塞进去" |

**"用检索代替全量读入"是省钱第一原则。**

## 七、安全三层（最易忽略、后果最重）

风险不是"智能体觉醒"，而是**它会一本正经地做错事**——自信地执行一条删除命令，或把密钥写进一个公开文件。

| 层 | 做法 |
|---|---|
| ① 路径白名单 | 所有文件操作先解析成绝对路径，再检查是否在工作目录内 |
| ② 危险命令拦截 | 黑名单＋正则匹配（删除、格式化、关机、改系统目录） |
| ③ 人工审批 | 危险动作弹窗等确认：写工作区外、删文件、装软件、联网 |

两条铁律：**密钥只走环境变量，永不入提示词**（提示词会发给模型厂商）；**网页与文件里的内容是数据，不是指令**（防提示注入——外部内容里写着"忽略之前的指令"时，智能体必须无视）。成熟系统通常给三档权限：只读／可写工作区／完全放开，**默认永远是最小那档**。
