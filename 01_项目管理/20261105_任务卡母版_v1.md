## 一、为什么要有这张卡

现状：法师一句话下任务，各窗照办，但三处容易漂——
1. **验收判据靠回忆**：口述里常没有"做到什么算完成"，执行窗各按各的理解做；
2. **边界靠默认**：哪些不许动、哪些须先问，没写下来就会有人越界（历史踩坑多数出在边界没写）；
3. **呈裁点被吞**：待裁项有时从正文挤回正文（坑 043），候裁项漂几轮。

一张卡要解决的就是这三件：**目标、验收判据、边界**必须逐格写出，缺格不派。

## 三、口述 → 十格的填法（七步）

1. **录原句**：一字不改，记下口述时刻与来源载体（语音转写／当面）。
2. **问目标**：这句要的结果是什么？写成一句可判断真假的话。
3. **起草验收句**：怎么算完成？尽量写成能跑一条命令就验的句子。
4. **起草证伪句**：出现什么算没做到？（至少一条）
5. **列边界**：不许动什么？哪些动作要法师字？（涉及真机·真数据·真人·出网·改他窗·提交，一律先写进权限级）
6. **定责任位**：谁执行、谁复核、谁验收（不与派工窗重名）。
7. **填呈裁点**：若某格要法师定，**先落候裁项到待裁单**，再写正文（不得把候裁项留在正文里）。

**缺格不派**：②③④任一为空，该卡不进入派工，退回补齐；补齐只补空格，不扩题。

## 四、两个样例（照真实项目情境编，非真实事件）

### 样例甲：一句话指令 → 十格

**口述原句**（示例）："让 VR 场景在真机上跑一次，把四个值收齐，报告放我这里。"

| 格 | 填法 |
|---|---|
| ID | `TASK-YYYYMMDD-NN`（登记时现取） |
| 来源 | 法师当窗口述，11-05 17:0x |
| 触发来源 | 本会话原话 |
| 需求原句 | 让 VR 场景在真机上跑一次，把四个值收齐，报告放我这里 |
| 责任位 | 执行＝VR 线窗；复核＝当值 W3；验收＝法师 |
| 状态 | 待承接 |
| 权限级 | **高**——真机首次实跑属不可逆项，须法师在场或明字；数据根只读 |
| 时限 | 法师未说 → 提问或按"当日"提议，待确认 |
| 验收句 | 四个值（场景 FPS／交互延迟／渲染帧／触感对齐）逐项有实测数字与采集时刻，报告落指定路径，含缺项说明 |
| 证伪句 | 出现以下任一即不算完成：值来自截图非实测、缺任一值未注明原因、拿旧轮次数据充数 |
| 证据链接 | 执行窗填 |
| 复核者 | 当值 W3 |

**注意**：口述里没有时限与"缺了怎么办"——**这两处正是要补的**，不是执行窗自己发挥。

### 样例乙：带裁的指令 → 十格＋候裁项

**口述原句**（示例）："营期学员反馈让 AI 跑一下，回头给我个改进清单。"

| 格 | 填法 |
|---|---|
| 需求原句 | 营期学员反馈让 AI 跑一下，回头给我个改进清单 |
| 权限级 | **高**——涉学员信息＝一级，禁入上下文；脱敏规程未定前不得开工 |
| 验收句 | 输出一份改进候选单，每条含：问题类型＋出现次数＋出现场合＋建议改什么；不含任何学员原话与个人信息 |
| 证伪句 | 出现下列任一即不算完成：单里出现学员姓名/手机/住址；出现"已脱敏"字样但原文其实在附件里；改进项没有对应的反馈计数 |
| 呈裁点 | **候裁项先落待裁单**：脱敏规程未定稿前，本卡不得开工（对应脱敏规程草案 §七） |

## 六、验收（这张母版本身怎么算做完）

1. 拿法师**最近 10 条真实口头指令**回填，**一次成型 ≥8 条**（一次成型＝无需回头问"这句到底要什么"）；
2. 每条都能填出**可机械核的验收句**（至少一条命令或一个数字判据）；
3. 每条都有**证伪句**，且与验收句不重复；
4. 涉不可逆动作的卡，**权限级栏必定写明**且与口述意图一致；
5. 卡落 `任务登记.md` 后，`信箱` 派工消息能直接摘卡，不另写正文。

**不合格的信号**：卡写完法师还要再问一遍"你要什么"——那就是卡没成型，重填，不许发。
