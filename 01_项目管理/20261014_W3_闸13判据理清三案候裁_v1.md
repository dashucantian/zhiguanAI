## 二、理清楚：这道闸其实要防**三格不同的病**，此前被混成一句话

- **病 A｜误报超限**：把"已决留字行"一起数进 8 行上限。10-13 起就在报（页头自报活行 6、闸数到 15），P35 换行首形状时顺手解决——**属裁文范围内**。
- **病 B｜哑闸**：页面形制再被改一次，判据没跟着改 ⇒ 数到 0 行、静默报绿，这一门等于不存在。**法师点名的正是这一格**。
- **病 C｜假红骚扰决策面**：待裁单清空＝项目最健康的状态，却被"数到 0 即 Bad"判成失配，每轮报红。**这格是本窗自加码造出来的，原本不存在**。

⇒ 三格病要三种判据，**我当时想用一条"数到 0 就红"同时管 B 和 C，必然一头不对**。"理清楚"这一步本来就该在做之前跑，我跳过了——这是比"自加"更早的一环，也是法师这句复令指的东西。

## 三、三案（各防哪格、代价、要不要动不准修文件）

| 案 | 判据 | 防 A | 防 B | 防 C | 改动面 | 实测凭据 |
|---|---|---|---|---|---|---|
| **甲**（＝现势） | 只数行首形状，零条报绿 | ✅ | ❌ 形制再改即静默绿 | ✅ | **零改动** | 实跑 `[OK] 活行 4` |
| **乙**（本窗建议） | **两侧对照**：行首尺数出的活行数必须等于页头自报「现 N 条待裁」；一致 ⇒ 数到 0 也算真 0 报绿；不一致或页头无自报 ⇒ 报红 | ✅ | ✅ | ✅ | `收口检查.ps1` 第 13 门一段（＋9／－3），**属不准修名单，需您「准修」＋「提交」两道字**；另须在 §二.16⑦ 补一句"页头必须永远带自报数"（该句是裁文的延伸，也需您给字） | 六例自测全过：0/0 绿、1/1 绿、自报 1 尺 0 红、页头无自报 红、9/9 未上报 红、9/9 已上报 绿（`_analysis_tmp/gate13_selftest_1014.ps1`） |

**取舍要说清的两句**：
1. 乙的可靠性来自一个**外部约定**：页头那一行"现 N 条待裁"必须永远存在且永远由数出来写。这条约定本身要靠 §二.16⑦ 那句补文才成立，所以乙是"判据＋条文"两件事一起裁，不是只改脚本。
2. 甲不是安全态——它是**法师点名的哑闸原样**。留着甲＝默认接受"下一次改版式时这一门会静默失效"。这一点此前被我的"一律撤回"掩盖了，照直摆出来。

## 四、"一律撤回"这一步错在哪（照直认，不辩）

- 您的令是"钉住私自改规矩"。我做的动作是"把两处自加全撤到最小态"。事后重看：**撤与装是同一种动作——都在替这道闸定判据**，只是方向相反。正解次序＝**先理清（§二那三格）→ 摆案（§三）→ 候裁 → 才谈撤到哪一格**。
- 后果两笔：①病 B 重新暴露（现在形制再改就是哑闸）；②一个已测过的可用方案被我扔在一旁、没呈给您，等于让您的裁量面少了一项。
- 这与"私自改规矩"是**同一根的第二个果**：都是**没先取证就动手**。已写进复现 005 第 4 步，不再单列成两种病。
- 本窗不自裁的意思不是"什么都自己决定个相反的"——是把选择权连同后果一起摆到您面前，然后停手。**停手不等于回退到最差态**。

## 五、乙案备装补丁（待命，未应用；给「乙」字即照此一段替换）

```powershell
    $ls13 = [System.IO.File]::ReadAllLines($dj13, [System.Text.Encoding]::UTF8)
    # 法师裁 P35「准」放行面＝行首形状一行；本段"两侧对照"判据系法师另裁（待裁单 P39 回乙）后加装，非本窗自加。
    $rows13 = @($ls13 | Where-Object { $_ -match '^## P[0-9]+ ' })
    $head13 = ($ls13 | Select-Object -First 6) -join "`n"
    $rep13 = [regex]::Match($head13, '现\s*(\d+)\s*条待裁')
    if (-not $rep13.Success) {
        Bad "闸13：页头六行内没有自报「现 N 条待裁」，本门无从对账——须现读页首并同步本行判据。"
    } elseif ([int]$rep13.Groups[1].Value -ne $rows13.Count) {
        Bad "闸13：两侧对不上——页头自报 $($rep13.Groups[1].Value) 条，行首尺数到 $($rows13.Count) 条。判据失配即不可信，不得各报各的。"
    } elseif ($rows13.Count -le 8) {
        Ok "闸13：待裁单活行 $($rows13.Count) 行 ≤ 上限 8，页头自报与行首尺一致（数到 0 亦为真 0）。"
    } else {
        if ($head13 -match '示删并|放宽到') {
            Ok "闸13：待裁单活行 $($rows13.Count) 行＝超上限 $($rows13.Count - 8) 行，头部已照直上报「请您示删并或放宽」（§二.16③ 合规；本门不判该不该超，只判有没有瞒着消数）。"
        } else {
            Bad "闸13：活行 $($rows13.Count) 行已超上限 8，但头部六行内无上报字样——正是 §二.16③ 禁止的形状，须照直上报并附可合并清单。"
        }
    }
```

配套条文补文（同批，§二.16⑦ 检查点句之后一行）：**页头必须永远带一行"现 N 条待裁（上限 8）"，N 由数出来写、不得凭印象填**；该行同时是闸 13 的对账基准，删它即本门报红。
