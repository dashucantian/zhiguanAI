## 二、Go 走充值余额的完整打通

### 2.1 问题定位（先分家，再动手）

法师补充 10.00 美元后，管家对所有 Go 模型一律返回 503。**故障点不在上游，在管家自己的本机额度快照闸**：

### 2.2 改了什么

| 文件 | 改动 |
|---|---|
| `ai_router/plans.py` | 新增两个池名常量：「按月总额度」「超额按量余额」 |
| `ai_router/store.py` | 新增 `consume_pool`（按次扣减，带锁）、`pool_remaining_by_name`、`go_billing_mode` |
| `ai_router/pools.py` | `go_billing_mode()` 决定放行与封顶口径；走余额时不吃订阅的每模型封顶与三层窗口 |
| `ai_router/router.py` | 余额模式下跳过封顶与窗口判定，并在理由里写明「按月总额度已用尽，现在走充值余额按量计费」 |
| `ai_router/proxy.py` | 记账时取上游实际扣款 `usage.cost`，新增账本栏「计费来源」，并按次扣减余额池 |

### 2.3 三条口径

1. **放行口径**：按月总额度还有 → 照旧走订阅；用尽但充值余额还有 → 放行走余额（上游自动改按量价计费，不再受每模型封顶约束）。
2. **记账口径**：金额取上游实际扣款，不按本机估价；账本多一栏「计费来源」，写「按月总额度」或「超额按量余额」。
3. **守额口径**：余额池按次扣减，扣到 0 为止；余额那笔**不进**订阅封顶的账，11-19 重置后订阅额度仍是干净的。

## 五、Token Plan 密钥怎么设在用户级环境变量

Token Plan 的密钥本机没有，百炼那个池因此判为不可用。两种走法，二选一。

### 走法甲：您在系统里设一个用户级环境变量（推荐，不需要给我任何密钥）

1. 按 Win 键，输「环境变量」，点「编辑系统环境变量」。
2. 在上半格「用户变量」那一栏，点「新建」。
3. 变量名填：`TOKEN_PLAN_API_KEY`（一字不差，别加空格）。
4. 变量值：把 Token Plan 后台给的那串密钥粘进去。
5. 点「确定」，一路「确定」关掉。
6. 密钥不用告诉我，也不用发到任何对话里——它只是写进您自己电脑的环境变量，本机代理读得到，别人读不到。

设完不用重启电脑，也不用重启管家。管家每次取密钥都是现读用户级环境变量，您设完立刻生效。

想确认设上了：开一个新的命令提示符窗口，敲 `echo %TOKEN_PLAN_API_KEY%`，能打出一串东西就成了
（打不出来就是还没生效，检查变量名有没有多空格）。

### 走法乙：您授权我去读 DSH 的凭据

您回一句「授权 AI-028 读 DSH 凭据」就行。读到的密钥同样只进环境变量、不落盘、不进日志。
