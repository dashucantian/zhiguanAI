# AI 调用管家

管你手上三个订阅：**OpenCode Go**（美元额度）、**百炼 Token Plan**（Credits）、**Qoder 积分**。
它做三件事：告诉你这个活该走哪个订阅、用一个本机代理自动分流、把每一笔花的钱记在本地账本上。

全在本机跑。密钥只从环境变量读，不落盘、不进日志、账本文件不进版本库。

---

## 一、第一次用（三步）

**第一步：双击 `调用管家.cmd`**
弹出一个中文菜单，按序号选就行。

**第二步：把三个订阅的剩余额度抄进去**
菜单里选「录额度」，把百炼和 Qoder 的剩余积分填进去（抄官网上的数字即可）。
OpenCode Go 不用抄，它的每模型封顶是固定的，管家自己知道。

> **一个渠道可以分好几个池。** Qoder 就有三个池（套餐内积分、资源包、Qwen 专属积分），
> 到期日各不相同，得分开录，管家才能提醒你哪个快过期。录的时候它会问「这是哪个池子」。
> 同样，每个池的到期日、刷新日也一起填进去。

**第三步（可选，但省事）：把客户端指到本机代理**
见下面第三节。不做也能用，只是省不了自动分流。

## 三、接本机代理（自动分流的正戏）

**代理是干什么的**：你的编码客户端（Claude Code、Kilo Code、jcode 等）本来直接打 OpenCode，
现在改打本机的代理。代理按规则挑一个最省的模型再转发出去，同时把这一笔记进账本。

**为什么值得**：OpenCode 官方的「预计请求数」是按每次 7 万多 token 算的，
你的实际每次用了二十几万 token，所以消耗比预估快好几倍。代理能实时看到实际 token 数，
并且把贵模型自动换成便宜的，这是省钱的主要来源。

**怎么接**：

1. 先起代理：双击 `启动代理.cmd`（窗口开着别关）。
2. 菜单里选「配置」，照着打印出来的片段填进你的客户端：
   - 接口地址填 `http://127.0.0.1:8791/v1`
   - 模型名填 `auto`（写 `auto` 才会自动选；写死模型名就照你指定的走）
   - 密钥填不填都行；要填就填你自己定的那串，并且客户端和代理两边一致

**接 Go 通道时，代理自动替你补两样东西**，你自己不用管：
- 一个会话头（Go 上游缺了会直接报 400）。
- 一个像浏览器的客户端标识（Go 上游前面挡着 Cloudflare，用默认标识会被挡成 403）。

**代理的规矩**：
- 只绑本机 `127.0.0.1`，别的机器连不上。
- 上游密钥只从环境变量 `OPENCODE_API_KEY` 读，代理不代你从任何地方找密钥。
- 某个模型这个月用满封顶的九成，就自动不再用它，改用更省的；全打满就退到免费模型。
- 上下文特别大时，自动避开封顶只有 15 美元的那几个贵模型。
- 每次调用在 `数据\审计.log` 留一行，带任务号、时刻、HTTP 码、花费、耗时。

**还有一条容易踩的账**：
Go 的额度除了「这个月多少美元」，还有更细的三层窗口——5 小时占两成、一周占五成、一个月占满。
**月度还剩一半，也可能因为某个 5 小时窗口烧穿了而被限速**（2026-11-03 零点那 13 分钟连打 42 次，
把 grok-4.7 的 5 小时窗口烧到 129% 就是这么来的）。代理会盯着这三个窗口，
接近上限时提前提醒并改派更省的模型。

**Windows 上设环境变量**（只对当前窗口有效，关掉就没了，不落盘）：

```
set AI_ROUTER_TOKEN=你自己定的一串字符
set OPENCODE_API_KEY=你的Go密钥
set AI_ROUTER_PORT=8791
```

## 四、几个数字从哪来

- 每模型美元封顶、单价：OpenCode 官方文档（opencode.ai 的 Console 文档页）。
- 百炼各档 Credits 与价格：阿里云百炼 Token Plan 官方文档。
- Qoder 各模式积分消耗：Qoder 官方 Credits 说明（参考值，不是计费值）。

**这些数字在 `ai_router\plans.py` 一个文件里**，是唯一真值源。要改价改上限，只改这一个文件。

**口径提醒**：OpenCode 官方那个「预计请求数」是**按每次 7 万多 token 折算出来的次数**，
不是赠送的调用次数。上下文越长，实际能跑的次数越少，两者差得很远。

## 七、边界

- 不替你找密钥、不替你登录、不替你点官网页面。
- 不读你的项目代码，不改你的仓库文件（账本只写在自己的「数据」目录里）。
- 不做智能体编排，只做「这个活该走哪个订阅」的判断和转发。
- 个人版百炼不许拿来做生产自动化，所以代理只代理 OpenCode，不代理百炼。

## 八、跟 EasyCLIProxyAPI 什么关系

**两回事，别混。** EasyCLIProxyAPI 是第三方转换器，主要干三件事：Codex 账号池、协议转换、失败重试。
它跟 OpenCode Go 的订阅额度互不相干。

**实测结论（2026-11-04）**：
- 真正在烧 Go 额度的是 **DSH**，它直连 `https://opencode.ai/zen/go/v1`，3,366 次、约 22.69 美元。
- EasyCLIProxyAPI 里那个 `openai-compatibility` 组指的是 `https://opencode.ai/inference/v1`，
  **那是另一条计费路径，不是 Go**；同一个密钥在那儿 31 次全失败（付费模型报 402、免费模型报 429）。
- 所以 EasyCLIProxyAPI **既没消耗你的 Go 额度，也不是 Go 通道的正确接法**。

**留不留它**：只留 Codex OAuth 账号池和协议转换的话，就留着，同时把它那个白占 provider 位的组改掉或删掉；
若只是为了走 Go，那就别用它，直接用本代理。

## 九、把调用挂到任务号上（跟任务中枢对接的那根轴）

**为什么**：任务中枢管「谁在做什么」，任务看板管「进度到哪」。
只有这个管家知道「这条任务花了多少钱」。两边要接上，缺的就是**任务号**这一根轴——
任务号一旦挂上，成本就能按任务回流，看板能按任务显示花费，巡检也能在额度触顶时点名是哪条任务烧的。

**任务号从哪来**（先到先得）：

1. 客户端带的头 `x-task-id`（最准，每个客户端各挂各的）；
2. 面板里「设当前任务」设的（**一次设定，所有走本代理的调用都算在这个任务号下**，不用改任何客户端）；
3. 代理环境变量 `AI_ROUTER_TASK_ID`（启动时的默认）；
4. 都没有 → 记「未标记」（**不猜、不编**，事后一眼看出哪些活没挂上任务）。

**怎么设**（面板里选「设当前任务」）：

```
python ai_router/cli.py 设当前任务 --设置 TASK-20261104-02 --工作区 D:/Project/zhiguanAI
python ai_router/cli.py 按任务看账
```

**给每个客户端各挂各的**（面板里选「配置」会打印同样的片段）：
- OpenCode：provider 的 `options` 里加 `"headers": {"x-task-id": "TASK-20261104-02"}`
- Codex：`~/.codex/config.toml` 的 `[model_providers.ai-router]` 里加 `http_headers = { "x-task-id" = "TASK-20261104-02" }`
- DSH：`settings.yaml` 的 provider 下加 `headers: {"x-task-id": "..."}`
- Claude Code：`settings.json` 的 `env` 里加 `ANTHROPIC_CUSTOM_HEADERS="x-task-id: TASK-20261104-02"`
  （这一条**以你手上版本为准**，本机没装 Claude Code，没验过；不认这个变量就退回「设当前任务」，效果一样）

**两条限制**：
- HTTP 头只能带 ASCII 字符，所以**头里的任务号用英文或数字**（`TASK-20261104-02` 这种）；
  中文任务名走「设当前任务」那条路。
- 任务号会被清洗：换行、空格、竖杠等换成横杠，截到 64 字符——否则一条脏任务号能拼出一条假日志。

## 十、派工前先问一句（派工选型）

**为什么有这条**：任务中枢派工时，最容易漏的是「这个活该走哪条通道、大概花多少」。
人凭印象派，常见结果是本该走免费模型的活扔进了贵模型，或者反过来。
派工选型就是把路由层已有的判断整理成一段**能直接抄进派工单的话**。

**怎么用**：

```
python ai_router/cli.py 派工选型 --任务 改码 --上下文 中 --无人值守 --任务号 TASK-20261104-02
python ai_router/cli.py 派工选型 --任务 写作 --上下文 小 --任务号 TASK-20261104-02 --一行
```

**出长这样**：

```
【调用安排】TASK-20261104-02
活类：改码｜上下文：中（约 80000 token）｜无人值守：是
走哪条通道：OpenCode Go
用哪个模型：deepseek-v4.1-flash
预计花费：约 0.03 美元（按输入 80000 token、输出 2000 token 估，实际以账本为准）
为什么：无人值守的活走 OpenCode Go 的本机代理，按规则选最省的模型。
本月封顶余量：deepseek-v4.1-flash 封顶 100 美元，已用 8.95，还剩 91.05 美元
5 小时窗口占用：0%
一周窗口占用：18%
备选：beam-free、iceman-contributor-free、qoder、bailian
（生成时刻 2026-11-05 00:19:26；本段由本机调用管家生成，不写中枢、不改源表）
```

**一行版**（塞进表格或对话里）：
`TASK-20261104-02｜OpenCode Go｜deepseek-v4.1-flash｜预计 0.03 美元`

**边界**：
- 这是**只读出口**：它不写中枢、不改源表、不往账本写任何东西。谁把这段贴进派工单，是人的动作。
- 「预计花费」是按输入 token 与输出 2000 token 估的**估算值**，不是账单；实际以账本为准。
- 任务号不给时取本机「当前任务」设定；两处都没有会记「未标记」，并在结论里提醒你先去挂上。
- 「要联网搜索、图像、语音这类 Harness 能力」加 `--要联网搜索`，它会指到百炼 Harness。

## 十一、账本对账（任务号对不对得上）

**为什么有这条**：任务号唯一的正源是 `01_项目管理\任务登记.md` 里的 `TASK-YYYYMMDD-NN`。
账本是本机自己写的，万一某个号写错、写成别的系统编号、或者压根没挂上，得能一眼看出来，
而不是等到月底对不上才发愁。

**怎么用**：面板里选「对账」，或命令行 `python ai_router/cli.py 对账`。

**出四态**（口径照协调位 11-04 的裁）：

| 判定 | 什么意思 | 管家怎么办 |
|---|---|---|
| 合 | 这个号在任务登记里 | 正常入账 |
| 未标记 | 没挂上任务 | 单列一行，**必须看得见** |
| 外部号 | 像是别的系统的号（飞书 `ZG-xxx`、窗口号） | 原样记着，不猜、不改、不丢 |
| 笔误 | 跟某个已登记号只差写法（如少了分隔符） | 原样记着，等人确认 |

**为什么允许「未标记」**：不给出口，跑批和临时调用就会把号乱填一气；
给了出口但让它可见，才对得上账。**藏起来的未标记比明写出来的未标记危险。**

**工作区栏**：账本每行还记「工作区」。
面板「对账」会把它列出来，并指出这个路径**在不在盘**、**是不是隔离执行树**（在 `_worktrees` 之下且真实存在）。
代理记账时也会自动补：任务号对应的隔离树若在盘，就把它的路径填上——填的是实测存在的路径，不是随手写的字符串。
面板「设当前任务」同理：不给 `--工作区` 时，它自己去查这个任务号的隔离树在不在盘，在盘才填真路径，不在盘就留空并提示；人显式给的路径照用。
