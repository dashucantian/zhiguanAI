## 一、深链载荷格式（静态破译，无逆向工具，读 app.asar 明文 JS）

注册表：`HKCU\Software\Classes\qoder-cn` → Launcher.exe "%1"（state.ini 指向 `.qoder-versions\0.4.3\Qoder CN.exe`，Launcher 仅转发 argv）。

主进程 `deepLinkMainService`（t8e/xGr）＋路由解析器（_Gr/FGr）：

| 载荷 | 动作 | 校验 |
|---|---|---|
| `qoder-cn://discussion?discussionId=<uuid>` | 开讨论 | uuid v1–8 严格式 |
| `qoder-cn://issue?projectId=<uuid>&issueId=<uuid>` | 开 issue | 双 uuid |
| `qoder-cn://invite?token=…&scope=project\|discussion` | 受邀加入 | token base64url |
| `qoder-cn://aicoding.aicoding-deeplink/mcp/add?name=…&config=…` | **装 MCP 服务器** | 见下 |
| `qoder-cn://aicoding.aicoding-deeplink/extension/install?…` | 装插件/技能/MCP | descriptor |
| hostname `aicoding.aicoding-agent` 等 | 委托给 IDE | |
| `/agent` 路径 | **明令禁止**（DEEP_LINK_INTERNAL_ROUTE_FORBIDDEN） | |

硬约束：URL ≤32768 字符；禁 hash/username/password/port；队列 20 条、600 秒过期；同链接去重；未登录挂起。mcp/add 的 config＝base64(percent-encoded JSON)（链序：JSON→quote→base64→再 quote 避裸 `+`），≤256KB；name ≤512 字。

**结论：深链没有「发消息/开会话」路由——派活仍只能走 AI 窗口侧 MCP；但 mcp/add 是看板↔Qoder 的正式整合接口。**
