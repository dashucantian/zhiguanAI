## 三条规则

1. **一事一文件**：新的 KZ 订正、D 决策登记为本目录下 `KZ-<日期窗号>.md`／`D-<日期窗号>.md`（见下命名）。各窗口只新建自己的文件＝**结构性零冲突**，"他人占用"概念消失。
2. **日期窗号**：新编号格式 `KZ-0924-W2a`／`D-0924-W3a`（月日＋窗口＋当日窗内序）。**不需要查全局末行、天然唯一。** 旧流水号（KZ-001~028、D1~D49、日志≤053）永久只读、不改号不迁移；`00_总索引.md` 把新旧统一呈现。
3. **时限与代登**：
   - 公共**旧大文件**（台账／决策日志／日志 README §七）即日冻结为**遗留只读**，仅 W3／巡检线单写者维护，改动同轮必提交；
   - 他人**完整的**登记行滞留未提交 **>24h** → 任何窗口可逐字代提交，trailer 注明"代登 by Wx"；
   - "待登记"只是 ≤24h 的临时出口，不得常态化。

## 命名与格式

- 文件名：`KZ-0924-W2a.md`（日期＝裁定日，窗号从 Session 取，日内序 a/b/c）
- 正文必备四段：**背景**（哪条错/哪项裁定）、**裁定/订正原文**（逐字）、**影响落点**（哪些文件同步改了）、**边界**（不追溯范围）。
- 新工作日志：文件本身即天然分片（一事一文件已成立），其索引行由生成器汇总，不再手写进 README §七。
