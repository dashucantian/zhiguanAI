法师 2026-10-09 在本窗裁「**三点同意**」，对应 W3 提请三项：

## 二、制度正文（此后各窗照此，缺一位即算未署）

每个落 `01_项目管理\登记分片\` 的**新件**，在标题行 `# D-…｜…` 之下的**首个非空行**署一行：

```
署｜<任务号>｜<窗别>｜<sessionId前8位>｜<AI号>
```

- **五段固定序，四位分隔符全用全角 `｜`**；缺项写 `—` 占位，**不许省位**（省位会让解析结果串列，比缺项更坏）。
- **会话短号**＝完整 sessionId 前 8 位。与规约 §二.3 既有 `Window: 候核·<sessionId前8位>` **同形**，不是新造键；全 ID 由 `05_产品与开发\任务看板\board_config.py` 的 `WINDOWS` 40 行表反查。
- **任务号**＝开工号优先。开工号未取者写分片号本身；`分片号 ≠ 开工号` 时（先例＝D-1008-W1b「分片号到位≠开工号，仍未开工」）**写开工号，分片号已在文件名里，不重复**。
- **AI 号**＝AI-0xx 署名号，可多会话共用一号，不充当键（双键制，协调正本 §21）。

**适用范围只有 `登记分片\` 的新件。**三处不适用，勿套：

| 载体 | 为什么不适用 |
|---|---|
| 己档 `信箱\engine\巡检日志-*.txt` | 一日多任务，一行署不下；仍按会话分档（README ①bis） |
| 协调正本／各线讨论稿 | 多任务多轮，署行无稳定归位 |
| 历史分片 | 法师裁「不回填」；且循规约 §二.7「旧号永不迁移」与「历史提交不改写」 |

## 三、检查落点（旁路提示，非闸门）

检查加在 **W3 自己维护的** `登记分片\生成登记索引.py` 新增 **section E**，输出「本制后应署 N 件／缺 M 件＋清单／制前豁免 K 件」。首跑实测＝**应署 2／缺 0／豁免 107**。

**判据＝git 首次入库时刻**，不是文档内容里的日期，也不是文件名 MMDD：

| 情形 | 处置 | 为什么 |
|---|---|---|
| 已入库、首次入库时刻 **早于** `EFFECTIVE` | **豁免** | 制前旧件；法师裁「不回填」，把它们报成缺项＝变相逼回填 |
| **未入库**（git 里还没有） | **要求署名** | 本制后新件，提交前就该带上 |
| git 不可读 | section E **明写"本项未执行"** | 不静默判合格——宁可报不了，不可假通过 |

- 常量 `EFFECTIVE = "2026-10-09 15:30"`（法师三点同意时刻），**带年份 ⇒ 跨年自动无歧义**，不需手工更新。
- git 调用一律 `cwd=ROOT` ＋绝对 pathspec，避免相对路径歧义（见下方自曝第②条）。

> ⚠ **本窗两条自曝**
> **①判据第一版是错的，且错到违抗了您的裁定。**第一版按「分片**前六行**的首个 ISO 日期」判，实测把 **7 件制前旧件**报成缺项（D-0925-W3a／D-1007-W3a／D-1008-W3a／D-1008-W3b／D-1009-W3a／KZ-1009-W3a／KZ-1008-候核-ce059cf9）——**这等于变相要求回填，直接撞您裁的第 3 点**。根因＝**把"文档里提到的日期"当成了"文档创建的日期"**；而旧件正文出现新日期恰恰是登记制本身的常态（就地注记、订正记都往里写新日期），两者必然分离。这是本窗今日内**第三次**由自己的实测推翻自己刚交的产物（前两次＝GET 405 误判、467608a2 归因）。

边本来就该存在，只是没定格式。实测：`登记分片\` 现有 **109 件**，其中 **98 件**在正文提到了 8 位短号、**52 件**写了正式 Session 名，**全是散文、格式不一**；另规约 §二.3 已强制 commit trailer 带 `Window:`／`Session:`。
