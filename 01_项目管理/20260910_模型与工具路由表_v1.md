## 1. 三维路由原则

按 **数据敏感度 × 实时性 × 任务类型** 路由，**不按"模型参数大小"排座次**。

本机硬件背景【本机实证，2026-09-05 实测】：ROG Flow Z13 / Ryzen AI Max+ 395（Strix Halo）/ **64GB LPDDR5X 统一内存**（CPU 与核显共享同一池，**不存在独立显存与显存卸载**）/ Radeon 8060S 核显（RDNA3.5，40CU）/ **无 NVIDIA 独显，无法用 CUDA** / 瓶颈是**内存带宽**约 215–256 GB/s 而非容量。

三个本地模型均 Q4_K_M，合计约 **55.6GB**（27B 15.66 + 3.6-A3B 19.71 + Ornith 20.22），三者**均带 mmproj 视觉投影、均可看图**。推理走 llama.cpp 的 **Vulkan** 后端；绝对速度有限（MoE 基线约 49 tok/s，Dense 约 11.7–31.8 tok/s），**决定速度的是激活参数量而非总参数量**。

## 2. LLM 路由表

| 任务类型 | 首选 | 备选 / 说明 |
|---|---|---|
| **高频·实时**（日常对话、批量分类、标注预打标） | 本地 Qwen3.6-35B-A3B（MoE） | 本机带宽受限，MoE 激活参少→快 2–6×；09-05 实测开推测解码 69.4 tok/s |
| **代码 / agentic 攻坚**（muse-direct、控制台、BLE 排障） | 本地 Ornith-1.5-35B-A3B（SWE-bench 79, MIT） | 候选补充 Qwen3-Coder-30B-A3B；Ornith token 消耗高，**勿用于高频短文本** |
| **深度离线批处理**（规范精修、白皮书框架、周报综合、跨文档核校） | 本地 Qwen3.8-27B（Dense） | 读档理解力最强但最慢（11.7–31.8 tok/s），不进实时路径 |
| **截图 / 看图审计**（控制台、VR 场景、波形图） | **三个模型均可**（均有 mmproj），建议交叉互验 | 【本机实证】推翻"仅 Ornith 带视觉"前提 |
| **实时秒级引导语生成（VR）** | ⚠️ 本地核显延迟偏高；**非敏感禅修引导文可走云 Qwen-Max 保低延迟，EEG 数据仍留本地** | 需法师特别裁定（见第 5 节） |
| **联网调研 / 长文润色** | 云 API，**仅限非敏感内容** | 本地模型无实时网络；公开素材与通用调研可出网 |
| **事实核校** | **不得由产出方自证**，走独立联网核校或第二模型交叉 | 经验五 |

## 3. 专用小模型（非 LLM，全部本地不出网）

| 环节 | 首选 | 关键备注 |
|---|---|---|
| ASR 中文转写 | FunASR / SenseVoice | 量化版仅 254MB；中文优于 Whisper；⚠️pyannote 说话人分离须先在 HuggingFace 接受使用条款才能下载 |
| ASR 备选 | faster-whisper (large-v3) | int8 后约 10–16GB，ROCm/核显可用 |
| TTS（声音克隆） | CosyVoice 3.0 | Apache-2.0；CPU 路径延迟约 1.5–3s（**非实时**，适合预录引导） |
| TTS 低延迟兜底 | Kokoro-82M | <300ms，165MB，103 种中文音色，不支持克隆 |
| TTS ❌排除 | GPT-SoVITS | Windows+核显**跑不了**（须 Linux+ROCm+独显） |
| EEG 信号处理 | MNE-Python + MOABB + pyriemann | 行业标准；实时链路用 **MNE-LSL**（"MNE-RT"不存在） |
| 设备接入 | BrainFlow / BlueMuse(Muse) | Muse S：Windows 用 BlueMuse 桥接 LSL |
| 数据格式 | BIDS-EEG + mne-bids | OpenNeuro/PhysioNet 均接受 |
| 深度学习 | braindecode | Strix Halo 核显不在 ROCm 支持列表→建议 CPU 或 ONNX+DirectML |
| RAG 检索 | BGE-M3（约 2GB, CPU 可跑） | + Dify / RAGFlow 纯本地部署 |
| 图像/3D资产 | TripoSR(CPU出粗模) + SD3.5(DirectML贴图) + Open3D后处理 | ❌TRELLIS本机不可行（须云 CUDA）；高质量网格走云 |
