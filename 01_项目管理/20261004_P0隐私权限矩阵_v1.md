## 三、驾驶舱暴露面审计（核心发现）

1. 🔴 **`--host` 默认 `0.0.0.0`（console_server:3011）＋ `/api/file`（:2473，任意 path 读取）＋ `/vr_assets/{path}`（:2308）**：服务一旦以默认参数在 LAN 运行，**局域网内他人可经 HTTP 读工作区任意文件**——若工作区含一级类文件（修道班/学员/机密），即违背一级边界。VR 需 LAN（Pico 浏览器）故 0.0.0.0 有其用途，但**读取面无差别暴露是缺口**。
   - 处置候裁（并入 **N7 绑 LAN 议题**）：甲＝默认改 `127.0.0.1`，LAN 需显式 `--host`＋`/api/file` 加路径白名单（限 output/导出区）；乙＝维持 0.0.0.0 但 `/api/file` 强制白名单；丙＝仅受控场景（法师在场）运行 LAN。
2. `/api/session/*`、`/api/reports`、`/api/dashboard`：输出为**匿名编号**会话与聚合计数（合规前提＝匿名编号制）——逐字段核验候 v0.1。
3. TLS 8778：自签证书（SAN 至 2028）——传输加密现状可用，信任提示属已知体验。
4. 8777 现无监听（体检件 §一）——暴露面为**条件性**（服务运行时才存在）。
