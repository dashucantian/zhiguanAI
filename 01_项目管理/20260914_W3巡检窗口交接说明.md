## 六、本窗口的方法论教训（新窗口必读，避免重犯）

1. **把人为处置误读成事故**：LM Studio 空表是法师**主动删除**的结果，我却报"第一手资料不可逆丢失"并据此推出"抢救优先"的紧迫性。教训：**见到"空/缺失"先问是不是人为处置，再判断是不是事故**。
2. **勘查不完整即下结论**：只查全局空的 `ng-sessions.sqlite`（0.14MB），漏查各 project 目录下的同名库（15.2MB／3411 条）。教训：**同名文件须穷尽所有位置**，一处为空不等于全部为空。
3. **自造轮子且造错**：`_resolve_replay_path` 用了 `SCRIPT_DIR` 而非既有 `REPORT_DIR`，且项目早有 `_safe_join` 助手 —— 重复实现且实现错。教训：**加功能前先 grep 既有同类设施**。
4. **改变量漏改引用**：把 `Path` 改 `os.path` 时漏改 `np.load(p)` 的 `p`，`NameError` 被 `except` 吞成"读取失败"、会话启动即 idle。教训：**异常吞掉真错，except 分支须记原始异常**。
5. **测试没读错误通道**：第一次端到端没抓 SSE 事件流，所以上面那个 bug 没暴露。教训：**验证脚本必须把错误通道一并采集**，只看成功路径等于没测。
6. **单份样本标定即上线**：v2 用**一份 267 秒 baseline** 标定区间，在法师 42 分钟真机会话上 theta 饱和从 15.7% **恶化到 80.2%**。教训：**标定须多份数据，且须在不同时长/状态的数据上交叉验证**（W1 的 H-A′ 用分位排名从根上绕开了这个问题）。
7. **"编译/语法通过 ≠ 运行时正确"**：本窗口第 10~12 例（累计）。另注：**`node --check` 校验 HTML 内联 JS 时须排除 `type="importmap"` 块**，否则把 JSON 当 JS 解析会误报语法错误（本窗口踩过）。
8. **环境坑（PS 5.1）**：`Out-File` 默认写 **UTF-16 LE 带 BOM**，后续读取须 `decode("utf-16")`；内联 `python -c "..."` 引号会被吞 → **一律写 `.py` 文件再跑**；`2>&1` 会把原生命令 stderr 包成 ErrorRecord 致 `$?` 假失败 → 用 `$LASTEXITCODE`。
9. **browser-agent 是远程执行**，无法访问 `127.0.0.1`；测本机页面须用**本机 Edge + CDP**（`websockets` 已装）。另：headless Edge 用 SwiftShader 软件 WebGL，**canvas 尺寸非 0 才算渲染成功**（09-05 曾因远程无 GPU 误判 canvas=0）。
