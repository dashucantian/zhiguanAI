# 判语 007：不需 Agent 军团

> 判决日期：2026-09-06 | 状态：已定 | 影响范围：协作架构

## 判决

不需要自建多智能体编排框架（AutoGen、CrewAI、LangGraph 等）。用现成看板（飞书多维表格）＋ AI 助理定期汇总，足以满足任务贯通需求。

## 依据（可核验的事实）

- 单人决策＋AI 执行的项目，复杂度必须压到最低
- 多智能体编排框架本身需要数周学习调试，调试成本远超收益
- 部分框架在无 NVIDIA 独显的环境下兼容性存疑
- 验收瓶颈在人：VR 佩戴体验、禅修反馈节奏、脑电噪声阈值这些核心判断只有法师能做，Agent 产出再多也得逐一验证
- 单人项目的真正瓶颈是决策，不是产能

## 被否方案

- 自建"总管 Agent"：用航母打渔，调试成本过高
- 多智能体并行编排：上下文丢失严重，协调成本大于收益

## 可复用教训

"秘书 Agent"不是一个全能 Agent，是三个能力：状态可见（看板）、主动提醒（定时任务）、分派执行（AI 助理＋子 Agent 并行）。这三个能力用现成工具即可实现，无需自建编排框架。
