## 为什么容易犯

1. 中文文书大量使用**带圈号／顿号／全角标点**做列表，而惯性判据是 ASCII 正则（`^[0-9]+\.`、`^-\s`）。
2. Shell 里"结论性文字"和"判据数值"写在同一条命令中，**echo 不参与条件判断**，看起来却像报告。
3. 跨层断言（工具面／服务面／进程面）常被一句话完成，实际只取了一层。

## 对策（三条，都是可执行动作，不是提醒）

1. **报"没有"之前，先跑一次正向自检**：拿一个**已知存在**的同类样本，用**同一判据**去抓。抓不到＝**判据坏**，不是东西不存在。
   最小式：`printf '① test\n' | grep -cE '^[0-9]+\.'` → 0 即证明该判据不认带圈号。
2. **判据与解说分离**：一条命令只准输出**原始计数**，结论句必须由人（或后续行）生成；⛔禁止把 `echo "↑空＝…"` 放在无条件位置上充当读数。要条件化就写 `if` 或用 `-z "$n"` 判**变量**而非判**文案**。
3. **跨层否定须两层各取一次**：工具面（`mcp_list`）／服务面（`curl` 本机环回）／进程面（`netstat`／`tasklist`）**各自实测**，任一层为空只能否该层。本卡实例＝工具面 0 命中 **且** 服务面 200 有内容 ⇒ 结论只能是"注册缺失"，不能是"服务未起"。
4. **读结构之前先定形状**（丁型，10-13 21:0x 追补）：打开一个 JSON／嵌套对象，第一步**打印该件顶层键清单**（`list(json.load(open(p)))`），别照 API 载荷或另一个载体的形状猜文件。⛔**「缺失」（字段没写）与「钳位」（值落在带边界）是两种病灶、件数分开**，不许用同一个"8/9"糊过去。
5. **多个面／多个 probe 报数四件套**：面名＋probe 名＋取法＋时刻，缺一不报（本型实例＝34 与 33/1/2 两个数都对，差别全在有没有弃权闸）。**取证方式也要声明**："跳过长行"与"逐件认过噪音"是两种取证——本窗 21:02:39 复扫 `\biaf\b|IAF`（`re.I`）于 `*.py`／`*.html`／`*.js`／`*.css`（排除面照 L 窗声明再加 `muse2-repo`）＝10 件 180 处，除 `qc_pipeline.py` 42 处（写方＋自测⑦）外全是保存下来的第三方营销页与 venv 词法器这类噪音。〔⚠**22:26:39 本窗两次自改这一格**：①**单位钉死**（L 窗 21:10 函 §一 提请、本窗现跑复算与其一字不差）＝`grep -ci iaf qc_pipeline.py`＝**33** 是**命中行数**，`grep -oi iaf｜wc -l`＝**42** 是**出现次数**（一行可多次）；同件最长行 95 字符、>400 长行 0 条〔判据＝python 现读全文逐行计长，测 22:26:39〕⇒ **两式对同一批文本，差 9 纯粹是「行／次」两种单位、不是取证宽窄**。⇒ **凡报「N 处」须写明是「命中行」还是「出现次数」**，否则两个窗各说各话＝下一轮返工的种子（本条即该判据的第一次落地）。②**旧数自撤**＝那句「10 件 180 处」**照本行声明的面重跑跑不出来**〔测 22:26:39，三面各现跑：排 `_research_src`·`output`·`.venv`·`muse2-repo`＝**1 件／42 次／33 行**；只排 `muse2-repo`＝**40 件／254 次／197 行**；不跳过长行＝**307 件／68147 次／556 行**（单是浏览器 profile 里那几个压缩产物各占 6,001 次）〕⇒ 与 α 那条同因＝**句与面不符**，此格以后**只报成员表＋判据**。**结论一字不动**：真读方仍为零，`qc_pipeline.py`（写方＋自测⑦）之外全是噪音。〕
