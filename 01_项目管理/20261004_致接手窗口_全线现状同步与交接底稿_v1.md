## 二、硬纪律（违反代价最高的十条，逐条有出处）

1. **git 提交须法师逐批放行**——裸「提交」二字＝批准已摆出的清单；本窗不自行入库。禁 `add .`／禁 `commit -a`／**禁 push**／禁 amend·rebase。
2. **共享工作树 pathspec 纪律**——四窗（现更多）共用一个 index：只 `git add <本窗显式路径>`；新件先 add；共享 M 文件先核 diff 归属；**他窗 staged 原样不动**；`git commit -- <path>` 取的是**工作区全文**，同文件含他窗在途改动会搭车（本窗已实证一次：`closedloop_experiment.py` 的 A3 注记随 W3 `d38f819` 入 HEAD）。
3. **发现非本窗产生的变更 → 停下报告，不覆盖**（并发纪律④）。
4. **动采集/服务端代码前必现查** `GET /api/monitor/status` 的 `running`——不得复用本窗早前的检查结果（09-28 红线自曝教训，`D-0928-W1a` §三之二）。9600 同理：模拟器与真机互斥，跑前查空、跑后释放、禁挂账。
5. **编号先查后取**：ZG／D／KZ／日志号，扫描面＝索引末行 ∪ 当日实体文件标题号（只查索引防不住"有实体无索引"，`KZ-0924-W3b`）。撞号了就改号并留**改号记**。
6. **模拟数据＝验证自产，用后即删并报名**（删了哪些、几件，写进日志）。`save:false` 仍会落盘（已知行为，别当成 bug）。
7. **存证不许冒充**：跑不通写"未过／不可比"，**禁写"应该没问题"**；端点没监听就如实记"无监听"，不谎称已取存证；不凭记忆写时间戳。

## 三、环境坑位表（本机实测，省接手窗半天）

| 坑 | 实况与对策 |
|---|---|
| Python | 必用全路径 `%LOCALAPPDATA%\Programs\Python\Python312\python.exe`；PATH 上的裸 `python` 是 3.14，缺 fastapi/uvicorn 必挂 |
| node | 不在 PATH → `node --check` 类静态闸会诚实 SKIP（别当通过）；deno 兼容入口是既有替代法（`D-0926-W1d` §四候裁） |

| 服务 | 8777(HTTP)／8778(HTTPS) 是**代码里的文档口径，实际口会漂**（09-30 曾挂 8788）→ 用 `python vr_备场.py` 现算，别照文档抄地址；**旧进程冒充代码故障**是本档高频坑：改后端必重启才生效 |

| 安全闸门 | 本会话闸门：**Base 读可过、写不过**（10-01 实测）；IM 外发不过（含发给法师本人）；个别只读 git 命令会被误判拦下——被拦即如实报备，**不绕闸** |
