- **主持人条**：任何时刻只显示**一句话＋一个动作**；非法动作**不出按钮**（照抄 BCI2000 Preflight："出错时不给 Start"）。
- **证据抽屉**：11 项的所有表格与读数默认收起；**人不需要填表**（机器代填），需要时展开查改。
- **独立可观察通道**（⑦）：常驻原始波形小窗，**直读 SSE 原始帧**，不经过任何自测脚本、不读 `qc.json`——依据 Bowden 2025：自测层与观察通道**同源失效时漏检率会从个位数跳到 .52 量级**。
- **撤销/重来**：按 Horvitz 第 6/7 条（"猜错要便宜"），主持人条的任何自动动作必须可一句话撤回。

**表里三条硬约束**：① **T5 的 `observer` 必须是 `none`**（警戒性衰退有硬数字：30 次/小时信号率下检出率 85%→75%）；
② **T6 的 `judge` 是 `human_signoff`、"给不给原始档"机器无法自证**；③ **伪迹两分**（⑬）只作用于 T3：生理性伪迹**记录但不计设备缺陷**，设备性伪迹计缺陷。

## 四、两层状态机与结论三态（⑨④⑩⑬）

**会话层**：`DRAFT → READY → RUNNING ⇄ PAUSING/PAUSED → VERIFYING → AWAITING_SIGNOFF → COMPLETED`，旁支 `CANCELING → ABORTED`、`ARCHIVED`。
暂停与取消都是**排空式**（先把当前这一项做完再停）。

**单项层**：`PENDING / BLOCKED / ARMED / CUING / RECORDING / QC / QC_PENDING / QC_ALERTING / PASS / RETRYING / ESCALATED / INVALID / QC_ERROR / ACCEPTED_WITH_NOTE`

**结论四态（不可合并）**：
- `PASS` 达标｜`FAIL` 设备不达标｜**`INVALID`** 本次数据不可用但**设备没毛病**（人没静住、电极没贴好）｜**`QC_ERROR`** 脚本自身出错
- 外加 **`ACCEPTED_WITH_NOTE`**：数据可用但带保留（结论必须写明保留项）——依据 `skip` vs `xfail` 的语义区分。
- **`INVALID` 与 `ACCEPTED_WITH_NOTE` 绝不可合并成"失败"**：合并会让重试策略与结论口径双错。

## 五、四条机制（⑦⑧④⑨）

**5.1 判据哈希锁（⑧甲）**
- 新增 `qc_profile.json`（判据与阈值的**声明文件**，内容＝现 `qc_pipeline.py` 的阈值与判定链，**值一字不改**）＋ 其 `sha256`。
- 会话启动时校验：`sha256(qc_profile) == 声明锁定值` → 不一致**拒跑**并提示"判据已变更，请重新裁定后更新锁定值"。
- 产物指纹 `input_fp` **含 profile 哈希** ⇒ 判据一改，旧产物自动失效、必须重算。
- **意义**：把"判据不得擅动"从纪律升级为**机制**。

**5.2 独立可观察通道（⑦甲）**
- 常驻小窗直读 SSE 原始帧（帧号、末帧时刻、各通道原始幅值条），**不经过自测脚本、不读 `qc.json`**。
- 与自测层**不得同源**：独立解析、独立计时、独立渲染；任一方失效另一方仍可见。

**5.3 自动重跑规则（④甲）**
- 允许**阈值内自动重跑一次**（各项的重跑粒度见 §三 `retry` 列），并**如实记**"已自动重跑"（写入会话事件流）。
- 第二次仍不达标 → 升级到人（`human_gate` 的"判据落灰区"类），**不得静默继续、也不得无限重跑**。

**5.4 断点续跑与幂等（⑨甲）**
- 照搬 Bluesky：`checkpoint`＝可安全重来的点；**`clear_checkpoint`＝声明此处不可安全恢复**（电极重贴、受试者离开即调）。
- 中断后一律倒带至最近 checkpoint；**已采数据无论如何都落盘**；中断本身记成带时间戳事件。
- 中断后给人**四个选项**：`resume`／`abort`（保留数据、标 aborted）／`stop`（保留数据、标 success）／`halt`（直接停）。
- 幂等键：会话 ID（业务键，同一 ID 同时只能有一个在跑）＋ 尝试号（Run ID）——
  **重复点"开始"直接返回正在跑的那次，不重复采集**。
- SSE 断线续播用规范自带 `id:` ＋ `Last-Event-ID`，服务端留环形缓冲重放。

## 六、打断策略（⑫甲）＋ 误报记账

- **三态**：`不行动` ↔ `先问` ↔ `直接做`；**默认全部落"先问"**，仅当"判据硬＋代价低＋可回退"时允许"直接做"（T1/T2/T9 的读数）。
- **只允许三类触发**：① 只有人能做的 ② 判据落在灰区 ③ 数据有效性有风险。
- **`human_gate` 四元组**（每条都写死）：`问什么` ＋ `只接受什么答案（schema）` ＋ `多久不回默认做什么（ttl）` ＋ `谁有权答（roles）`。
- **静默成功**：只有**状态跃迁**才通知，配两个宽限（抖动不打断／不反复打断）。
- **误报记账**：每条提示显示"历史误报计数"，误报率越线时自动从**断言**降为**待核**。
  依据：Drew 2014（ICU 187 条/床/天、标注的心律失常告警 88.8% 假阳性）；Song & Wolfe 2026（**误报存在时预警好处完全消失**）。

## 七、质量门禁（⑮甲）——⚠ 属筛查门禁，不进判据链

- 规格（照 Heliyon 2023 的完整机制）：**每 2 秒一块**评 4 级 → **四色**（深绿/浅绿/橙/红）；
  **总分＝三个最差通道的平均**（正好暴露 Muse 单侧失效）；阈值 **≈82%**；**跳过门禁即记不合格**。
- 算法输入：信号特征（幅值／频率成分／**slew rate**）＋ 接触质量（DRL 与各电极间电导）＋ 无线丢包率。
- **界面必须同时明写**："**通过门禁 ≠ 数据可用**，门禁只是筛查"；权威判据仍是保存后的 `qc.json`／全量 npz。
- **阈值 82% 单列登记**（来源：Heliyon 2023，DOI 10.1016/j.heliyon.2023.e18433），**不并入 `qc.json` 判定链**。

## 八、口径落文（⑥⑬⑭）

**6 · AI 引导的三条判据**（写入方案，作既有第 3 条原则的**适用说明**，**不新立原则**）：
① **对象判据**：输出只用于判断任务/设备/数据是否达标 → 流程引导；若用于评价**受试者内在状态、境界、修习进度** → 越界。
② **退出判据**：可打断／可忽略／可关闭／判据可人工改判——**四者缺一即操控**。
③ **时机判据**：只在任务边界、低谷、或人主动问时开口；**在人正执行动作时插入、无法延后、必须立刻回应**者按干预对待。

**13 · T3 伪迹两分**（依据 Radüntz 2018：人工标注**刻意不标眨眼/眼动，因其与设备性能无关**）：
- **生理性伪迹**（眨眼／眼动／咀嚼／体动）：**如实记录但不计设备缺陷**；
- **设备性伪迹**（接触不良／工频／坏道／丢包）：**计入缺陷**。
- 二者在 T3 表与结论中**分列**，避免把生理伪迹算成设备问题。

**14 · T11 对照口径**（依据 Sensors 2024 / Front Neurosci 2024 两篇独立对照研究）：
- **镜像蒙太奇**（为参考设备构造与被测设备电极一一对应的电极版）＋**统一重采样到 250 Hz**；
- **只比相对特征**（α 峰频、Berger 效应指数），**绝对幅度不可跨设备比较**；
- **对照前不清洗**（作者原话 *"compare the devices in their initial state"*）——先清洗会把设备差异洗掉；
- **Muse 阻抗项记「不可得」**（两篇论文均记录其无法读取阻抗值）；
- **阻抗阈值按电极类型分组**（被动 <1 kΩ／有源 ≤25 kΩ／干电极 <1 MΩ），**不可套同一门槛**。
