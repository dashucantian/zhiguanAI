**修法**（三层，全部中文可读、指明期望格式）：

| 层 | 落点 | 处置 |
|---|---|---|
| 前端即时 | `console.html` 新增 `parseHostPort(raw,{allowUrl})` | 点「开始采集」时先本地校验：**1 毫秒**出红字报错、**零请求**（`performance` 计数复测），按钮即时恢复 |
| 端点同步 | `console_server.py` `monitor_start` | `neuradock` 分支先 `_parse_hostport` → 非法即 **HTTP 400 中文**，非法串不再进线程；校验通过后**回填规范化地址**，`mode` 展示位与存档口径不再被误粘贴污染 |
| 线程纵深 | `_worker` `neuradock` 分支 | 换用同一解析函数，异常时 `error`＋`end` 双事件如实收尾，不再静默死亡 |

旁证栏（容许粘整条 URL）与 TCP 栏（严格拒绝）**语义不同**，各按派单①②原文办理，差异已在回执列明。

## 二、① 新增旁证源「NeuraDock 指标 API（HTTP）」

- **读法定性**：派单标题写"新增数据源"，同节又要求"与自研 α/θ/β 并排显示"——若做成
  `monMode` 里与 TCP 互斥的一项，选它即无原始流、我方 α 无从计算，"并排"不成立。
  故实现为**独立旁证栏，可叠加在任一数据源之上**（"与 TCP 那条分栏"字面亦满足）。改法已在回执留话：
  要互斥形态只是把 select 挪进 `monMode`。
- 后端 `GET /api/ndmetrics?target=IP:端口`：**只读代理**，标准库 `urllib`（零新增第三方依赖）；
  拼路径由我方负责（实测基路径 `/api/v1` → 404，`/metrics` 才有数）；非法地址 400、连不上 502 均中文。
- 前端：新增「旁证源（只读·不入库）」选择器＋独立地址栏 `#ndSideAddr`；读数卡
  `#ndSideCard` **紧贴自研频段图正下方**，金色字＝对方算的、青色字＝我方算的，标题固定挂
  徽标「对方计算 · 非我方判据 · 不入库」；1 秒轮询（`api()` 加 `opt.timeout`，旁证请求 4 秒上限，
  平台不在线时界面不冻结）；来源行显示对方 `app_version`／`session_id`／`session_state`／
  `source.state`／`quality.grade`／可用路数。
- **不补值不破**：`status:"blocked"` → 显「blocked·原因码」；`value:null` → 显「无值（累积中）」；
  整卡**只显数字与状态、不画曲线**（对方 `window_sec 4`／`step_sec 1`，跨窗补点即等于我方补值）。
- 实跑并排（数据源=模拟＋旁证 63170）：对方 focus 20.75（置信 20%）／两项无值（累积中）
  ‖ 我方 α 16.8／θ -11.8／β 0.3 dB，同屏可辨；全文存证 `ZG076_验收记录_20260929.md`。
