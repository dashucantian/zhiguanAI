## 一、治理四动作

### 1.1 立规矩：本轮立三条，往后立四条

**规矩一：关停三要件。**
凡说"这件事停了"，必须同时满足三件：①**任务本身**不再有产出要求；②**执行面**（窗、cron、计划任务）不再触发；③**监控面**（台账、清单、周期哨、待裁单）不再把它当活。三件齐了叫**关停**；缺第三件叫**停了但还在被盯**，缺第二件叫**还在跑但没人认领**，缺第一件叫**只是没人做**。
→ 依据：本轮实测。周期哨 11-09 09:20 轮的四条里，有三条属于"线已停但监控面还在盯"（连续六轮报同一批"仍迟到"），一条属于"监控面在盯、但执行面结构上跑不了"。**这类噪音每轮消耗一次协调位的注意力**，是"任务多"的真实来源之一。
→ 落点：`周期任务哨.py` 的 TASKS 表已按三要件重写；此后新增周期任务，**必须同时写清三件**，否则不收。

**规矩二：值守留痕硬规。**
凡排程、cron、哨、定时任务，每一轮**无论有无变化**，都必须在自己的独占日志或台账**追加一行**（时刻＋做了什么／没做什么＋退出码）。**没有那一行，这一轮就不算跑过**。
→ 依据：C3 值守台 cron 每小时报 `succeeded`，而它的独占日志 `巡检日志-C3-b9f1881d.txt` 现读 mtime 停在 **2026-11-07 02:22:42**（尺＝`os.path.getmtime`，17:55:15）——**排程报成功，不等于办成了**。这个坑本项目吃过很多次（"报成功即办讫"），这次落在值守面上。
→ 落点：已写进 C3 值守台提示词首段（2026-11-09 改造）；往后新建自动件，提示词里必须带这一句。

**规矩三：一个活只挂一个位，一个位只对一个成果负责。**
台账（唯一任务源）、窗口编制（窗别）、身份号（署名）三者一物一位；**同一个活不许在两处挂**（台账有、周期哨没有；或者窗在做、台账没有），**同一个位不许对两个成果负责**。
→ 依据：双轴 §三 成因一——四主线两张卡（脑电 `TASK-20261102-01`、AI 复刻 `TASK-20261102-02`）在唯一任务源里出现 0 次，"空单与台账脱钩"（11-07 现读）。包一已补卡（11-06 完成），但**同样的病会复发**，所以立规。

### 1.5 口径一条：半对外载体的同源句可直改（法师 2026-11-10 字「立」）

**规矩**：同一句话已经在**源件**上改过（且有法师字），而它又在**半对外载体**（冷读本、化名稿、验收包等非直接发布件）上出现时——**可以直接跟着改**，不必另开裁点、不必另出理由页。

三条限定，缺一不可：
1. **同源**：必须是同一句、同一意思。改写、扩写、换说法都不算同源。〔**11-10 02:5x 补准边界**：判"同源"看**核心句是否逐字相同**——核心句逐字相同、只是排版形态（表行／条目）或括号注不同的，**算同源**；换了主谓、换了时态、加了限定语才算改写。例：`公众号未开设（法师 09-08 宣布"我们会新出公众号"）` 与 `公众号未开设（09-08 当时）、"我们会新出公众号"` 核心句逐字相同 ⇒ 同源。〕
2. **有字**：源件那一处必须是法师已给字的改动（例：㉟ 已决的 8 行）。没有字的，本条不适用。
3. **留痕**：改完在件内注明「依某字同源直改」，并照《01_发布审查清单》E3 自查一遍；查不出的项照实写"未过"，不许写"已过"。

**不适用三种**：新增句子；口径实质变更（如"未开设"改成"已定启用"）；要新造判据的场合。这三种仍走原路——出理由页 → 协调位核 → 法师字。

**本条不改 ㉟ 判据一字**，只把"同源直改"这个动作从"须另裁"改成"可直改"。

## 六、分阶段提示词系统（总纲）

**总纲另件**：`01_项目管理/20261109_W3_AI034_提示词系统_七阶段_v1.md`。七阶段：**S0 开工 → S1 定位与认领 → S2 施工 → S3 换手校核 → S4 收口与提交 → S5 呈裁 → S6 沉淀与复盘**。

**它凭什么"最灵活、系统、关联性强、可操作、可落地"**：
- **系统**：七阶段不是七段散文，是**七张同构的卡**（角色／触发／输入／输出件／判据／交接物／禁止项），字段一一对得上，像接口一样互相咬合。
- **关联性强**：阶段之间只靠**交接物**（下一阶段的输入就是上一阶段的输出件），不靠口头；交接物一律是**盘上可回读的件＋行号**。
- **可操作**：每个阶段的判据都写成**机器可查**的形式（收口检查的门 20—25 已有六道；缺的那几道在另件里标"缺"）。
- **可落地**：每阶段给**可直接复制的提示词正文**，含"第一动作跑什么""写哪几件""不许做什么"。
- **最灵活**：全篇**指针式**——写条不抄底座；每条挂判据出处（件名＋行号）；增补条位由任何窗提、协调位落、法师认（章程 §六第二处照认）。

**已具备 vs 缺**（现读）：
- 已具备：章程十二条（正本）、九道闸自检清单（甲3/乙5/丙1）、分工三栏表、教师席职责书、席位阶梯台账（门 22 可机检）、十格卡母版（含主线回指）、收口检查 25 门。
