## 三、团队协作方式

### 3.1 共享方式

```
团队协作方式全景
┌─────────────────────────────────────────────────────────────┐
│                    知识共享                            │
├─────────────────────────────────────────────────────────────┤
│                                                          │
│  静态共享                          动态共享          │
│  ├─ 文档版本管理                    ├─ 多维表格实时更新 │
│  ├─ 历史记录                        ├─ 实时评论@成员    │
│  └─ 权限控制                        └─ AI智能搜索      │
│                                                          │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 具体协作场景

#### 场景1：查看团队协作体系文档
```
访问路径：
飞书 → 工作台 → 知识库 → 止观AI项目 → 01_团队协作体系

操作方式：
1. 打开"团队+AI协同工作体系_完整方案_v2.1.md"
2. 使用飞书文档内置搜索定位需要的内容
3. 使用侧边栏导航跳转到对应章节
4. 查看当前版本号和更新日期

权限：全员可读，核心组可编辑
```

#### 场景2：共同编辑调整方案
```
访问路径：
飞书 → 工作台 → 知识库 → 止观AI项目 → 01_团队协作体系

操作方式：
1. 打开"团队+AI协同工作体系_完整方案_v2.1.md"
2. 点击顶部"编辑"按钮进入编辑模式
3. 进行修改
4. 使用"@成员"功能通知相关责任人
5. 点击"评论"按钮说明修改原因
6. 保存后自动生成新版本

版本管理：
- 每次编辑自动记录修改人、修改时间、修改内容
- 可随时查看历史版本和恢复
- 重要修改需要在文档顶部更新"版本号"和"更新记录"

示例格式：
---
**文档版本：** v2.2
**更新日期：** 2026-01-16
**更新人：** 郭永安
**更新记录：**
- 调整XX角色定位
- 新增YY功能描述
```

#### 场景3：共同填写调研数据
```
访问路径：
飞书 → 工作台 → 多维表格 → 公司图谱/产品库/技术动态

操作方式：
1. 打开对应的多维表格
2. 点击"新增记录"或直接编辑
3. 填写信息（自动关联负责人的飞书账号）
4. 保存后自动通知相关负责人
5. 可使用筛选功能查看自己负责的内容

实时协作：
- 多人同时编辑时显示"正在编辑"标识
- 冲突时飞书自动提醒合并
- 使用"评论"功能@成员讨论
```

#### 场景4：AI辅助检索与调用
```
访问路径：
飞书 → 工作台 → 知识库 → 止观AI项目 → 搜索框

操作方式：
1. 在知识库顶部搜索框输入关键词
2. 选择搜索范围（全部/文档/表格）
3. 查看AI生成的相关结果
4. 点击结果直接跳转到对应位置

AI辅助功能：
- 语义搜索（不只是关键词）
- 推荐相关文档
- 自动总结多个文档要点
- 快速定位到具体章节
```
