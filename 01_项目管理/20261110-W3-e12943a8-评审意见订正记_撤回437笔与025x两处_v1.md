## 四、由此立一条（建议，候法师字）

**提交面笔数一律写「显式午夜尺＋时点」，禁写裸日期。** 模板：

```
git rev-list --count HEAD --since="YYYY-MM-DD 00:00"   # 读数 N（YYYY-MM-DD HH:MM:SS 现取）
```

理由三条：①裸日期在本机是移动切点，同一条命令隔一分钟读数不同；②`--pretty=format:%h | wc -l` 比真值少 1（末行无换行），只能用 `rev-list --count` 或 `--oneline`；③笔数随时间只增不减，凡引用必带时点，否则下一次复核必然对不上。
