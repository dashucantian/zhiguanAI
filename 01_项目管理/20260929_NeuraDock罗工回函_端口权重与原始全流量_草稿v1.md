## 一、四问（按对方能直接查的口径写）

**问 1 · 端口能否固定／有无无界面模式**
指标平台每次启动 HTTP 端口都变（我方同一天内先后见到 `55005` → `52413` → `63170`），页面里的 API 地址也随之变。
① 能否固定端口（或提供配置文件／启动参数指定）？② 有没有命令行／无界面（headless）启动方式，便于我方长时间实验时稳定取数？③ 若结构上无法固定，能否提供一个**本机固定的发现入口**（例如写死的注册端口、或本机一个固定文件里记当前端口）？

**问 2 · 七项指标的公式与权重能否书面给出**
`/api/v1/metrics` 返回里，体验类指标（如 `focus`、`visual_load`）的 `formula_version` 与 `baseline_z` 均为 `null`；客观状态类（`spectral_complexity`、`global_integration`）自报 `formula_version: objective-state-v2.0.0`。请按**七项逐项**给出：
① 计算公式（或伪代码）；② 各频段／各通道的**权重**；③ 归一化到 0–100 的映射；④ `confidence_percent` 怎么算；⑤ `baseline_z` 在什么条件下才会非空（个人基线如何建立）；⑥ 体验类能否也给出 `formula_version`。
（我方诉求只是"事后能解释、能复现"，不要求开放源码。）

**问 3 · 原始全流量是否开放（这一问与"指标数据"是两件事）**
罗工答的是"把**指标数据**接入驾驶舱"，我方要问的是**原始脑电全流量**：`250 Hz × 7 通道`的原始 EEG 采样（含全通道波形与同步时间戳）能否开放、以何形式开放？
平台 API 目前自报 `raw_eeg_exposed: false`，页面亦写明"外部客户端只能读取结果，不能启动设备、绕过校准或取得原始脑电"。
① 这是**产品既定边界**还是**当前版本未开**？② 若可开，走什么通道（本地 TCP／文件导出／LSL 等）？③ 若确不可开，请书面确认一句，我方好据此把"原始流"需求从对贵方的依赖中摘除。

**问 4 · 数据失效时的返回语义（我方实测所遇，请确认是否设计行为）**
实测：当 `source.state` 已为 `"error"`、`last_sample_age_sec` 从 259 秒一路涨到 2099 秒（即约 35 分钟无新数据）时，`focus` 仍以 `status: "evaluated"` 返回**旧数值**。

（我方已在界面侧自行加了"数据龄 > 8 秒标陈旧"的红字兜底，但更希望由数据源自述，避免使用者误读旧值为实时值。）
