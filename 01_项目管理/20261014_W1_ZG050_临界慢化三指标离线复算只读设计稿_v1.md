## §一 三指标定义与计算方法

### 1. 恢复时间（Recovery Time）

**物理含义**：系统受扰动后回到基线所需的时间。临界点附近恢复变慢。

**计算方法**（逐坐逐通道）：
1. 对每通道的 alpha 功率时序（或原始 EEG 带通滤波后的包络），检测局部峰值（扰动事件）
2. 从峰值下降到峰值与基线差值的 1/e（≈37%）所需的时间即为单次恢复时间
3. 全坐取中位恢复时间作为该坐该通道的指标

**公式**：
```
t_recovery = t_when |x(t) - baseline| < |peak - baseline| / e
```

**实现要点**：
- 基线：滑动窗口中位数（窗口=10s）
- 扰动检测：超过基线 + 2*std 的峰值
- 单位：秒

### 2. 方差（Variance）

**物理含义**：信号波动幅度增大，系统在临界点附近涨落加剧。

**计算方法**（逐坐逐通道）：
1. 对每通道的 alpha 功率时序，计算全局方差
2. 也可用滚动方差（窗口=5s）的中位值作为稳健估计

**公式**：
```
variance = var(x(t))
```

**单位**：µV²（若用原始 EEG）或相对功率²（若用频带功率）

### 3. lag-1 自相关（Autocorrelation at Lag 1）

**物理含义**：相邻时刻的相关性增强，系统"记忆"变长，是临界慢化的核心指标。

**计算方法**（逐坐逐通道）：
1. 对每通道的 alpha 功率时序，计算滞后 1 个采样点的自相关系数
2. 或用 AR(1) 模型的系数 φ₁ 作为估计

**公式**：
```
ρ(1) = corr(x(t), x(t-1))
```

**取值范围**：[-1, 1]，临界点附近趋向 1
