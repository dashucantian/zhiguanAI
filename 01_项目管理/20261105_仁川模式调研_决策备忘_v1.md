## 一、直接采用，还是先借鉴？

**一手证据**：口述 061「我是做这个 AI 站的定制，针对这个中小企业」；084「target customer 是 SMB 甚至小微 solo partner」；145「瞄准的是 OPC，公司最多两三个合伙人」；171「现在主要在买的都是房产经纪……sface 就是做心理咨询，还有医疗服务的很多，还有律师」；094「一个月 399 到 999」（⚠口述未言币种）；176–178「所有的问题最核心的都是客户……从客源的管理，到客源的获取，到最后 retention」；031「相当于 cron job……每分钟去定期扫」；066「bas 每 4 个小时就扫一遍」；043–047「很多人开 4 个窗口、8 个窗口……我上线设置了 8 个窗口，同时开 8 个 instance」；129「open cloud 只完成了可能 20% 的工作」（以上均为**说话人自述，未核实**）。

**说话人归属订正（2026-11-06 00:0x，退补三）**：口述 167「所以你对你自己这个东西的定位还是一个software的定位，而不是一个agent的定位」——**句中的「你」指提问方自己那个东西，不是仁川自己的定位**。判定依据：底本 166「他他说的就是承担后果，但我这是给你做的工具的情，你自己不担后」句末的「你」与 167 的「你」同指一方（提问方），故 167 是仁川对提问方讲的话；**仁川自述其定位的一手句是 161–162**「这是business model的问题啊……所有公司一定都是使工者来承担这个问题」「如果说我承担这个问题，那就不是这个收费了」——即**他自述做的是工具、后果由客户担**。逐字稿无说话人标签，本窗据上下文衔接判定，**不作定论**。⇒ 本件不再用 167 支撑任何结论；「定位为工具而非 agent」这一层改挂 161–166。

**反证**：外部同赛道供给极拥挤（E22：入场券打到 2999 元；E24：全国 65 座城市落地 OPC 社区、23 城出台专项扶持政策）⇒「也是一人公司＋多 agent」不构成差异化。他自己也判断 harness 一年内有大幅跃升、全球「数成千上万的人」在做这件事（口述 125–130，自述未核）。

**我方对照**：我方已有等价件，不需抄——任务卡母版十格≈他的 acceptance criteria 结构；本机 4 台周期哨＋2 个 Windows 计划任务≈他的 cron 扫描；离线转写＋本机 OCR 桥≈他的语音入口。

**结论与置信度**：**先借鉴，不直接采用**。可借鉴三样：

- **① 唯一主 agent 只接我的语音、worker 各自干活**（口述 102–103）——产品形态的**口述版**，非产品实样；
- **② 验证必须换模型或工具、否则同源自证**（口述 050–053、104–105）——设计直觉；
- **③ 以客源与收入为卖点、卖工具而由客户担后果**（口述 176–178 客源管理／获取／retention；定位依据改挂 161–166「我这是给你做的工具的情」「如果说我承担这个问题，那就不是这个收费了」，**自述未核**；⚠原挂 167 的「定位为 software 而非 agent」已按上文说话人归属订正撤下）。

属**伪创新**（听着像核心竞争力、实为普通工程）的两样：多 agent 分工本身、定时扫队列本身。

置信度：**中低**——**他口述的形态可判断**；其真实营收、交付质量、客户留存**外部不可证**（无第三方证人，E22／E24 均为报道转述其自述）；且本轮未取得其产品实样（专名无一可确认指向何物，N1／N2 未得），故凡涉及其产品本身的推断均只在「口述」这一层成立。

## 二、能学什么？

**一手证据**：同上三样**口述形态**（非产品实样）；口述 104–105 讲验证 agent 的由来是「让那个 agent 自己干自己验证，发现不太好，就又开出一个新的 AI 站来干这个事」；口述 110–114 讲真上客户生产环境时「有无数个你之前想不到的东西」。

**反证**：口述 125–127 他自己说这些问题「就是 harness 的一部分」且年内可解 ⇒ 学了也可能被抹平；E9 引科普中国拆解「灵修班」伪正念三信号（只允许导师解释体验、不允许提问质疑、退出被说成「失去福报」）⇒ 学「带教闭环」若带进这三条，直接踩雷。

**我方对照**：我方质检链（`qc_pipeline.py`）与判语库已经是「换尺复算」的现成件，不缺方法，缺的是把它接进对客流程。

**结论与置信度**：三条可学，每条附难度与第一道验证动作（表内只留编号与一句话，细则见条目）：

| 编号 | 一句话 |
|---|---|
| L1 | 语音入口：单一主 agent 编译意图成卡 |
| L2 | 验证者必须换模型或换尺，不许同源自证 |
| L3 | 反馈按固定周期扫并落成改进决定 |

**条目**

- **L1** 可复制难度：低（转写与母版已在盘）｜第一道验证动作：取法师近 10 条真实口述指令，走「语音转写→母版回填→成卡」，一次成型 ≥8 条｜失败信号：一次成型 <6 条
- **L2** 可复制难度：低｜第一道验证动作：对 10 件已交付件各换一个模型或一把尺重跑，统计结论翻转数｜失败信号：翻转 >3 件
- **L3** 可复制难度：低（本机定时已有）｜第一道验证动作：实跑一轮扫描，确认真触发并产出，而非「已配置」｜失败信号：连续两轮迟到 >2 小时

置信度：高（此三条只依赖我方已有件，不依赖任何未核外部事实）。

## 五、我们的不可替代性是什么？

**一手证据**：口述 099–103（主 agent 的第一要务是随时接住我的信息，所以不让他干活）；口述 129–130（他判断 harness 很快解决大部分缺口，行业里做这事的成千上万）；口述 125（他自陈模型不进步的情况下今年 AG 能力也会大幅举标）。

**反证**：多 agent 编排、任务卡格式、定时扫队列、语音入口——这四项**都会被通用模型与开源 harness 追平**；追平要多久，**外部不可证**，口述 125–127 说的「年内」是说话人自述，未核实，不作我方结论。

**我方对照**：我方无法被外部复制的两样＝①法师的慈悲标准与判断力、②居士带教者本人的手感与信任（开工件 §二丁明列，只能内部验收与真实客户背书）；另一样是我方 136 坐脑电原始数据与 139 件判断资产的累积，外人拿不到。

**结论与置信度**：
- **外部永远无法证明、只能内部验收**：法师的判断力与慈悲标准；带教者本人的手感与信任。
- **会被通用模型追平**：多 agent 编排、任务卡格式、定时扫队列、语音入口（他自陈行业人数与年内跃升，自述未核）。我方在这些项上的领先是**暂时的**。
- **暂时不会被追平**：脑电原始数据＋判语资产的累积量，以及与具体社区的真实关系；但**目前没有任何第三方证人**能证明它们。
置信度：中（不可替代性的「分类」可判断；追平时间为不可证，不给数）。

## 六、必须专门回答的一问（摘要，全表见证伪清单件）

**「居士带教者愿意付费并买单」若为假，我方哪些件作废、哪些仍成立**——

**作废**：① 定价三档草案的第二档与第三档（无买家）；② 路线图阶段 3 全段（其完成判据第 1 条「≥3 笔真金白银付费」永不可能达成）与阶段 4 支线 A；③ 路线图「营员想带人用＝第二档现成客户」这条转化链；④ 仁川模式若以「照搬其定价带」为前提，则该前提作废（其价格带面向专业服务型个体户，不可平移到居士带教者）。
**仍成立**：① 定价三档第一档（免费自修）与「卖产品不卖带教服务」这条裁断；② 任务卡母版（内部效率件，与付费无关）；③ 营期反馈脱敏规程与阶段 2 反馈回路（营期已定，与付费无关，但扫描链路必须实测真触发）；④ 定位裁决单中「基础档免费」「按具体需要定价收费」两条；⑤ 全部脑电与质检资产、案例库判语、会话时间账。
**须重裁**：定位裁决单「第一段客群＝居士带教者」这一条本身。
