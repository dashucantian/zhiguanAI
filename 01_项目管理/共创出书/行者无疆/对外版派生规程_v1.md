# 行者无疆 · 对外版派生规程 v1（别编／外编起用）

> 建立：2026-09-28（W2·AI-010，P0-2 开工件）。
> **上位件**：《对外版清稿检查清单》（2026-09-19，C3 固化，六项，任一项不过即不得发布）。**本规程不取代它，只补它没写的四条。**
> 适用：别编九篇、外编五篇的〈对外发布版〉派生，以及书前书后五件升对外版。

## 一、放置与命名

- 内稿原位不动；对外版进本编目录下 `对外版\` 子目录（`别编·义理\对外版\`、`外编·公案\对外版\`）。
- 命名：`<篇名>（对外发布版）.md`。
- 正编五篇对外版历史上与本编并列于书根，**属既成事实，不搬迁**（搬迁会打断已有引用）。

## 二、稿头三行（与正编五篇同式）

```
# 行者无疆 · 别编 0X：<篇名>
> **对外发布版（L1 待审定）** ｜ 据内部稿整理，YYYY-MM-DD
> 本版状态：**待宗国法师审定**。审定通过后方可发布；未经批准不得对外传播。
> 与内部稿的差异见文末《发布版处理说明》。
```

## 三、正文区六项

即《对外版清稿检查清单》①～⑥。要点：**正文区**（文末《素材来源》标题之前）内部标识命中＝0；归属标注〔法师原话〕〔法师裁定〕〔法师口述〕〔AI 理解〕〔衔接语〕**属法则一实质内容，保留**；《发布版处理说明》整节供法师审定、**发布时连节删除**。

## 四、新增四条（P0-2 起用，均已写进各篇《处理说明》）

1. **人物首现即交代**。首次出现的人称，当处给一句可核对的交代，此后可简称。**治读者通读查出的"人物零交代"**。三个已知难点：
   - **维那**——一词在项目内**至少有三个所指**（本窗口读者通读已列为 P0-2 问题）；首现须限定"本书中指哪一个"，**具体措辞待法师定**（候选已置各篇处理说明，不用即不写）。**不猜、不合并**。
   - **AI 助理**——项目里做整理、比对与执笔的 AI 协作者；不是一个人，也不是一个产品。
   - **阿山／其他称呼**——首现须给对应关系（详见书前《凡例》修订项）。
2. **篇末台阶行**。每篇末加一行 `> 本篇台阶：…`——走到哪一级就说到哪一级，不到者明说停在哪一级（法则六）。**治读者通读查出的"结尾悬空"。**
3. **不悬空收束**。正文末尾若停在待裁事项上，**保留该事实**（不粉饰），但须补一句明确收束："此事待法师点头，本篇到此为止。"**不得以未完成的施工状态当结尾。**
4. **编号不进正文**。正文区不出现判语／日志／方案稿编号、版本号、commit 短哈希；改为无编号表述（"法师某日裁定""据项目文档"）。**日期保留**（日期是可核事实，不是内部标识）。《素材来源》节可含编号。
