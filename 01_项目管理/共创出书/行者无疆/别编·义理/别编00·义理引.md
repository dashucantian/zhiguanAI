## 一、这一编是什么

正编讲"发生了什么"，外编讲"你可以怎么做"。**别编讲"为什么这样想"。**

它不新造体系。每一篇都是**既有文档的人读化投影**——方案稿、判语卡、法师口述的原文在那里，别编只把它们按"人读得下去"的方式重写一遍，并按一条规矩往上走：

> **宏大落在具体上，一次只升一维。**（写作法则六）

## 三、台阶：各篇走到哪一级

法则六要求走三级台阶——**具体决定 → 普适判断 → 文明层面**，不许跳级。但**走到哪一级，各篇不同**。这一编的体例是：**走到哪儿，就说到哪儿；不到那一级，就明说停在哪一级。**

| 篇 | 台阶实况 |
|---|---|
| **02 自带法界反馈** | **全编唯一显式走完三级**的篇（具体决定—普适判断—文明层面） |
| 01 入照运融出 | 一、二级扎实（"控制台四个页签 vs 五相五项，结构正交"）；**第三级未走，本篇停在第二级** |
| 03 镜子，不是训练器 | 一、二级扎实（JMIR 元分析的负向裁决、证据种类之辨）；**停在第二级** |
| 04 真值从哪里来 | 一、二级最厚（90 页书、十项画像投影、"三相可算、一相半可、一相空"）；**停在第二级** |
| 05 胎藏界喻 | **明确停在登记层**——"义理展开待法师指导，AI 不引申" |
| 06 文明如何评判 | 第三级（托卡马克"输出大过输入"、普及化与个性化） |
| 07 虚拟禅堂 | 三、四级之间（道场、实修、传播、组织） |
| **08 止观传习史** | 三级齐备：具体史事 → "法无高低、随顺世俗而建" → 三语系互流与新文明 |

> **这不是缺点。** 一个项目如果每一篇都能一口气讲到文明层面，那多半是形容词在代替证据。**停在哪一级并说出来，本身就是这本书的品格**——与 05 的"写到这里就是边界"同源。

## 四、这一编不做什么

1. **不新造义理**。义理级的判断，出处一律是法师；AI 只登记、编号、比对。
2. **不复制方案文档原文**（既有硬约束）。凡重写，按三级台阶作人读化处理。
3. **不引申法师未展开处**。05 是最显式的样本；08 涉大圆满与禅宗同源之说，亦只转述"有种说法"，不判定。
4. **不用形容词堆"宏大"**。谈文明、时代、人机关系，必须从一个可指认的物件或决定切入。
