## 一、别编·义理 新增篇目

### 别编 09 · 从此·双基因

| 项 | 内容 |
|---|---|
| **对应正编** | 第八章「从此」 |
| **接哪一篇** | 别编 03「镜子，不是训练器」的延续——镜子只照，从此还学；但学的边界在哪里？ |
| **核心义理** | ① 做梦＝动能势能的自然平息过程，完成**记忆的整体性沉淀**（法师 10-05 课堂定名，转引级）；② 双层反馈：虫子模型＝动能反馈（自然层）× 止观AI＝神经反馈（意识层）；③ 对齐路径："虫子模型对齐人，大模型对齐虫子"；④ 三层体系：双层核心→个人本地节点→数字分身→"智慧本尊·不二智界" |
| **法师原话锚点** | "止观AI＝神经反馈回路系统（灵性基因），从此＝动能反馈系统（生物性基因），双基因构成基础"（《愿景框架》§二）；"简单当中把人的东西投射出来，就够了"（10-05 课堂·转引） |
| **与别编 03 的关系** | 03 划红线（不训练、不解读、不承诺功效）；09 在红线内开新面——"学"不是"训练人"，是"系统自己长"。区别：训练器的目标函数在人身上，从此的目标函数在系统自身。 |
| **边界（凡例·不替法师立法义）** | 本篇只登记法师原话与已裁定义理，AI 不引申"智慧本尊"的修证含义；三层体系的后两层（数字分身、智慧本尊）目前无工程实现，如实标为愿景。 |
| **素材来源** | 补充素材底账 §三（笔记 10-05·B 级转引）＋方案稿 v1 §0.1＋《愿景框架》§二§三§八 |
| **预计篇幅** | 与别编 03 相当（~1500 字正文） |

### 别编 10 · 谁能看——隐私作为修行设施的一部分

| 项 | 内容 |
|---|---|
| **对应正编** | 第七章尾声「给镜子装门禁」＋第八章（三级制贯穿） |
| **接哪一篇** | 别编 03「镜子，不是训练器」的另一面——镜子不训练人，也不让人被外面看到 |
| **核心义理** | ① 零出网三级制：一级（修道班/学员/机密）不出网不全量检索；二级（社区信息）脱敏；三级（工程）可出网；② 四道闸全部服务端强制（出网判定/一级拦截/标识脱敏/图像脱敏）——不是界面提示，是代码拒绝；③ 判据＝推理的物理位置，不是桌面端/云端的标签；④ "一级绝不出网"不因技术进步放宽 |
| **法师原话锚点** | "屏幕共享、权限控制和数据脱敏等功能必须在本地实现，不得上传到云端"（10-07 金口）；"镜子照得越清楚，越要先回答'谁能看'"（第七章尾声·法师裁定） |
| **与别编 03 的关系** | 03 说"不训练"；10 说"不外泄"。两条合起来是镜子的完整伦理：不改变照的人，也不让第三人看到照的内容。 |
| **边界** | 本篇不讨论具体法律合规（宗教法规分析线另档），只记项目自身的隐私义理。 |
| **素材来源** | 规约 §四bis ⑦＋D-1007-W3b＋看板需求与隐私原则_v1＋工作日志 10-07 系列 |
| **预计篇幅** | ~1200 字 |

## 二、外编·公案 新增/增补篇目

### 外编 02 增补 · 踩坑精选（续四案）

现有外编 02 收六案（坑 001～006 区间）。增补四案：

| 坑号 | 标题 | 现象（用户视角） | 根因 | 教训一句 |
|---|---|---|---|---|
| **012** | 接上却是死数 | 蓝牙连上了，数据也有，但全是零 | 位让出：前一个进程占着蓝牙没释放，新进程拿到的是空壳连接 | 连上≠通了；先查持有者 |
| **015** | 从模式跳到机制，一日三犯 | 同一天里三次把"临时做法"写成了"永久规则" | 模式（当下怎么绕过）与机制（制度上怎么固化）没分清 | 绕过后必须追问：这是模式还是机制？ |
| **017** | 自建的闸门从未响过 | 收口检查跑了两天全绿，但一道闸的判据本身坏了 | 症状与正常态长得一模一样＝没有告警；脚本头注写着"判据亦须被核验"，坏掉的恰是判据 | 闸门本身也要被验；"全绿"可能是"全瞎" |
| **018** | 先核持有者不自动清锁 | index.lock 残留，git 全堵 exit 128 | 崩溃/强杀后锁文件没清；但"先核持有者"的纪律让人不敢自动清 | 确认零进程后才清锁；不自动、不猜 |

体例照现有外编 02：现象（原话）→根因→解法→排障顺序→教训。每案 ~400 字。

### 外编 05 · 复现路径（三）多模型协作与系统扩展

| 项 | 内容 |
|---|---|
| **对应正编** | 第六章（窗口分开）＋第八章（第五任模型·从此三批施工） |
